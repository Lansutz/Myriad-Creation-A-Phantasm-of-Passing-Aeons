# Myriad Creation: A Phantasm of Passing Aeons

纷繁的世界：一场流逝的幻景

一款仍在制作中的**大战略 + 上帝模拟**游戏。我想做的不是复述某一段固定历史，而是让地理、技术、人口、文化、宗教与政治在漫长的时间里彼此牵动，看它们会走出什么样的轨迹。

## 出发点

这个项目的思考，受唯物史观、布罗代尔的三时段、人类学、技术史、反辉格的历史书写、地理历史学与历史政治学的影响较多。我更关心长期的、结构性的缓慢变动，而不是把历史写成一连串英雄人物与偶然事件；也尽量避免用今天的眼光去替过去的人评判"进步"或"落后"。

项目在制作中大量借助了 AI，但具体的想法、取舍和设计是我自己的。

## 架构

工程以 Unity 6 / C# 实现，代码按职责拆成几个程序集，目标是在大世界、大量角色与聚落的情况下仍能稳定运行，同时让修改和模组制作更容易：

- **MyriadCreation.Core**：基础数据结构与约定
- **MyriadCreation.World**：地图、地块、锚点与栖居点等世界数据
- **MyriadCreation.Simulation**：人口、经济、革新、文化、宗教、社会、政治、战争等模拟系统
- **MyriadCreation.Rendering**：地图与各类叠加层的渲染
- **MyriadCreation.UI**：界面布局
- **MyriadCreation.Infrastructure**：存档、序列化、模组与事件等基础设施
- **MyriadCreation.Editor**：编辑器工具
- **MyriadCreation.Tests**：编辑模式与运行模式测试

这里我刻意不追求"拆得越细越先进"。每一层抽象都应当解决一个真实的问题——状态归谁所有、谁能修改、性能边界在哪里、模组能不能方便地扩展。

## 几个核心概念

**栖居点（HabitationSite）**是人在地图上栖居的业务入口，以三种模式区分：

- **定居点（Sedentary Settlement）**：永久性，以居住和生产为核心，如村、镇、城、都会
- **据点（Fortified Outpost）**：永久性，但以控制、防御和通道为核心，如堡垒、关口堡、烽燧、驿站
- **营地（Temporary Encampment）**：临时性或半永久性，可以拔营转移，如行军营地、冬营、游牧营地

正常发展只能向上：营地可以转为据点或定居点，据点可以转为定居点；定居点是终态，只有在遭到毁坏时才会沿明确的路径降级。

**锚点（Anchor）**只负责空间上的定位、索引与地图操作（放置、点击、移动、删除），它本身不携带聚落的业务数据。栖居点通过锚点在地图上显现，锚点之间可以形成控制关系和影响范围。这样可以避免把整张地图涂满边界分明的色块——前现代的控制往往是围绕一个个节点展开的，而不是现代意义上清晰的国境线。

**革新（Innovation）**在这套模拟里占很大比重，许多变化都由它推动。一个社会能否出现某个固定的社会阶层，往往需要相应的革新作为前提，无论那是技术上的还是观念上的；不同社会所拥有的阶层也因此并不一致。

设施（Facility）独立拥有自己的施工状态、损毁状态、材料与形制；城墙的形状记录在设施形制里。局部损毁只影响具体设施，不会单独改变整个栖居点的模式。

## 状态

这个项目还远未完成，很多系统只有框架，不少设计也会继续调整。代码能否在 Unity 中完整编译运行，需要在编辑器里实际打开确认。我把它放在这里，更多是记录一个正在成形的东西，而不是展示一件成品。
