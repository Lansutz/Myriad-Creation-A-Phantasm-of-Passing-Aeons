> 2026-11-09 01:45（Asia/Shanghai）。撤回两个提问，并把它们改成设计原则。

## 1. 我错在哪

| 我的提法 | 错在哪 |
|---|---|
| "偶然性预算"：多大比例结果由偶然决定（如 5% 黑天鹅）？ | 把偶然当成**全局参数**。这正好犯了我自己立的原则 5（别用抽象数值替代机制）。偶然本来就有载体：**气候/灾害**（自然）、**个体出生与死亡**（生物）、**接触**（地理与事件）。 |
| "powers 的代价 / 世界反噬" | "反噬"是凭空发明的机制，模拟里没有对应物质环节；还会把干预变成"游戏技能"。真实后果已经由因果链承担，不需要额外惩罚层。 |

## 2. 偶然性到底由什么构成（已核代码）

| 层 | 载体 | 证据 |
|---|---|---|
| 自然 | 13 类灾害，按季节修正概率；改 `fertility / annualTemp / soilHumidityPct / stability / order` | `DisasterSystem.cs:282-337`（`ApplyImmediateEffects` 地震/火山/火灾；`ApplyDisasterEffects` 旱/涝/寒潮/热浪/蝗/歉收/饥荒）；`GetSeasonDisasterMod`（`:339-349`）；`DisasterSchedule` order 11 |
| 自然 | 季节性气候与年际波动 | `SeasonChangedEvent`、`WorldMapSimulationSystem` |
| 生物 | 出生等位基因组合（6 基因座）、突变（0.0075/0.015）、疾病、死亡（health 衰减 + 疫病） | `DnaSystem.cs:210-258`；`DiseaseSystem.cs:209-212`；`CharacterData.cs:344-372` |
| 接触 | 谁遇到谁（迁移/商路/战争）——由地理与事件决定 | `MapActorManager`、`EconomyManager` 商队、`DiplomacyManager` |

**结论**：偶然性已经"有"了，不需要预算。需要的是**别在结果层掷骰**（直接决定战争胜负、国家存亡），以及在 M1 把不可复现的随机源换掉（`PopulationTick` 用 `Environment.TickCount` 播种，H 域已证）。

**一个真实缺口**：`fertility` 目前没有下游（生产链不存在，F 域 P0）⇒ "旱灾→减产→饥荒"这条最经典的偶然链条是断的。这不是偶然性问题，是生产问题。

## 3. 干预为什么不设代价

后果链条已经足够：

- 抬山 → 降水（雨影）→ 肥力 → **产出（缺）** → 人口 → 税基 → 军力；
- 改河道 → 通航/洪水 → 贸易成本 → 城镇兴衰；
- 降灾 → 稳定度/肥力 → 叛乱/饥荒。

所以"改坏了世界，历史自己会惩罚"，不需要再做一层冷却或反噬。**只守两条边界**：

1. **只改条件**（不得加钱、改胜负、指定存亡）；
2. **匹配时间尺度**（布罗代尔）：地形/气候属长时段，改动天然稀少；灾害属短时段。用世界时间表达，不用 UI 冷却。

外加一条可观察要求：每次干预**记入编年史**，让改动可追溯而不是无声改数。
