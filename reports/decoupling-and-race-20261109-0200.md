# 架构解耦与生物学基底修正报告

> 2026-11-09 02:00（Asia/Shanghai）。里程碑：Plan v3 / M2.8「解耦审计 + 种族基底」。
> 触发：用户三点——① 系统要耦合但**代码/文件架构要解耦**（改一处不必连带改多处），并怀疑"还是有些没有做全"；② 我问"天才能否逆地理"是蠢问题，答案由**这个人和他的种族**决定；③ 一切都是为了模拟**可能真实发生的事**。

---

## 1. 结论先给

**用户的怀疑是对的：解耦只做了一半。**

- **做完了的一层**：程序集（15 asmdef、依赖无环、UI 禁止引用 Simulation 家族）、目录即 owner、`ARCHITECTURE_RULES` 门禁。
- **没做的一层（这才是"改一处要改多处"的原因）**：
  1. **内容一半在 JSON、一半在 C#**：29 个建筑、单位定义、政体组件的革新门槛、阶层革新门槛、革新→阶层涌现映射，全部硬编码在代码里；
  2. **状态有 5 组双真源**：两套人口、两套法律、两套遗传、两套存档、两套建筑可用性；
  3. **关键量被跨层直接写**：`realm.treasury +=`、`tile.stability = Lerp(...)`、`anchor.influenceTier = ...`；渲染路径甚至会在查询时**写**模拟状态；
  4. **组合根被拆成 13 个 partial**（按技术关注点拆而非按职责），改系统常要改 `GameWorld`；
  5. **场景与代码双源**：`Main.unity` 把面板引用序列化为 `null`，代码里却有打开面板的方法。

**"这个人到底是什么玩意儿"的答案是：种族 + 基因 + 特质 + 处境。而种族目前是空的**——`RaceDefs.json` 0 条，代码硬编码一个"人族"，11 项生理参数全为 1f。所以现在换谁、换哪个种族，世界都一样。

---

## 2. 已落盘的改动

### 宪章（`DESIGN_CHARTER.md`）
- **原则 2 重写**：能动性**不是设计参数**，是"具体个体的构成（种族生理/基因/特质/健康/处境）在具体地理里的实际结果"；信号改为只验因果（换人换结果 / 换地理换结果 / 极端个体使尾部变厚），不再设"属性差 ≥1σ"这种拍脑袋阈值。
- **原则 1 修正**：国家形成"可识别多种方式"，但**是世界生成后自然涌现**；`StateFormationPath` 是事后分类。
- **新增 §1.6「生物学基底：种族不是装饰」**：列 `RaceData` 的 11 项参数与 2 个消费端，指出内容为空是 P0。
- **新增原则 8「系统耦合，架构解耦」**：五条可测信号 + 现状耦合点。
- **§2 标题改为"八条原则"**。
- **§6 待议**：撤回"能动性上限"与"大战略胜利条件"（都是我问蠢了），只留 2 条。

### 总纲（`SYSTEM_MASTER_PLAN.md`）
- §0 新增第 10/11 条结论（解耦只做一半；所有人差异恒等于零）。
- §3.0 系统清单新增 **S14 生物学基底（种族/基因/体质）**，并说明为何单列。
- **新增 §4.4 架构耦合审计**：7 类耦合点 × 证据 × 处置。
- M3 增"补生物学基底（RaceDefs ≥3 个差异明显的种族）"；M8 增"让个体构成真正生效"。
- §7 横向门禁新增 **原则 8（五条信号）**。
- §8 待议收敛到 2 条。

### 决策（`DECISIONS.md`）
- **D20** 系统耦合/架构解耦（五条信号，立为门禁）
- **D21** 种族是生物学基底，`RaceDefs` 为空 = P0
- **D22** 撤回"能动性上限"提问
- **D23** 内容外提清单（建筑 29 / 单位 / 政体组件门槛 / 阶层门槛 / 涌现映射 → JSON）

## 4. 已验证 / 未验证

**已验证**
1. 解耦缺口的三类（内容硬编码、双真源、跨层写字段）都有具体文件与行号，不是印象。
2. 种族当前对模拟的实际影响只有两处（人口增长、疫病抗性），且参数全 1f ⇒ **人物差异在数据上恒为零**。
3. 五条解耦信号可以逐条写成检查（其中②③已能机械判定）。

**未验证**
1. 未全仓扫描"哪些 `public` 字段被跨程序集写入"——只抽了 3 个例子；全量需要一次静态扫描（建议纳入 M0.5 的工具链）。
2. 未评估把 5 张硬编码表外提为 JSON 的工作量，也未评估对现有测试的影响（很多测试直接 `new` 定义对象，外提后可能要改夹具）。
3. 未实机验证"换种族 → 结果不同"——因为种族内容为空，这条信号目前必然不成立。
