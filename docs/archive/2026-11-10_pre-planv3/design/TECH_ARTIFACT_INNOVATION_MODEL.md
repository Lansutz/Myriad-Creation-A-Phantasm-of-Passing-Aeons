# 技术/器物类革新：工艺—型制—能力模型

> 用户定调：技术器物类按**工艺、型制、能力**分；型制必须用**技术史意义上的中性名称**——
> 不依赖某一文献、语言、文化专名或文学绰号，而按**动力来源、结构、运动方式、作用对象**命名，便于跨文化比较。
> 历史依据/技术史序列见 [TECH_HISTORY_NOTES.md](TECH_HISTORY_NOTES.md)；革新/物品分类见 [INNOVATION_VS_ITEM_CLASSIFICATION.md](INNOVATION_VS_ITEM_CLASSIFICATION.md)。

---

## 1. 三层定义

```text
工艺（Technique）
  └─ 怎么做：配方、加工、装配、机构、工序
       ↓ 解锁
型制（Pattern）
  └─ 做成什么：具体武器/器械/船只/车辆/建筑的构型
       ↓ 提供
能力（Capability）
  └─ 能做什么：射程/穿甲/攻城/机动/载重/火力密度/战术
```

| 层 | 是否革新节点 | 落点 | 例子 |
|---|---|---|---|
| **工艺** | 是（`InnovationKind.Technique`） | `Innovation` | 黑火药配制、颗粒化火药、弩机制作、膛线加工 |
| **型制** | 可以是（`InnovationKind.Pattern`），但**必须是中性技术描述** | `Innovation` + `EquipmentDef`/`UnitDef`/`BuildingDef` | 火门枪、火绳枪、射石炮、配重式投石机、覆顶撞门车、车载张力弩 |
| **能力** | 否 | `unlocks`/`capabilityModifiers`/单位属性 | 穿甲、射速、射程、攻城加成、移动射击 |
| **物产** | 否 | `GoodsDef` | 火药、箭矢、铅弹、铁、铜 |

### 1.1 中性技术术语规则

1. **按动力来源**：人力/畜力/水力/风力/配重/扭力/张力/火药；
2. **按结构**：梁/拱/架/轮/顶棚/悬挂/铰接/多桅/多甲板；
3. **按运动方式**：抛射/撞击/攀越/挖掘/移动/旋转；
4. **按作用对象**：门/墙/壕/城/人/船；
5. **不把史料专名/文化专名/文学绰号当规范名**：如 `吕公车`、`轒辒车`、`野驴投石机`、`trebuchet`、`manjaniq` 只作为历史别名/来源注记，不进入 `innovationName`。

### 1.2 跨文化对应示例

| 中性名 | 可对应的历史专名 |
|---|---|
| **配重式投石机** | 欧洲 trebuchet、伊斯兰 manjaniq、中国配重抛石机 |
| **覆顶撞门车** | 罗马 testudo arietaria、中世纪冲车、中国临冲 |
| **移动攻城塔** | 欧洲 siege tower、中国吕公车等 |
| **扭力投石机** | 罗马 onager、mangonel 等 |
| **车载张力弩** | 中国床弩/车弩、欧洲 carroballista 等 |

> 原则：**先写技术原理/结构，再在来源/别名里写史料专名**。

## 2. 火药：先分工艺，再分用途

| 条目 | 层 | 说明 | 建议 |
|---|---|---|---|
| 硝石提纯 | 工艺 | 从硝土/鸟粪/矿物中提纯硝石 | 若模拟硝石资源 |
| **黑火药配制** | 工艺 | 硝石/硫磺/木炭配比 | 复用 `207` |
| 颗粒化黑火药 | 工艺 | 湿法造粒，燃烧稳定、便于运输 | 可选 |
| 无烟火药 | 工艺 | 硝化纤维，需近代化学 | 后续时代 |
| 火药（物产） | 物产 | 成品黑火药 | `GoodsDef`，不是革新 |

- `207 → 黑火药配制`；`unlocks: good:blackPowder`；火药本身是物产。

## 3. 火器：按击发机构/炮种分型制

### 3.1 手持火器

| 中性型制 | 关键机构 | 能力差异 | 备注 |
|---|---|---|---|
| **火门枪** | 火门手动点火 | 射程短、装填慢、精度低 | 最早；`手铳` 作为史料别名 |
| **火绳枪** | 火绳枪机 | 可瞄准、齐射 | 需要火绳/火药 |
| **燧发枪** | 燧石击发 | 更可靠、射速提高 | 需要弹簧/火石 |
| **线膛枪** | 膛线 + 米涅弹 | 射程/精度大幅提高 | 需要精密加工 |
| **后装枪** | 后膛闭锁 | 装填速度质变 | 工业时代 |

### 3.2 火炮

| 中性型制 | 能力 | 备注 |
|---|---|---|
| **射石炮** | 攻城、破墙 | 早期石弹炮；重、机动差 |
| **野炮** | 野战、机动 | 较轻 |
| **臼炮** | 高抛、曲射 | 攻城/壕战 |
| **火箭** | 面杀伤/纵火 | 不稳定 |

> `307 → 火绳枪机`（具体型制）；`火绳枪兵` 是单位，不是型制。

## 6. 船只：三层坐标（船体形态 × 动力系统 × 用途）

> 船名不是船类本名；`卡拉维尔/克拉克/盖伦/长船/风帆战舰` 都是"船体+动力+用途/模块"的组合。规范名用中性三轴描述。

### 6.1 第一层：船体形态（最底层）

| 船体形态 | 说明 |
|---|---|
| **筏** | 木筏/竹筏/浮囊筏；无龙骨，靠浮力面承载 |
| **独木舟** | 整木挖空，最早单体舟 |
| **木板船** | 搭接/平接船板，出现龙骨与横梁 |
| **双体舟/舫** | 两舟并联，提高稳性 |
| **复合结构船** | 木—金属、木—玻璃钢等混合船体 |

### 6.2 第二层：动力系统

| 动力 | 说明 |
|---|---|
| **人力撑篙船** | 撑篙推进，浅水/内河 |
| **人力划桨船** | 单层/多层桨 |
| **人力橹船** | 橹的连续推进，效率型 |
| **人力拉纤船** | 岸上拉纤 |
| **风力横帆船** | 横帆，顺风为主 |
| **风力纵帆船** | 纵帆，可抢风 |
| **风力混合帆船** | 横/纵帆组合 |
| **桨帆并用船** | 桨+帆 |
| **轮桨推进船** | 轮桨/车船的技术实质 |
| **明轮蒸汽船** | 蒸汽+明轮 |
| **螺旋桨蒸汽/内燃机船** | 螺旋桨推进 |

### 6.3 第三层：用途（中性功能名）

`内河货船 / 远洋货船 / 客船·渡船 / 渔船 / 漕运船 / 工程船 / 拖船 / 战船`  
`战船` 只是功能子类，不是船类本名。

### 6.4 命名：短中性名 + 轴标签，不拼复合名

三层坐标是**数据/标签**，不是名字。规范名只取该条目最主要的差异轴：

- 船体形态：`筏`、`独木舟`、`木板船`、`双体舟`、`复合结构船`；
- 动力系统：`横帆船`、`纵帆船`、`桨帆并用船`、`橹船`、`明轮蒸汽船`、`螺旋桨蒸汽船`；
- 用途：`内河货船`、`远洋货船`、`客船`、`渔船`、`漕运船`、`工程船`、`拖船`、`战船`。

三层信息放 `affinityTags`/`definition`/数据字段，例如：

```text
innovationName = 横帆船
affinityTags   = [ship, hull:plank, propulsion:sail-square]
definition     = 木板船体、横帆推进的帆船；用途由具体设计/单位决定。
```

不要写 `木板船体·横帆·远洋货船` 这种长复合名——难记、难本地化、UI 也放不下。

- `长船` = `hull:narrow-long` + `propulsion:oar-sail` 标签，不是名字；
- `风帆战舰` = `propulsion:sail` + `module:broadside-artillery`，不是名字；
- `三列桨/五列桨` = `oar-arrangement` 修饰，不是独立条目；
- 史料船名（卡拉维尔/克拉克/盖伦）只放来源/别名。

## 8. 落点与测试

- `黑火药配制`：`unlocks: good:blackPowder`；火药物产进 `GoodsDef`（待接）。
- `弩机制作`：单位 111 `弩手` 继续依赖 304；`unlocks: equipment:crossbowMechanism`。
- `配重式抛射机构`：`unlocks: equipment:counterweightTrebuchet`；物品是 `EquipmentDef`：配重式投石机。
- `火绳枪机`：`unlocks: equipment:matchlock`；物品是 `EquipmentDef`：火绳枪；`火绳枪兵` 单位后续另加。
- 测试：`InnovationSchemaTests` 精确名称/前置理由；`InnovationMigrationTests` 名称断言。
- 不把 `火药/火器/攻城器械/弩` 作为可研究条目。
