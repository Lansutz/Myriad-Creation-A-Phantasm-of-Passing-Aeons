# 革新 vs 物品/物产/单位：技术器物分类表

> 用户要求：把前面列的名称搞清楚——**哪个是革新，哪个是革新解锁的物品/物产/物资/单位**，不要把物品名当革新。
> 规则：革新 = 工艺/机制/结构原理/制度；物品 = 具体器材/船只/武器/建筑；物产 = 可储存交易的物资；单位 = 编成/角色。
> 对应文档：[TECH_ARTIFACT_INNOVATION_MODEL.md](TECH_ARTIFACT_INNOVATION_MODEL.md)、[TECH_HISTORY_NOTES.md](TECH_HISTORY_NOTES.md)。

---

## 0. 判定标签

| 标签 | 含义 | 落点 |
|---|---|---|
| **革新·工艺** | 配方/工序/加工/装配方法 | `InnovationDef` = `Technique` |
| **革新·型制** | 具体结构原理/构型（不是具体物品实例） | `InnovationDef` = `Pattern` |
| **物品/装备** | 具体武器/器械/船只/车辆实例 | `EquipmentDef` / `UnitDef` / `BuildingDef` |
| **物产/物资** | 可储存/交易的材料 | `GoodsDef` |
| **单位** | 编成/兵种/船员角色 | `UnitDef` |
| **标签/修饰** | 桨手层数、帆装组合、功能模块 | `affinityTags` / 修饰字段 |
| **不做** | 无独立模拟效果 | 不建条目 |

> 同一个词在不同语境可能跨层；本表给**主判定**。例如 `火绳枪` 是物品，`火绳枪机` 是革新。

## 5. 一句话规则

- **革新** = 配方/机构/结构原理/制度（`黑火药配制`、`火绳枪机`、`配重式抛射机构`、`横帆帆装`）；
- **物品/装备** = 具体器械/船只/武器（`火绳枪`、`配重式投石机`、`远洋货船`）；
- **物产/物资** = 可交易材料（`火药`、`纸`、`铁`）；
- **单位** = 编成/角色（`火绳枪兵`、`弩手`）；
- **标签/修饰** = 三列桨、长船、风帆战舰（组合/修饰，不是条目名）。

## 6. 软前置（能力阈值）

- 硬前置：`prerequisiteTree`（All/Any/Leaf，可嵌套）；不掌握就不能掌握下一个。
- 软前置：由 `associatedGoods` 的**物理属性**推导能力阈值（如 `meltingPoint` → `heat.maxTemperature`），用已解锁各项提供的**总能力**满足；不要求某个特定前置科技（如青铜），也不要求特定燃料（如木炭）。
- 实现：`InnovationSoftPrerequisite` + `HasCapabilityValues`；不是"已知低阶材料给研究加成"的阶梯。

## 7. 冶铁/炼钢的拆分

- `202 块炼铁冶炼`：低温固态还原 + 锻打；不是“冶铁术”泛称。
- `203 渗碳炼钢`：块炼铁渗碳 + 折叠锻打；不是“炼钢术”泛称。
- `931 生铁高炉` / `929 坩埚钢` / `930 渗碳淬火` 保留为具体路线/工艺。
- 软前置由关联物产熔点推导：块炼铁约 0.7×铁熔点，渗碳钢约 0.9×钢熔点；不要求青铜/木炭等特定前置。
