# 现有“七维”法律结构研究

> 2026-11-05。对象：`LawComposition` 的七个核心维度（`LawSystem.Fingerprint` 实际使用的 7 个）：
> 最高交接、最高范围、中央交接、中央机构、地方交接、地方职能、央地结构。
> 目的：逐项研究、判断是否能纳入统一法律/法令系统、哪些要改名/拆分/新增/延后。

---

## 1. 七维清单与现有选项

| # | 维度 | 现有选项 | 现有代码 |
|---|---|---|---|
| 1 | 最高交接 `SupremeSuccession` | 世袭 / 直接选举 / 代议推举 / 僭夺 / 轮座 / 神命 | `LawComposition.supremeSuccession` |
| 2 | 最高范围 `SupremeScope` | 全能 / 法理受限 / 惯例约束 / 共议制约 / 神意约束 | `supremeScope` |
| 3 | 中央交接 `CentralSuccession` | 任命 / 选举 / 考试 / 世袭 | `centralSuccession` |
| 4 | 中央机构 `CentralInstitution` | 无常设 / 王庭 / 议会 / 长老议事会 / 官僚中枢 / 宗教会议 / 军事委员会 | `centralInstitution` |
| 5 | 地方交接 `LocalSuccession` | 任命 / 选举 / 考试 / 世袭 / 城市特许 | `localSuccession` |
| 6 | 地方职能 `LocalScope` | 全权自治 / 征税司法 / 仅军事驻防 / 完全直辖 | `localScope` |
| 7 | 央地结构 `SpatialStructure` | 单一制 / 联邦制 / 邦联制 | `spatialStructure` |

未进七维但已在 `LawComposition` 的：最高归属（君主/共和）、头衔分配、领地分配、中央有无、信仰治理、法源等。

## 2. 逐维研究

### 2.1 最高交接

历史形态远多于六项：

- 世袭（长子/幼子/诸子/兄终弟及/选举君主）；
- 推举/选举（贵族、显贵、军队、代表会议）；
- 指定继承/共治/摄政；
- 神命/加冕/教皇认可；
- 篡夺/征服/内战；
- 轮座/抽签（少见）。

问题：

- “僭夺”是**取得方式**，不是稳定继承法；更适合事件/合法性路径；
- “轮座”太特殊，应作变体；
- “世袭”应拆为**继承规则**（长子/幼子/均分/选举君主）或作为子项；
- “神命”与宗教治理/合法性绑定，不是纯继承法。

建议：

- 保留组：最高交接；
- 项：世袭-长子、世袭-诸子均分、推举、选举、指定共治、神命加冕、篡夺（事件）；
- 继承法细则作为子项/另一组，不塞进一个选项。

### 2.2 最高范围

“全能/法理受限/惯例约束/共议制约/神意约束”方向可以，但：

- “全能”容易现代绝对主义化；前现代王权仍受习惯/宗教/贵族约束；
- “法理受限”与“惯例约束”重叠；
- “共议制约”与中央机构/代表会议重叠。

建议：

- 改名更中性：`无成文约束 / 习惯约束 / 宗教约束 / 贵族/代表共议 / 成文法约束`；
- 把“谁参与共议”交给中央机构/代表组，不在此重复；
- 早期只有习惯/宗教约束，成文法约束需革新。

### 2.3 中央交接

任命/选举/考试/世袭覆盖主要路径，但：

- 缺少 **购买/捐纳**、**推荐/保举**、**教区委任**、**军功晋升**；
- “考试”是具体制度，需成文法/文书/科举类革新；
- 任命/世袭不是互斥，可能混合（如官职世袭+部分任命）。

建议：

- 保留组，增加“推荐/保举”“捐纳”“军功”；
- 考试作为子项/需革新；
- 与官僚系统连接：不同交接方式给不同 `administrativeCapacity/merit/corruption`。

### 2.4 中央机构

现有七项覆盖宫廷、议会、长老、官僚、宗教、军事，但：

- “议会”是现代词；中世纪应是**等级会议/代表会议/显贵会议**；
- “官僚中枢”的子选项（三省六部/三公九卿/部院制）是**官僚形态**，不是机构类型，应拆组；
- “宗教会议”与信仰治理/法源重叠；
- 缺少 **宫廷/内廷/外廷** 区分、**常设/非常设**（已有 centralExistence）。

建议：

- 组：中央机构类型（无常设/宫廷/显贵会议/等级会议/长老会/官僚中枢/宗教会议/军事委员会）；
- 另组：官僚形态（三省六部/三公九卿/部院制/其他），需官僚革新；
- “议会”按时代改名“等级会议/代表会议”；
- 宗教会议归信仰治理或法源，不混中央机构。

### 2.5 地方交接

任命/选举/考试/世袭/城市特许覆盖主要路径，但：

- **城市特许不是“交接方式”**，是地方自治/特权类型，应移到“地方职能/特许”组；
- 缺少 **购买/抵押/包税**、**教区委任**、**军管**；
- 地方官职世袭与封臣继承不同，需区分“官职”与“领地”。

建议：

- 组：地方官职产生方式（任命/选举/考试/世袭/购买/教区委任/军管）；
- 组：地方自治/特许（城市特许、行会、领主司法）；
- 与地方职能分开。

### 2.6 地方职能

全权自治/征税司法/仅军事驻防/完全直辖方向可以，但：

- “全权自治”与“城市特许”重叠；
- “征税司法”是两项职能，可拆；
- 缺少 **司法/财政/军事/治安** 分项；
- 应与 `DecreeOrder` 执行/地方 compliance 连接。

建议：

- 改成分项：司法权、征税权、军事驻防权、治安权；
- 或保留四档，但明确每档包含哪些权；
- 城市特许作为例外规范，不塞进地方职能组。

### 2.7 央地结构

单一/联邦/邦联是现代概念，前现代不适用：

- 中世纪常见 **复合君主制（composite monarchy）**、personal union、采邑网络、帝国/行省、羁縻；
- “联邦/邦联”是近现代制度，不能开局就有；
- 央地结构不是一条法律，可能是多重法律秩序/特许/习惯叠加。

建议：

- 早期：`习惯/采邑网络/帝国行省/复合君主制`；
- 近现代才解锁 `单一制/联邦制/邦联制`；
- 央地结构由多个组（中央-地方权能、地方自治、特许）合成，不靠单选项。

## 3. 七维之外缺什么

| 维度 | 是否该加 | 模拟作用 |
|---|---|---|
| 最高归属（君主/共和） | 已有，独立组 | 合法性/继承/外交 |
| 头衔分配 | 已有但塞在最高范围子项，应独立 | 继承/贵族/内战 |
| 领地分配 | 同上 | 继承/分封/中央集权 |
| 中央有无常设 | 已有 | 行政能力 |
| 官僚形态 | 应拆独立组 | administrativeCapacity/corruption |
| 军事统辖 | 应加（已部分） | 调遣/自主性/边防 |
| 信仰治理 | 已有，冻结 | 合法性/宗教 |
| 法源 | 已有 | 司法/法律整合 |
| 身份/公民权 | 视模拟需要 | 兵源/税基/权利 |
| 边境管制 | 应加（非关隘） | 贸易/安全/通行 |

## 4. 与历史阶段绑定

| 阶段 | 可用的七维形态 |
|---|---|
| 部落/习俗 | 最高交接=推举/世袭/神命；中央机构=长老会；地方=习惯；央地=采邑/部落联盟 |
| 早期王权 | 最高=世袭/神命；中央=宫廷；地方=任命/世袭；央地=复合 |
| 中世纪 | 等级会议、城市特许、封建法、教会法；央地=复合君主制 |
| 早期现代 | 常设官僚、常备军、主权立法；央地=单一/复合 |
| 现代/未来 | 联邦/邦联、成文宪法、根本化 |

早期不能出现“联邦制/议会/官僚中枢/考试”等现代项；这些要革新/时代解锁。

## 5. 对现有代码的判断

- `LawComposition` 的七维是**政体结构问题域**，不是法律效力等级；
- 它能并入法律系统，但应作为 `ConstitutionalOrder` 的组，而不是“根本法”；
- 七维中至少三处需要拆：
  1. 头衔/领地分配从最高范围拆出；
  2. 城市特许从地方交接拆出；
  3. 官僚形态从中央机构拆出；
- 至少两处需要改名：
  - “议会” → 等级会议/代表会议（按时代）；
  - “联邦/邦联” → 早期用复合/采邑/帝国行省，近现代才用联邦；
- 至少一处需要新增：
  - 军事统辖/边防管制（已在军事法审计中提出）。

## 6. 模拟必要性

| 维度 | 必要 | 不做的后果 |
|---|---|---|
| 最高交接 | 高 | 继承危机/内战无法解释 |
| 最高范围 | 高 | 合法性/专制/共治无法表达 |
| 中央交接 | 高 | 官僚质量/腐败/能力无来源 |
| 中央机构 | 高 | 决策/合法性/行政能力无来源 |
| 地方交接 | 高 | 地方官/领主/城市差异消失 |
| 地方职能 | 高 | 地方自治/税收/驻军无差异 |
| 央地结构 | 中高 | 法律 reach/comp 无法分层 |
| 头衔/领地分配 | 高 | 继承/分封/内战缺失 |
| 官僚形态 | 高 | 官僚系统接不上 |
| 军事统辖 | 高 | 调遣/自主性/边防缺失 |

不要为了“七维完整”硬塞没有模拟作用的项；但上述高必要项不能省。

## 8. 结论

- 七维方向基本对，但**太现代、太扁平、互相重叠**；
- 不能直接当“根本法”；应作为 `ConstitutionalOrder` 主题域；
- 先拆：头衔/领地、城市特许、官僚形态；
- 先改名：议会、联邦/邦联；
- 先加：军事统辖、边境管制；
- 早期只开放习惯/王权/长老/复合结构，现代项靠革新解锁；
- 这七维的每一项都要能改变至少一个模拟变量，否则不进组。
