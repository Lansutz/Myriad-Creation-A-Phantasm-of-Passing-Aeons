## 0. 命名规则

1. **中性技术描述**：按结构/动力/功能命名，不用历史专名、文化专名、文学绰号；
2. **不把多种特征硬拼成一个长名**：船 = 船体 + 帆装/推进 + 用途，分别用字段/标签表达；
3. **不用 `·` 拼接**；
4. **一个词只承担一个层**：`射石炮` 是具体早期火炮；`攻城炮` 不是它的同义词，更不是所有攻城炮的统称；
5. 历史名（caravel/carrack/galleon、trebuchet、bombard 等）只作 `variantOf`/参考，不作 canonical name。

## 1. 船：动力 × 攻击/毁伤机理 × 船体

### 1.1 “长船”是船体结构，不是战船类型

“长船”描述的是**窄长、浅吃水**的船体；维京长船是典型：帆桨并用，靠桨在无风/近岸时保持机动。

- `长船` = `ShipHullForm.Long`；
- 它本身不定义战术；
- 在长船船体上装什么**战术模块**，才决定它是接舷平台、撞角舰还是运兵船。

### 1.2 撞角战船：先看撞角类型，再看动力匹配

| 撞角 | 毁伤机理 | 典型平台 |
|---|---|---|
| **尖锐式** | 水线以下穿透、戳洞 | 人力多列桨舰 |
| **攻城锤式** | 钝重舰首冲量、整体倾覆 | 人力多列桨舰 |
| **鳍式** | 水平鳍片在木板上制造长裂缝 | 人力多列桨舰 |

关键：**风帆不能精确倒车脱离**，高效撞角平台几乎都是**人力多列桨舰**；桨手提供冲刺/倒桨的精确控制。

中性名示例（结构化字段组合，不是历史专名）：

```text
人力多列桨 · 尖锐撞角舰
人力多列桨 · 攻城锤式撞角舰
人力多列桨 · 鳍式撞角舰
```

### 1.3 风帆战舰：看火炮搭载/投射逻辑，不看“有帆”

| 类型 | 技术核心 | 中性名 |
|---|---|---|
| 多层连续火炮甲板、舷侧齐射 | 战线最大火力 | **舷侧多炮层主力舰**（战列舰） |
| 单层炮甲板、速度/巡航半径 | 巡逻、侦察、追击 | **单层炮甲板巡航舰**（巡洋舰/护卫舰） |

“风帆战舰”只说明动力，不说明火力层级；不作为 canonical 名。

### 1.4 过渡型：名字就是动力+武器组合

| 组合 | 典型 | 中性名 |
|---|---|---|
| 保留桨手，主火力改舷侧炮位，帆航占比高 | 加莱赛船 | **帆桨并用 · 舷侧炮座舰** |
| 帆桨并用，目的是投送步兵跳帮/劫掠，无舷侧重炮 | 维京长船 | **帆桨并用 · 接舷平台** |

### 1.5 当前数据模型

`EquipmentDef` 增加船类字段：

```csharp
ShipHullForm hullForm;        // Raft/Dugout/Long/Broad/Composite
ShipPropulsion propulsion;    // Oar/SquareSail/Lateen/OarSail/Paddlewheel/SteamScrew
RamType ramType;              // None/Sharp/Hammer/Fin
BatteryLayout batteryLayout;  // None/GunPort/BroadsideSingleDeck/BroadsideMultiDeck
bool boardingPlatform;
```

具体物品示例：

| 物品 | 船体 | 动力 | 撞角 | 火力/模块 |
|---|---|---|---|---|
| 独木舟 | Dugout | Oar | None | — |
| 横帆船 | Broad | SquareSail | None | — |
| 桨帆船 | Long | OarSail | None | boardingPlatform |
| 纵帆船 | Broad | Lateen | None | — |
| 远洋货船 | Broad | SquareSail | None | — |
| 炮门战船 | Broad | SquareSail | None | GunPort |

> `横帆船`/`纵帆船` 只是“帆装 + 船”的简称；完整设计由 `船体 + 动力 + 撞角 + 火力/模块` 组合。历史名 caravel/carrack/galleon 只作组合参考，不作本名。

## 2. 攻城炮：`射石炮` 是具体早期火炮，不是“所有攻城炮”

### 2.1 射石炮（bombard）

- 早期大型前装滑膛炮，主要发射**石弹**，用于轰击城墙/塔楼；
- 铸铁/铸铜大口径，身管短粗，装填慢；
- 中文对应 **射石炮/射石砲**，英文 **bombard**；
- 它是 14–15 世纪攻城火炮的一支，不是 16 世纪以后的加农炮/长管炮/臼炮。

### 2.2 不要叫“攻城炮”的层

`攻城炮` 是**功能类别**（用于攻城的火炮），不是某一具体器物/革新：

| 名称 | 层 | 说明 |
|---|---|---|
| 射石炮 | 具体早期火炮 | 石弹、轰城；可做 innovation + item |
| 臼炮 | 具体火炮 | 高抛弹道、曲射；另列 |
| 长管炮/蛇炮 | 具体火炮 | 长身管、直射、反人员/轻型；另列 |
| 加农炮 | 具体火炮 | 中长身管、攻城/野战两用；另列 |
| 野炮 | 功能类别 | 野战机动火炮，不是攻城炮同义词 |
| 攻城炮 | 功能类别 | 只作分类/tag，不作条目名 |

### 2.3 当前内容

- 革新 `308 射石炮铸造`（Technique/Pattern，早期铸炮工艺）；
- 物品 `EquipmentDef 3 射石炮`（SiegeEngine，发射石弹）；
- 不建“攻城炮”革新/物品；后续臼炮/长管炮/加农炮分别另列。

## 2.5 近战武器：不要用一个“青铜武器/铁制武器”物品

革新是**铸造/锻造工艺**，物品是具体兵器：

| 革新 | 物品 |
|---|---|
| 201 青铜冶炼 | 青铜戈、青铜矛、青铜剑、青铜镞 |
| 202 块炼铁 | 铁剑、铁矛、铁刀 |

- `青铜戈` = 长柄勾啄（Polearm）；
- `青铜矛/铁矛` = 长柄刺击（Spear）；
- `青铜剑/铁剑` = 直刃（Sword）；
- `铁刀` = 单刃（Saber）；
- `青铜镞` = 消耗件。

不再用 `青铜武器`/`铁制武器` 作为具体物品名；它们是材料+工艺类别。

## 3. 火器：按“点火/击发机构”拆

| 名称 | 层 | 关联革新 |
|---|---|---|
| 火门枪 | 具体物品 | 火门点火 |
| 火绳枪 | 具体物品 | 火绳枪机 |
| 燧发枪 | 具体物品 | 燧石击发机构 |
| 线膛枪 | 具体物品 | 膛线加工 |
| 射石炮 | 具体物品 | 射石炮铸造 |
| 火绳枪兵 | 单位 | 不是物品/革新 |

`火绳枪` 不是革新；`火绳枪机` 是击发机构。`燧发枪` 同理。

## 4. 弩与攻城器械

| 名称 | 层 | 说明 |
|---|---|---|
| 弩机制作 | 革新·工艺 | 制弩工艺 |
| 弩 / 蹶张弩 / 腰开弩 | 物品 | 具体弩 |
| 车载张力弩 | 物品 | 车载架座 + 弩 |
| 张力弩炮 | 物品/攻城器械 | 大型张力发射装置 |
| 配重式抛射机构 | 革新·型制 | 配重抛臂机构 |
| 配重式投石机 | 物品 | 具体器械 |
| 牵引式投石机 / 扭力投石机 | 物品 | 具体器械 |

不要把这些笼统合成 `攻城器械` 一个革新。

## 6. 仍待辨析

- 桨帆船的具体桨手层数（三列/五列）只作 modifier，不作船名；
- 长船、风帆战舰等只作 tag/组合，不作 canonical name；
- 臼炮/长管炮/加农炮/野炮的先后与模拟差异；
- 船体材料（木/复合/铁/钢）与帆装/推进的模块化组合。

---

## 7. 铸造 ≠ 锻造

- 铸造：液态金属入型腔；细分范铸/失蜡/砂型/金属型；
- 锻造：固态金属加热后锤打/模压；细分自由锻/模锻/折叠锻；
- 两者是并列工艺族，不是材料专属；材料相关不等于材料命名。
