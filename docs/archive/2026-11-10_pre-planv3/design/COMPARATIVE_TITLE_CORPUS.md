# 头衔比较研究：西欧 / 神罗 / 北欧 / 近东 / 印度 / 希腊 / 美洲（样本集）

> 2026-11-08。方法：按「原文 → 词源/本义 → 权力来源 → 制度 → 演变/传播」逐条整理；用于建立可提取的头衔样本库与传播模型。
> 说明：本环境网页全文抓取被 DNS 拦截，只能拿到检索条目；词源按通行辞书与古文字学整理，争议处标"一说/存疑"。
> 结论先行：**同一译名（国王/公爵/伯爵/皇后）背后是完全不同的权力来源**；头衔传播有同源、借词、仿译、称号公式四条路径，rank 阶梯只是翻译与后世系统化的产物。

## 0. 阅读口径

- **词源 ≠ 现行含义**：`后` 本义君主、后世后妃；`侯` 本义射侯、后世侯爵。
- **译名 ≠ 制度**：`knyaz` 译"王公/公爵"，本义"宗长"；`Herzog` 译"公爵"，本义"军队领袖"。
- **同一词根可以分叉**：`*kuningaz` → king / konungr / knyaz / kuningas，语义各不相同。

## 1. 法兰西 vs 英格兰

| 层 | 法兰西 | 英格兰 | 本义/词源 | 权力来源 |
|---|---|---|---|---|
| 王 | roi | king | roi < 拉丁 rex（治理者）；king < 古英语 cyning < 原始日耳曼 *kuningaz（亲族之长） | 治理 / 亲族 |
| 后 | reine | queen | queen < 古英语 cwēn（女人、妻子；与哥特语 qens 同源） | **不是"女国王"，原义是"女人/妻子"** |
| 公爵 | duc | duke | 拉丁 dux（引导者、军事领袖） | 军事 |
| 伯爵 | comte | earl（本土）/ count（诺曼） | comte < 拉丁 comes（同伴、侍从）；earl < 古英语 eorl（勇士、首领） | 宫廷侍从 / 军事 |
| 侯爵 | marquis | marquess/marquis | 拉丁 marchio（边疆，march） | 边防军事 |
| 子爵 | vicomte | viscount | vice-comes（副伯爵） | 代理 |
| 男爵 | baron | baron | 法兰克语 baro（男人、战士；一说"自由人"） | 军事/人身 |
| 骑士 | chevalier | knight | chevalier < caballarius（骑马者）；knight < 古英语 cniht（男孩、仆从） | 军事服务 |
| 乡绅/侍从 | — | thane | 古英语 þegn（仆从、随从） | 服务关系 |
| 亲王 | prince | prince | 拉丁 princeps（第一人） | 首席 |

要点：

- 英语的 earl 与 count 是**两个来源**：earl 是本土"勇士/首领"，count 是拉丁"同伴"；诺曼征服后并用（earl 用于本土爵位，countess 来自法语）。
- king 与 knyaz 是**同源词**（*kuningaz），却分别译成"国王"和"王公/公爵"——翻译层把同源词拆成不同等级。
- queen 的本义是"女人/妻子"，不是"king 的女性形式"；"女王"是后世语义扩展。

## 2. 神罗：Herzog 不是"部落"，是"军队领袖"

| 头衔 | 词源 | 本义 | 权力来源 | 备注 |
|---|---|---|---|---|
| Kaiser | 拉丁 Caesar | 恺撒 | 帝国继承/宣称 | 不是"皇帝"的本土词 |
| König | *kuningaz | 亲族之长 | 亲族/王权 | 与 king 同源 |
| Herzog | 古高地德语 herizogo（heri 军队 + zogo 领袖） | **军队领袖** | 军事 | 拉丁 dux 的**仿译**（calque） |

| Graf | 古高地德语 grafio/graf（词源存疑，一说与"书写/官署"有关） | 官长/伯 | 行政/地方 | 与拉丁 comes 不同源，却译"伯爵" |
| Markgraf | marchio（边疆） | 边疆伯 | 边防军事 | 与 marquis 同源 |
| Pfalzgraf | comes palatinus（宫廷伯） | 宫廷伯 | 宫廷 | |
| Landgraf | 领地伯 | 领地伯 | 领地 | |
| Burggraf | 城堡伯 | 城堡长官 | 城堡/军事 | |
| Kurfürst | 选举侯 | 选举侯 | 选举 | HRE 选帝侯 |
| Freiherr | 自由领主 | 自由领主 | 人身/法律 | 译"男爵" |
| Ritter | 骑手 | 骑士 | 军事服务 | |

**翻译问题（用户提到）**：

- `Stammesherzogtum` = 现代史学对"部族公国"（萨克森、巴伐利亚、施瓦本、法兰克尼亚、洛泰林吉亚）的称呼；`Herzog` 本身是"军队领袖"，不是"部落"。译"部落公国"容易误导，建议正文用"部族公国（Stammesherzogtum）"并注明 Herzog=军事领袖。
- "邦国"更接近 `Land`/`Fürstentum`（领地/侯国）的自治政治体；"大君"在日语里是将军的外称（taikun），汉语"大君"指君主——两者都不是 `Herzog` 的直译。建议：学名用"公国/公爵（Herzog，军事领袖）"，显示层可保留用户偏好的"邦国/大君"，但**数据层 authority=military，institution=stem-duchy**。

## 4. "国王"这个词

- 词根：原始日耳曼 `*kuningaz` ← `*kunją`（亲族、家族）+ `*-ingaz`（属于…的）→ **亲族之长**。
- 同源/借词：
  - 古英语 cyning → king；
  - 古诺斯 konungr → 瑞典 konung；
  - 古高地德语 kuning → 德语 König；
  - 芬兰语 kuningas（借自日耳曼）；
  - 斯拉夫 `*kъnędzь` → 俄语 knyaz（借自日耳曼）；
  - 立陶宛 kunigaikštis（借自斯拉夫/日耳曼）。
- 语义分叉：king（主权君主）、knyaz（宗长/王公）、kuningas（王）——**同一词根，三种制度**。
- 对照：拉丁 rex（治理者）、希腊 basileus（王）、波斯 shah（统治者）、苏美尔 lugal（大人）、汉语 王（斧钺/仪式权威）——"国王"这个译名把不同权力来源压成一格。

## 9. 传播模式（给模拟用）

| 模式 | 例 | 机制 |
|---|---|---|
| 同源继承 | *kuningaz → king / konungr / König / knyaz / kuningas | 语言分化，词根不变 |
| 借词 | Caesar → Kaiser / tsar；Graf → greve；Herzog → hertig | 借入方保留外来制度词 |
| 仿译（calque） | Herzog = dux（军队领袖）；Fürst = princeps（第一） | 用本族词根翻译外来概念 |
| 称号公式 | 王中之王（亚述→波斯→亚美尼亚→埃塞俄比亚）；cakravartin（印度→东南亚） | 公式随帝国/宗教扩散 |
| 翻译/比附 | knyaz→prince/duke/king；jarl→earl；Graf→count；后来"国王/公爵/伯爵"套译 | 译者用本国等级表比附 |
| 法律身份 | 瑞典 frälse（免税贵族） | 贵族=特权身份，不是头衔 |

## 11. 对模型的落点

1. `TitleDefinition` 增 `etymologyOrigin`（原始权力来源）、`currentAuthority`（现行来源栈）、`etymon`（词根/同源组）、`institution`（制度：宫廷/军事/宗族/宗教/选举/行政）、`diffusionType`（同源/借词/仿译/公式/比附）。
2. 删 `rank`；位阶用同域组合偏序 + 跨域礼制/臣属/主权裁决。
3. 头衔传播模拟：以 `etymon` 建同源图，以 `diffusionType` 建传播边；翻译只是显示层映射，不是等级。
4. 译名表按制度来源重标（knyaz=宗长、Herzog=军事领袖、Graf=官长、frälse=免税贵族身份）。
