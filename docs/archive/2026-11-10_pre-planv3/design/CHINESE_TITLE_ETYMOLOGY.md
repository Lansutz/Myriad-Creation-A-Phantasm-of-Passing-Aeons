# 中文头衔的字源与权力来源：王 / 公 / 侯 / 伯 / 子 / 男 / 后

> 2026-11-08。方法：检索字源/古文字/制度史来源（见 §5 引用），结合通行字源学整理；本环境网页全文抓取被 DNS 拦截，只能拿到检索条目，故对争议处标注"一说/有争议"。
> 结论先行：**这七个字的"本义"不是同一种权力**；五等爵是后世对异源头衔的系统化；`后` 则发生了"君主 → 后妃"的权力来源转移——正好证明「词源=原始权力来源，且会变」。

## 0. 一句话表

| 字 | 本义（主流解释） | 原始权力来源 | 后世语义/头衔 | 关键变化 |
|---|---|---|---|---|
| 王 | 斧钺（戉）之形，执钺者 | **军事/仪式权威** | 王、天子 | 军事权威 → 天命/道德王权 |
| 公 | 平分/公共（八+厶）；一说族老/先公 | **宗族/集体/长辈** | 公爵、三公 | 族老/公共权威 → 爵位/最高官 |
| 侯 | 射侯（箭靶）/善射者、斥候 | **军事（射御/边防）** | 诸侯、侯爵 | 军事首领 → 封建爵位 |
| 伯 | 伯仲叔季之长，长子 | **宗族辈分/长老** | 伯爵、方伯 | 族长/长者 → 爵位/霸主 |
| 子 | 婴孩/子嗣 | **血缘/子嗣（王族子弟）** | 子爵、尊称（夫子） | 子嗣/贵族子弟 → 爵位/尊称 |
| 男 | 田+力，力田的男子 | **劳动力/农业/成年男性** | 男爵 | 力田者 → 最低爵位 |
| 后 | 君主/宗主（夏后氏、后羿、后稷）；字形象生育/祖先（一说） | **原始主权（可能带生育/祖灵神圣性）** | 王后、皇后、太后 | **君主 → 后妃**（权力来源整体转移） |

## 1. 逐字

### 王

- 甲骨文/金文多释为**斧钺（戉）之形**：钺是军权与刑杀的象征，"执钺者"即最高权威。林沄等主此说；王仁湘《戉——早期王权的象征》即讨论"钺→王权"。
- 本义：**军事/仪式权威**，不是"道德表率"。
- 后世"三画连中，贯通天地人"（董仲舒）是**哲学化再解释**，不是字源。
- 权力来源变化：军事/祭祀权威 → 天命、道德化王权。

### 公

- 常见解释：八（分）+ 厶（私）→"背私为公"（《韩非子》"自环者谓之厶，背厶谓之公"），本义"公共/平分"。
- 另一路：公作为"先公/族老"的尊称，宗族长辈。
- 权力来源：**宗族/集体/长辈**（不是军事）。
- 后世：五等爵之首"公"、三公（最高官），语义从"公共/族老"转向"爵位/官位"。

### 侯

- 甲骨文象**射侯（箭靶）**或箭与侯形；本义与射箭、善射、斥候（侦察/边防）相关。
- 权力来源：**军事**（射御、边防、斥候）。
- 后世：诸侯（封建领主）→ 侯爵（marquis）。"侯"的军事来源与"公"的宗族来源不同，却同在五等爵里。

### 伯

- 本义：伯仲叔季之"伯"，**长子/长者**；引申为族之长、诸侯之长（方伯/伯主，即"霸"）。
- 权力来源：**宗族辈分/长老**。
- 后世：伯爵（count/earl 的译名）；"方伯"是区域霸主，不是固定爵位。

### 子

- 甲骨文象**幼儿/子嗣**；本义"孩子、子嗣"，引申为贵族子弟、尊称（夫子、孔子）。
- 权力来源：**血缘/子嗣**（王族/贵族之后），或师长尊称。
- 后世：子爵（viscount）是后世的爵位系统化；"子"作为爵名与"儿子"本义已分家。

### 男

- 字形象**田+力**（田间用力），本义"男子/力田者"（成年男性劳动力）。
- 权力来源：**劳动力/农业/成年男性**（也可能指"有田之男"）。
- 后世：男爵（baron）为最低爵位；"男"的农业/劳力本义与爵位无关。

### 后

- 本义：**君主/宗主**。先秦文献中"后"常指君：夏后氏、后羿、后稷（后稷=谷物之神/农官之长）、"后王"；《尚书》"后"多指君。
- 字形一说象**生育/祖先**（与"毓"相关），若成立，则"后"的原始权威带**生育/祖灵神圣性**。
- 关键变化：秦汉以后"后"专指**王后/皇后/太后**；"後（after）"本是另一字，简化字合并为"后"。
- 权力来源：**原始主权（君主/宗主）→ 婚姻/宫廷/母族（后妃）**。这是"词源≠现行权力来源"的最佳例证。

### 附：帝 / 皇

- 帝：甲骨文或象花蒂/燎祭（"蒂"为生命之源），本义"天帝/祖先神"；权力来源：**宗教/宇宙论**。
- 皇：煌/大/光明，形容词性"伟大、光辉"。
- 皇帝 = 皇 + 帝：复合词，权力来源是**神圣/宇宙论主权**，不是"王+1"。

## 2. 五等爵是"异源头衔的后世系统化"

- 公侯伯子男在先秦文献（《孟子》《周礼》）里被列为五等，但**西周到春秋金文未必存在严格的五等阶梯**；现代研究对"周代五等爵"是否成立有长期争议（参见《先秦两汉文献中所见周代诸侯五等爵》）。
- 更合理的看法：公（族老/公共）、侯（军事/射御）、伯（辈分/长老）、子（子嗣）、男（力田）本是**不同权力来源的头衔/称谓**，后世（战国—汉）把它们编排成一条等级阶梯。
- 对模型的意义：**rank 阶梯是后世分类视图，不是机制真源**；机制要回到 authority（原始权力来源）与绑定。

## 3. 对 authority 模型的补充

1. **`etymologyOrigin`（原始权力来源）与 `currentAuthority`（现行权力来源）必须分开存**：
   - `后`：原始=主权；现行=后妃（婚姻/宫廷）。
   - `侯`：原始=军事；现行=封建爵位。
   - `公`：原始=族老/公共；现行=公爵/最高官。
2. `authority` 应是**来源栈**而非单值：原始来源 + 叠加来源（如"军事 + 宗教加冕"）。
3. 原义用于：合法性叙事、称号生成、礼制位次、词典/说明；
   现行来源用于：继承、任命、资格、门禁。
4. 译名按制度来源标注（knyaz=宗长、dux=军事领袖、comes=侍从、emir=指挥官、后=君主/后妃），禁止"译名→rank 数值"。
