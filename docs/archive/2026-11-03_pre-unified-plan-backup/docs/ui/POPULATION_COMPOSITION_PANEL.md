# 人口构成面板（Population Composition Panel）

## 目标
查看一个对象的人口构成：文化、宗教、宗教传统、种族、阶级、阶层、职业。  
地图模式只显示**主流文化/主流宗教/主流传统**；面板展示完整构成。

## 对象与关系
- 标题只显示名称，**不加括号注类型**；类型用独立的小徽标/图标表示，不拼进名字里。
- 所有关口堡/边堡/河口堡/海防堡/河防堡本质上都是 **堡垒**；正文只显示 **堡垒**，关口/河口/边防等用途放详情或悬浮提示，不拼在类型后面。
- 对象切换用**关系**，但要区分两类：
  - **栖居点之间的关系**：`上级` / `下级`，只能出现在栖居点之间；
  - **政权归属**：显示为 `所属：X`，不是“上级”；
  - **政权之间的关系**：不在本面板出现，放到政权面板。
- 面包屑示例：`蓟` / `所属：匽`  
  若还有上级：`蓟` / `上级：某城邑` / `所属：匽`
- 没有关系时显示“独立/无所属”。

## 数据来源
- `SettlementData.composition : PopulationComposition`
- 每条 `PopulationGroup`：`count + raceId + cultureId + faithId + religionTraditionId + economicClass + stratum + occupations`
- `religionTraditionId = -1` 表示未显式细分；由 `ReligionCatalog.ResolveTraditionId(faithId)` 解析主流传统后代。
- 单位也有自己的构成：成员/兵员的文化、信仰、传统、职业；与栖居点共用同一个面板模型。

## 面板结构

```
┌──────────────────────────────────────────────┐
│ 蓟               人口 12,340   ↑2.1%          │
│ 所属：匽   上级：某城邑                           │
├──────────────────────────────────────────────┤
│ [文化] [宗教] [宗教传统] [种族] [阶级] [阶层] [职业] │
├──────────────────────────────────────────────┤
│        ╭──────╮       ● 河谷文化   58.3%      │
│       │ 12,340 │      ● 山地文化   25.1%      │
│        ╰──────╯       ● 商团文化    9.7%      │
│        环图/饼图        ○ 其他       6.8%      │
├──────────────────────────────────────────────┤
│ 主流：河谷文化 · 主流传统：河谷礼制              │
└──────────────────────────────────────────────┘
```

### 头部
- 名称；类型用独立徽标；总人口；可选增长。
- 关系只显示文本，不做嵌套链接/括号。
- 无“锚点/省/政权”切换按钮。

### 分类页签
- 文化、宗教、宗教传统、种族、阶级、阶层、职业。
- 职业可重叠，职业页签百分比**不保证合计 100%**，页脚注明。
- **宗教传统**是宗教系统内部层级（`ReligionNodeType.Tradition` / `ReligionMapLevel.Tradition`），不是文化系统的 `TraditionDef`（文化传统）；UI 文案只写“宗教传统”，不写“传统”以免混淆。
- 解析顺序：先看显式 `religionTraditionId`；没有则用 `ReligionCatalog.ResolveTraditionId(faithId)` 找主流传统后代；再没有则显示“未细分”。

### 图表
- ≤6 类：**环图/饼图** + 图例；中心显示总人口。
- >6 类：环图 + 可滚动条形列表；<1% 合并“其他”，点击展开。
- 点击扇区/行：只筛选地图高亮，不修改数据。
- 地图模式只显示主流值，不做比例混色。

### 单位页
- 单位页增加“构成”页签：
  - 成员/兵员的文化、信仰、传统、职业；
  - 与载具/背包、成员/职务同页；
  - 军队的大规模兵员按兵种/文化/信仰聚合，不为每个人建卡。
- 单位构成与栖居点构成共用 `PopulationCompositionPanelModel`。

## 地图模式联动
- 文化模式：每个 cell 显示**主流文化**颜色。
- 宗教模式：每个 cell 显示**主流宗教**颜色。
- 宗教传统模式：每个 cell 显示**主流传统**颜色（现有 `ReligionTradition` 模式）。
- 点击面板只高亮对应 id 的 cell；其他 cell 变灰。
- 面板不直接写 `TileData`；地图模式只读 composition 聚合。

## 参考 UI 写法
拆包里的《Things That Happen on the Map》是 Godot：
- 每个面板一个独立 UI 脚本（`city_ui.gdc`、`army_ui.gdc`、`culture_panel.gdc` 等），面板逻辑和数据分离；
- 图表用自定义 Control 绘制（`country_history_chart.gdc`），不是把数据塞进通用表格；
- 有 UI smoke runner 做无头验证。

我们可以照这个思路：
- 每个面板一个 Presenter/Model，不把逻辑写进 Renderer；
- 环图用 UI Toolkit 的 `generateVisualContent` 或 uGUI 自定义 `MaskableGraphic` 画扇区；
- 行列表用 `ListView`/池化 ScrollRect；
- 加 EditMode 测试验证行数据、百分比、主流标记；UI 本身用 PlayMode/截图验证。

## 性能
- 聚合只在 composition 版本变化时重算；不每帧遍历。
- 上级/下级聚合只沿关系链取对象，不遍历 524k 地块。
- 环图扇区数上限 8（含“其他”），其余进列表。
