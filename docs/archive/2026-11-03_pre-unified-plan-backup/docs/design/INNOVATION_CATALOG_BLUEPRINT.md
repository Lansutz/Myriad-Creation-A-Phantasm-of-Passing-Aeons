# 革新目录蓝图（V3）：词汇审计后的精确体系

> 用户指出：王国/帝国/城邦制不能当"国家结构"革新（分析术语、用法多）；不能出现"现代/古代"这类词汇；
> 朝贡体系不是革新、也不是东亚独有；社会/文化/宗教/知识一块最笼统；要重新检查所有词汇。
> 本文是对 V2 蓝图的全量词汇审计与重写；本轮大头是革新，法律只保留"模拟有意义"的骨架。
> 核心原则：**不是所有候选都要做成革新**。物产/器物/宽泛活动先分流；只有改变模拟变量或解锁内容的具体能力，才进入革新目录。

---

## 1. 五条硬规则

1. **革新 = 可迁移的一般概念**（Idea/Technique/Institution/Practice/Knowledge），不是历史专名、不是政体标签、不是时期标签。
2. **禁止把"国家/政体/结构的分析术语"当革新**：
   - `王国`、`帝国`、`城邦`、`城邦制`、`共和制`、`君主制`、`神权政治`、`封建`、`官僚帝国`、`民族国家`、`单一制`、`联邦制`、`邦联` 等属于 **`PolityForm` / `StateStructure` 描述维度**，由具体制度/法律组合决定，不是研究节点。
   - `中央集权/中央集权化` 是过程/程度，不是条目；其制度侧用具体安排（中央与地方权限、地方自治、行政区划）表达。
3. **禁止历史专名作为革新**：`罗马公民权`、`雅典民主/雅典公民大会`、`科举`、`郡县制`、`行省制`、`十二铜表法` 等放到 **`InnovationVariant`（内容变体）**；`variantOf` 指向一般概念，带 region/cultureTags；变体不是研究节点，不能作为通用革新的前置。
4. **禁止"回溯性分析标签"，但允许现代具体概念**：
   - 禁止的是**后世观察者回溯分类**的标签：`王国/帝国/城邦/封建/朝贡体系/官僚帝国/神权政治/共和制/君主制` 等（这些不是当时行动者的具体制度，而是分析范畴）。
   - **现代的具体制度/技术/思想可以作为革新**：`铁路`、`电报`、`蒸汽机`、`工厂`、`股份公司`、`中央银行`、`公共教育`、`公共卫生`、`职业文官制`、`成文宪法`、`权利法案`、`政党`、`普选权`、`普遍公民权`、`民族主义`、`机械印刷`、`出版市场`、`报纸`、`社会保险`、`劳动法`、`民法典`、`公司法` 等。
   - 但仍不把**国家结构分类标签**（`单一制/联邦制/民族国家`）当革新：它们是 `StateStructure/PolityForm` 描述维度，由具体宪法/制度组合决定。
   - 也不在名称前加"现代/古代"作修饰（直接写概念名：`职业文官制` 而非"现代文官制"）。
5. **禁止伞形/模糊词**：`官僚制度`、`印刷术`、`公民权`、`边界概念`、`朝贡体系`、`社会/文化/宗教/知识`（作为单一条目）都不能当可研究条目；必须拆到具体实践/制度/技术。

## 2. 分类模型

```text
InnovationCategory（伞形分类，不可研究）
  └─ Innovation（可研究条目）
       ├─ kind: Idea / Technique / Institution / Practice / Knowledge
       ├─ field: 26 个 InnovationField（保留）
       ├─ subfield: 域内子类
       ├─ era: 0..5
       ├─ termEn / definition / scope / sources
       ├─ prerequisites + prerequisiteRationale
       ├─ prerequisitesAny（真实替代路径）
       ├─ unlocks（UnlockRule：阶层/身份/职业/文化特质/教义/建筑/政体/法律/货币/命名 pattern）
       ├─ regions/cultureTags
       └─ legacyIds
```

**政体/结构是"描述维度"，不是革新：**

```text
PolityForm（描述性标签，运行时推断/展示）
  ├─ 由 LawComposition 的制度组合决定：最高权力归属、继承、中央机构、地方权限、领土结构…
  ├─ 例：城邦/王国/帝国/共和/神权/游牧 等只是"分析/展示标签"
  └─ 不进入革新目录
StateStructure（描述性维度）
  ├─ 中央-地方权限、地方自治、代表机构、成文宪法、国界线…
  └─ 由具体法律/制度组合决定，不设"单一制/联邦制"革新节点
```

## 3.5 研究依据与分组重构（旧 26 字段的问题）

### 3.5.1 研究来源

- **HRAF《Outline of Cultural Materials》（OCM，7th ed. draft 2025）**：人类学/跨文化比较的**两级主题分类**（物质文化、生计、食物、纺织、建筑、能源、机器、工具、财产、交换、金融、劳动、交通、通信、聚落、政府、法律、军事、战争、健康、宗教、社会分层、婚姻家庭、教育、艺术等）。
  - 用途：只作为**主题覆盖与层级设计的参考**；OCM 的名称/编号受 HRAF 版权约束，本项目**不复制其词表/编号**，领域名自拟、独立实现。
  - 参考：https://hraf.yale.edu/resources/reference/outline-of-cultural-materials/ （OCM 介绍）；https://hraf.yale.edu/wp-content/uploads/2026/03/ocm-2025.pdf （7th ed. draft 2025，仅研究参考）
- **OECD/Eurostat《Oslo Manual》(2005)**：把创新分为 **product / process / organizational / marketing** 四类；本项目映射为：
  - product/process → `Technique`（技术/工艺）
  - organizational → `Institution`（组织/制度）
  - marketing/business practices → `Practice`（做法/惯例）
  - 另加 `Idea`（思想/学说）与 `Knowledge`（知识门类），因为历史创新不全是企业创新。
  - 参考：OECD/Eurostat, *Oslo Manual: Guidelines for Collecting and Interpreting Innovation Data*, 3rd ed. (2005), https://ec.europa.eu/eurostat/documents/3888793/5838637/KS-73-05-598-EN.PDF.pdf/3d66d924-58df-44d7-94a2-941939c287f9

### 3.5.2 旧 26 个 `InnovationField` 的问题

1. **混轴**：`Agriculture/Transport/...` 是领域；`Bureaucracy` 是治理的子域；`Philosophy/Ritual` 是知识/实践类型；`Script` 是信息载体——不在同一层级。
2. **重叠**：`Governance` vs `Bureaucracy` vs `Law`；`MilitaryThought` vs `MilitaryInstitution`；`Craft` vs `Machinery` vs `Metallurgy` vs `Construction` vs `Mining`；`Script` vs `Mathematics` vs `Philosophy` vs `Education` vs `Theology`。
3. **缺域**：食物加工/储藏、能源/公用、建筑/聚落、通信/档案、外部关系、艺术/娱乐等没有独立位置。
4. **结论**：`InnovationField` 只保留为 **legacy 字段**（迁移/测试兼容），不再作为主分组；改用 `InnovationDomain + Subdomain + Kind + Scale`。

```text
            └─ scale: Household / Community / Polity / InterPolity
```

## 3.6 粒度准则：先分"物产/器物/活动/能力"，再决定要不要做

> 用户指出："采集"太笼统；"木炭"是物产；"夯土"只是一个具体物品。对。**不是所有候选都要做成革新**；
> 先做类型判定，再决定放 `GoodsDef`、`BuildingDef`、`EquipmentDef`、`Innovation`，还是直接不做。

### 3.6.1 判定树

1. **可储存/可交易的实物/材料**（木炭、纸、陶器、玻璃、瓷器、铁、钢、火药、夯土材料…）→ **`GoodsDef`（物产）**，不是革新。
2. **单个器物/设施/建筑**（弓、弩、水磨、风车、帆船、城堡、道路、桥梁…）→ **`Equipment/Building/Infrastructure` 内容**；革新是**制作/使用它的技术或制度**（`弓箭制作`、`水力磨粉`、`帆装`、`碎石路面`、`石拱桥`）。
3. **宽泛活动/大类**（采集、农业、畜牧、渔猎、贸易、战争…）→ **Capability/Subdomain（能力/子域）**，必须拆到"方法/资源/生态"层面的具体做法，且每种做法有不同模拟效果。
4. **具体做法/技术/制度/思想**，能改变至少一个模拟变量或解锁一个内容 → **Innovation**。
5. 若拆分后没有独立模拟效果（只是同一种做法的换名/地区小差异）→ **Variant** 或干脆不做。

### 3.6.2 例子（按用户点名的三个）

| 候选 | 是什么 | 处理 |
|---|---|---|
| **采集** | 宽泛活动 | 拆成 `块根采集`、`坚果与种子采集`、`贝类采集`、`蜂蜜采集`、`海藻采集`（按食物类型/季节/工具区分）；只有模拟饮食/季节/储藏时才保留 |
| **木炭** | 物产（可储存/交易） | 进 `GoodsDef`；若要表现"烧炭"这一能力，革新叫 **`炭窑烧制`**（技术），而不是"木炭" |
| **夯土** | 材料/具体物品 | 进 `GoodsDef`/材料表；革新叫 **`夯土版筑`**（技术/做法），而不是"夯土" |

### 3.6.3 更多同规则例子

| 候选 | 是什么 | 处理 |
|---|---|---|
| 陶器 | 物产 | `GoodsDef`；革新 `陶器烧制`、`陶轮`、`釉` |
| 玻璃/瓷器 | 物产 | `GoodsDef`；革新 `玻璃制造`、`瓷器烧制` |
| 纸 | 物产 | `GoodsDef`；革新 `造纸` |
| 铁/钢/青铜 | 物产 | `GoodsDef`；革新 `块炼铁冶炼`、`生铁高炉`、`坩埚钢`、`渗碳淬火` |
| 火药 | 物产 | `GoodsDef`；革新 `火药配制` |
| 弓箭 | 器物 | `EquipmentDef`；革新 `弓箭制作`（技术）、`弓术`（做法） |
| 水磨/风车 | 器物/设施 | `BuildingDef`；革新 `水力磨粉`、`风力磨粉` |
| 帆船 | 器物 | `EquipmentDef`；革新 `造船`、`帆装` |
| 道路/桥梁/运河 | 基础设施 | `BuildingDef`/地图设施；革新 `碎石路面`/`铺石路面`、`石拱桥`/`木梁桥`、`运河开凿` |
| 夯土/土坯/砖石 | 材料 | `GoodsDef`/材料表；革新 `夯土版筑`、`土坯砌筑`、`砖石砌筑` |
| 采集/农业/畜牧/渔猎 | 宽泛活动 | Capability/Subdomain；拆到具体做法（如 `块根采集`、`谷物种植`、`山羊驯化`、`围网捕鱼`） |

### 3.6.4 结论：不是"全部都要好好做"，而是"能力优先"

- 先列**模拟里真实存在的变量/系统**（食物、物产、建筑、运输、军事、行政、法律、信仰、身份、知识…），
  再倒推"哪些能力会改变它们"；每条能力必须有 `unlocks` 或效果落点，否则不做。
- 预计首批 **150–250 条有明确模拟效果的革新**；不是 300–400 条百科式清单。后续只在新增系统需要时扩。
- `GoodsDef` 增加 `unlockedByInnovationId`/`requiredInnovationId`，把"物产出现"和"能力出现"分开。

### 3.6.5 现有目录对照（新增前必须查重）

已把候选池与现有 **185 条**逐类比对，发现不少重复/粒度问题，详见 [INNOVATION_DEDUPE_AUDIT.md](INNOVATION_DEDUPE_AUDIT.md)。典型：

- **道路**：现有 `808 硬质道路`，不能再加"道路铺设"；拆成 `夯土道路/碎石路面/铺石路面/木栈道/堤道`。

- **材料**：`石灰石/大理石/混凝土/砖/瓦/水泥` 是物产；革新是 `石灰烧制/石灰砂浆配制/大理石开采/石材切割/混凝土配制/制砖/制瓦/水泥烧制`。
- **器物/设施**：`水磨/风车/帆船/轮车/弩/火器/攻城器械/战车/船型` 等现有条目本质是器物；需迁移到 `BuildingDef/EquipmentDef`，革新改为工艺/做法（如 `水力磨粉`、`帆装`、`弩机制作`、`火器制造`）。
- **系统落点**：城墙是 `SettlementBlockKind.Wall` + `FortificationLevel` 0–15（5 tier × 材质工艺 1–3）+ `WallMaterial`（Palisade/Earth/Stone/Brick）+ `WallLayout`/横向段/层（1–3），一个聚落可有多个城墙块，不是"城墙建造"；战车 1013 已是双马战车、单位 210，四马需另加单位/条目；酿酒 913 是谷物酒但无物产/配方/效果，需补 `酒` 物产或先不做。详见 [INNOVATION_DEDUPE_AUDIT.md](INNOVATION_DEDUPE_AUDIT.md) §8。
- 同名/近义条目**一律复用现有 ID**（如 106 水磨、200 陶器制作、205 造纸术、206 印刷术、207 火药、304 弩、305 攻城器械、306 城堡建筑、307 火器、403 罗盘、401 帆船、800 夯土筑城、801 拱券技术、807 轮车、808 硬质道路、823 驿传邮驿、907 弓箭、924 马镫、935 玻璃制造、936 瓷器、963 石叶技术、966 岩画、974 养蚕、976 漆器、977 玉石、988 机械钟、989 风车、990 星盘、1007 撞角战术、1009 皮革加工、1013 战车），不新增重复 ID。

## 6. `InnovationVariant`（历史专名的正确位置）

```json
{
  "variantId": "roman_citizenship",
  "variantOf": 1106,
  "name": "罗马公民权",
  "termEn": "civitas Romana",
  "regions": ["mediterranean"],
  "cultureTags": ["roman", "latin"],
  "definition": "罗马共同体的法律身份与特权（通婚/贸易/上诉等），可授予行省居民；不是普遍公民权。",
  "effectsDelta": { "citizenshipInclusion": 0.1, "legalPrivilege": 0.2 },
  "prerequisites": [],
  "sources": ["Roman law; Constitutio Antoniniana 212 CE"]
}
```

规则：
- 变体不能作为通用革新的前置；只能在匹配 region/culture 的路径中替代/细化一般条目；
- 变体不改变一般概念的定义；
- 旧档中历史专名条目迁移为 `variantId`，不占革新节点。

## 7. 前置模型与审查

```json
{
  "prerequisites": [1101, 1110, 1103],
  "prerequisitesAny": [],
  "prerequisiteRationale": {
    "1101": "没有国界线，无法想象主权领土边界",
    "1110": "没有机械印刷出版，无法形成跨地域共同体",
    "1103": "没有普遍公民权，民族成员无法成为政治共同体成员"
  },
  "unlocks": ["ideology:nationalism", "polityForm:nationState"],
  "regions": ["europe", "east_asia"],
  "cultureTags": ["modernity"],
  "legacyIds": [1017]
}
```

审查规则：
- 前置存在、无环、`era ≤` 本条目；
- 前置不得是伞形词/过程词/政体标签/历史专名；
- `prerequisitesAny` 至少 2 项且同 kind/层级；
- 每条前置必须有 rationale；
- `unlocks` 落到具体系统；
- 区域变体不得用全球普适前置（如"奇普统计"不能给全球官僚制当前置）。

## 8. 迁移与实施

### 8.1 旧 185 条迁移

1. 保留 ID；`legacyIds` 记录旧语义；伞形词降 `InnovationCategory`；历史专名转 `InnovationVariant`；政体标签移出革新目录。
2. 改名/拆分优先：所有 `*术`（12）、`*制度`（9）、`中央集权/官僚/印刷/边界/公民权` 等。
3. 补字段：`termEn/definition/kind/category/prerequisiteRationale/unlocks/sources`；185 条先全量补定义。
4. 新增条目：按 §4 各域补到 300–400（目标 350–500），区域变体内容层最后补。

### 8.2 阶段

| 阶段 | 内容 | 验收 |
|---|---|---|
| I0 | Schema + 校验 + 185 条迁移（字段/改名/legacyIds/variant）+ 去重（复用/拆分/转物产） | `InnovationSchemaTests/PrecisionTests/MigrationTests`；去重审计通过 |
| I1 | 政治/宪制/民族主义簇（国界线/机械印刷出版/普遍公民权/常任文官制/考试选官等） | `NationalismGateTests`；旧档迁移 |
| I2 | 行政/军事/经济/书写/宗教/艺术/社会各域补到 150–250；区域变体 | `InnovationContentSizeTests`（能力优先，不以数量为目标） |
| I3 | `UnlockRule` 接阶层/身份/职业/文化/宗教/法律 | 正反向门槛测试 |
| I4 | 法律只接骨架（W18 缩窄版） | 法律测试 + UI |

### 8.3 测试

- `InnovationSchemaTests`：字段/ID/前置存在/无环/era。
- `InnovationPrecisionTests`：禁词（`*术`/`*思想`/伞形制度/中央集权/官僚制度/印刷术/边界概念/公民权泛称/政体标签/时期标签）不得作可研究条目。
- `InnovationPrerequisiteTests`：rationale、`any` 同层、无伞形/历史专名前置。
- `NationalismGateTests`：1017 需国界线+机械印刷出版+普遍公民权；缺一不可。
- `InnovationContentSizeTests`：数量/域/era/区域变体。
- `InnovationMigrationTests`：旧 ID→新/变体不丢进度。
