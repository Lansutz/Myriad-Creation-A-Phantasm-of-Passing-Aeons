# 地图编辑器规范

本文定义高度图地图编辑器的基础笔刷、程序化岛屿生成器、编辑历史、派生数据重算，以及海洋连通模型。除非特别说明，格子均指六边形或方格网中的一个**边相邻**单元；顶点接触不构成相邻。

## 1. 数据与派生状态

每个格子保存可编辑的 `elevation`（高程）。系统由当前海平面 `seaLevel` 推导 `isLand`，并维护脏区集合 `dirty`。一次编辑不得直接修改坡度、气候、群系、通行成本等派生结果；这些数据只能由统一重算产生。

### 1.1 脏区

每个脏区记录最小包围范围以及待处理阶段：`height`、`slope`、`climate`、`biome`、`cost`、`oceanConnectivity`。编辑高度后，应将受影响格和各阶段所需的邻域加入对应脏区；相邻或重叠脏区应合并。未重算的格子可以显示“待更新”标识，但不能把旧的派生值当作新的结果写回存档。

### 1.2 固定的派生重算顺序

所有会改变高程的工具均遵守以下顺序（后文的“标准顺序”均指此序列）：

1. **修改高程**：收集本次操作的旧/新 `elevation`，并只写入确有变化的格子。
2. **标记脏区**：标记高度变化区域及依赖它的邻域；若 `isLand` 可能翻转，则标记海洋连通性检查。
3. **重算坡度**：从新高程计算坡度、坡向及相关地形分类输入。
4. **重算气候**：基于高程、坡度和海陆/海岸状态更新温度、降水等气候场。
5. **重算群系**：使用最新坡度和气候选择群系。
6. **重算通行成本**：使用最新坡度、群系、海陆状态和海洋层级计算移动成本。

海洋连通性是海陆状态的前置派生数据：在第 2 步发现边界可能变化时，必须先完成第 3 节的局部连通性维护，再执行第 3～6 步。这样气候、群系和通行成本始终读取同一版本的海岸和海洋层级。

## 2. 编辑工具

### 2.1 基础笔刷

笔刷以中心、半径、强度和衰减曲线为参数。一次拖拽从按下到松开构成一个原子操作；拖拽经过的采样点合并为同一组高度变更，避免每个采样点分别进入历史记录。

| 工具 | 高程修改 | 脏区标记 | 坡度/气候/群系/通行成本重算 |
| --- | --- | --- | --- |
| 抬升 | 对覆盖格按衰减权重增加 `elevation`，并裁剪到地图允许范围。 | 标记实际改变的格及坡度、气候和群系依赖邻域；跨越 `seaLevel` 的格同时标记 `oceanConnectivity`。 | 标准顺序：先坡度，后气候、群系，最后通行成本。 |
| 降低 | 对覆盖格按衰减权重减少 `elevation`，并裁剪到地图允许范围。 | 同抬升；由陆变海时必须标记海洋连通性。 | 标准顺序：先坡度，后气候、群系，最后通行成本。 |
| 平滑 | 使用操作开始时的快照求邻域加权平均，并以强度向该平均值插值；不得按扫描顺序就地读取，以免方向偏差。 | 标记值实际改变的格和依赖邻域；每个跨海平面格标记连通性。 | 标准顺序：先坡度，后气候、群系，最后通行成本。 |
| 陡崖 | 在笔刷方向或指定断层线两侧施加相反高程偏移，形成受最大落差限制的阶跃；断层带内可做窄幅过渡。 | 标记阶跃两侧、断层带和依赖邻域；任何海陆翻转标记连通性。 | 标准顺序：先坡度，后气候、群系，最后通行成本。 |

### 2.2 陨坑群岛生成器

生成器在指定中心与半径内使用确定性种子生成多个相交或分离的环形岛：为每个陨坑叠加外缘正高度、内碗负高度及噪声，保留低于海平面的坑底和岛间水道。参数至少包括种子、岛屿数量、陨坑半径范围、外缘高度、坑深、噪声幅度和海平面偏移；同一参数和输入地图必须生成相同结果。

1. **高程修改**：先在临时高度场合成全部陨坑，再一次性写回生成区域，不能逐个陨坑触发派生重算。
2. **脏区标记**：标记生成区域、其依赖邻域，以及全部跨越 `seaLevel` 的格的 `oceanConnectivity`。
3. **重算**：完成局部海洋连通性维护后，按标准顺序重算坡度、气候、群系、通行成本。

### 2.3 火山群岛生成器

生成器在指定范围内按确定性种子布置火山锥、破火山口、熔岩脊和岛间浅海。参数至少包括种子、火山数量、锥体半径/高度范围、火山口半径/深度、熔岩流长度、粗糙度和海平面偏移。火山口可低于海平面形成内湾，但应保留可配置的火山环缺口以形成水道。

1. **高程修改**：在临时高度场叠加锥体、火山口和熔岩脊后，一次性提交实际变化的格。
2. **脏区标记**：标记生成区域、依赖邻域和所有海陆翻转格的 `oceanConnectivity`。
3. **重算**：先维护局部海洋连通性，再按标准顺序重算坡度、气候、群系、通行成本。

## 3. 海洋模型

### 3.1 格子字段

每格维护以下字段：

| 字段 | 定义 |
| --- | --- |
| `isLand` | `elevation > seaLevel` 时为 `true`，否则为 `false`。等于海平面的格视为海格。 |
| `isCoast` | 陆格且至少有一个边相邻海格时为 `true`；海格不使用此标记。 |
| `oceanTier` | 海格的 `Coast`、`NearSea` 或 `DeepSea`；陆格为 `None`。 |
| `oceanDepth01` | 海格的归一化水深，`clamp((seaLevel - elevation) / maxOceanDepth, 0, 1)`；陆格为 `0`。 |
| `seaConnectId` | 海格所属边相邻海洋连通片的稳定标识；陆格为 `null`。 |

### 3.2 Coast、NearSea 与 DeepSea 判定

* `Coast`：任意边相邻格为陆地的海格。
* `NearSea`：不是 `Coast`，且到任意 `Coast` 海格的边相邻最短距离不超过 `nearSeaWidth` 的海格。
* `DeepSea`：其余海格，即非 `Coast` 且距离海岸超过 `nearSeaWidth` 的海格。

层级计算应先以所有 `Coast` 海格为源做多源 BFS，再依距离分类；不以欧氏距离替代路径距离。陆地完全阻隔 BFS：搜索不能穿越陆格。海洋连通性也只认可边相邻海格，斜角或顶点接触的海格不连通。

### 3.3 连通性增量维护

连通性校验仅在一条海陆边界实际改变时触发：纯陆地高度变化、纯海床深浅变化，以及不改变任何格 `isLand` 的编辑，不做连通性校验。触发时只处理变化格及其边相邻格涉及的旧/新海洋连通片，随后为受影响片重算 `seaConnectId` 和海洋层级。

* **陆转海（`isLand: true → false`）**：将新海格与所有边相邻海格的连通片合并；新格没有海邻居时创建新片。合并后为合并片选择规范 `seaConnectId`（例如最小既有 ID，或新分配 ID），并重算该片的层级。
* **海转陆（`isLand: false → true`）**：移除该海格，检查它原连通片中剩余的边相邻海格。以这些海邻居为起点进行 BFS；若发现多个互不可达分组，为每个分组分配或保留独立 `seaConnectId`，即完成连通片拆分，再重算各分组层级。
* **多格批量变更**：以本次操作结束后的海陆图为准，将所有翻转格及其受影响旧片合并为一个检查任务，避免按格顺序先合并后拆分造成暂态 ID 或重复扫描。

### 3.4 全局重算边界

下列参数变化不能安全地局部更新，必须把整张地图标为脏区并全局重算 `isLand`、`isCoast`、`oceanDepth01`、`seaConnectId`、`oceanTier`，随后按标准顺序重算坡度、气候、群系和通行成本：

* `seaLevel`（海平面）；
* `nearSeaWidth`（外海缓冲宽度，决定 `NearSea` 与 `DeepSea` 的分界）；
* `maxOceanDepth`（影响 `oceanDepth01` 的归一化上限）。

## 4. 操作栈、撤销与重做

操作栈保存已提交操作，重做栈保存被撤销操作。一个操作包含工具类型与参数、编辑前后的格子高度差异（或可重放的确定性生成器输入）、海平面相关参数差异，以及受影响范围。生成器优先保存种子和参数，同时保存最终高度差异作为版本兼容的回退结果。

* **提交**：完成一次原子操作后，将其压入操作栈并清空重做栈；空变更不创建历史项。
* **撤销**：从操作栈取出最后一项，恢复其编辑前高度/参数，压入重做栈，并按该项影响范围执行脏区标记和标准顺序重算；若恢复了全局参数，则走全局重算。
* **重做**：从重做栈取出最后一项，恢复其编辑后高度/参数，压回操作栈，并使用与提交相同的脏区和重算规则。
* **一致性**：撤销和重做不直接恢复缓存的坡度、气候、群系或通行成本；它们必须从恢复后的源数据重新推导，保证与正常编辑结果一致。

## 5. 批量绘制与重算锁

批量绘制（拖拽笔刷、生成器预览确认、脚本导入或多选编辑）开始时自动获取可重入的重算锁。锁持有期间只允许写入源高程、合并脏区、记录海陆翻转和累积操作差异；禁止执行局部或全局派生重算，也不得向渲染/寻路系统发布半完成缓存。

批量结束时释放最后一层锁并执行一次统一刷新：先对累计的海陆边界变更做连通性校验，再按照标准顺序处理合并后的脏区。若批量被取消，应回滚其暂存变更并丢弃脏区，不产生历史项。异常退出时也必须以 `finally` 等等价机制释放锁；导入模块本身不得用 `try/catch` 包裹导入语句。

编辑器提供“**手动统一重算**”命令，用于外部数据修改、调试或发现缓存不一致时。该命令在当前批量锁释放后运行；它忽略局部脏区并执行第 3.4 节的全局范围重算，结束后清空所有脏标记。手动重算是派生缓存修复操作，不创建高度编辑历史项。
