# 地图编辑器：高度图格式与导入导出

本说明定义地图编辑器的高度图交换格式、导入处理顺序与导出约定。所有高度图解码器都**必须**输出数值位于 `0..1`（含边界）的浮点高程数组；后续网格生成不得依赖某一源格式的原始整数精度。

## 支持的导入编码

导入器仅支持 PNG 文件，并且只能使用下列三种编码之一：

| 编码 | 输入像素 | 解码结果 |
| --- | --- | --- |
| 8 位单通道灰度 | 每像素一个 8 位灰度值 `Y` | `height = Y / 255` |
| 仅红通道 RGB | RGB 像素的红通道 `R`；`G`、`B` 不参与解释 | `height = R / 255` |
| RGB24 打包 | RGB 像素的三个 8 位通道 | `height = (R + G × 256 + B × 65536) / 16777215` |

RGB24 的未归一化高度值解码公式为：

```text
R + G×256 + B×65536
```

其中 `R`、`G`、`B` 均为 `0..255` 的整数。实现必须在解码后归一化为 `0..1` 的浮点值，并在必要时将结果钳制到该范围内。

## 导入流程

按以下顺序处理导入的高度图：

1. **编码选择：**用户选择 8 位灰度、仅红通道 RGB 或 RGB24 打包；编辑器据此解码为 `0..1` 浮点高程数组。
2. **精度模式：**选择与目标地图一致的编辑/量化精度；该步骤处理已归一化的高程，而非重新解释 PNG 通道。
3. **反转与垂直翻转：**按用户选项执行高程反转（`h = 1 - h`）和垂直翻转（上下行交换）。
4. **重采样：**将高度数组重采样至目标地图的宽度与高度。
5. **高斯平滑：**如果启用，对重采样后的数组应用指定参数的高斯平滑。
6. **网格映射：**将最终的 `0..1` 高程映射到地图网格的水平坐标和有效高度范围，生成或更新地形网格。

## 导出规则

- 默认导出为 **8 位单通道灰度 PNG**。
- 可选导出为 **RGB24 打包 PNG**；其通道顺序和数值权重必须与导入公式一致。
- 导出范围可选择**全图**或当前**框选范围**。
- 支持自定义高度裁剪：先将选定高度区间裁剪到其边界，再重新映射到导出所需的 `0..1` 范围。
- 文件名必须采用 `mapname_height_v版本号.png` 规则；其中 `mapname` 为地图名，`版本号` 为导出版本标识。例如：`island_height_v2.png`。

## 模组扩展点（当前不支持）

下列格式或通道解释不属于核心导入器支持范围，明确保留给模组扩展：

- HSL 编码；
- 蓝通道高度编码；
- RGBA 浮点格式。

模组若实现这些扩展，应在进入核心导入流程前将数据转换为 `0..1` 浮点高程数组，并遵循本文定义的后续处理顺序。
