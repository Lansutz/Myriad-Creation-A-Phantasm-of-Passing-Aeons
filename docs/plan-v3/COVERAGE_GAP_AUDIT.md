# 覆盖缺口审计：还有哪些系统没被覆盖

> 2026-11-09 19:10。方法：把总纲 S1–S18 与"一个前现代历史模拟器必须有的机制"对账，只记**证据能指到的缺口**；猜的标"未验证"。

---

## 1. 已经存在但只做了一半的（不是缺口，是死端）

| 东西 | 现状证据 | 缺的那半 |
|---|---|---|
| 道路 | `RoadLevel` 枚举 + `TileData.roadLevel` + 建筑 300–303 + 影响移动/影响范围（`MilitaryMovementSystem.cs:278`、`SettlementInfluenceSystem.cs:250`、`BarrierSystem.cs:86-91`） | 谁修路？`BuildBuilding` 有、`ConstructionPlanSystem` 有执行器，但**谁发起**未验证；道路的维护/衰减无 |
| 疾病 | `DiseaseSystem`（R0/感染/死亡/恢复，按地块）+ `CharacterDiseaseSystem`（32 种人物病） | **跨地块传播**（商路/军队/朝圣）未验证；城市密度影响未验证 |
| 建筑 | 29 座硬编码 + `BuildBuilding` + `ApplyBuildingEffects` | 玩家/AI 发起路径；建筑升级/拆除 |
| 货币 | `CurrencySystem` | 成色、贬值、货币替代 |
| 人物知识 | `CharacterKnowledgeRegistry`（按政权记"认识哪些人物"，入档） | 只覆盖**人物**，不覆盖地方/事件/他国动向 |
| 计划 | `PlanType` 10 类含 `Exploration` | 执行器只有 2 个（研究/建设） |

## 2. 真正的缺口（按"历史模拟是否必需"排序）

### P0：不做就解释不了历史

| 候选系统 | 现状 | 为什么必需 | 归属 |
|---|---|---|---|
| **军事后勤与补给**（粮道、就地征发、冬营、士气） | 军队创建本身无生产者（`CreateArmy` 零产品调用）；无补给线 | 战争现在跑在空集上；没有后勤，"为什么远征会失败"无法产生 | M7 前置 |
| **信息传播**（消息速度、传闻、情报、地图知识） | 只有诏令信使（`CourierAI`）；人物知识有、地理/事件知识没有 | 多视角模拟的核心是"谁知道什么"；没有它，命令延迟、误判、谣言都不存在 | M6 |
| **价格与物价水平** | 货物只有 `baseValue`（静态）；`DynamicGoodsRegistry` 由投入反推 baseValue | 无价格波动 → 无饥荒的价格信号、无通胀、无贸易套利；"物价革命"这类历史事件无法发生 | M3 |

### P1：影响多个已有系统

| 候选系统 | 现状 | 为什么必需 | 归属 |
|---|---|---|---|
| **司法与犯罪** | 案件→审判→判决链空转（D 域）；无犯罪率、无庇护所 | 法律系统做了一半，另一半（执法）没有；"庇护权"是教会/城市特许权的核心 | M5 |
| **识字与教育** | 无 literacy 字段 | 识字率决定：官僚效率、法律文本传播、宗教经典解释权、革新吸收速度 | M6 |
| **劳动力与租佃**（工资、地租、佃租形式） | 只有 `SocialSubclass`（Tenant/Serf/HiredLaborer），无租金/工资 | 阶级四维要落到"收入从哪来"；没有它，阶层只是标签 | M4 |
| **债务与信贷**（借贷、利息、违约） | 只有 `DebtSlave` 一个社会子类；无借贷 | 战争财政、商人资本、农民破产都靠它；也是"债务奴"的成因 | M4 后段 |

### P2：可延后

| 候选系统 | 现状 | 说明 |
|---|---|---|
| 长期气候变化（小冰期级） | 有季节与年际波动，无百年尺度趋势 | 布罗代尔长时段的一部分，但可用参数近似 |
| 人口结构（年龄/性别/婚姻市场） | 人口是标量块 | 影响继承、兵源、婚配；工作量中等 |
| 语言接触与翻译 | 有 `Language` 内容与 `parentLanguageId` | 只有谱系，无"接触/借词/双语"机制 |
| 情报与间谍 | 无 | 可先并入"信息传播" |

## 3. 三个便宜但有高回报的接法

1. **道路 → 后勤 → 战争**：道路数据与移动影响都在，只要给军队加"补给来自后方节点 + 道路容量"，M7 就能从"空集战争"变成可解释的战争。
2. **疾病 → 商路 → 城市密度**：`DiseaseSystem` 已按地块建模，接上贸易路线与人口密度，黑死病式的传播就自然出现（不需要新系统）。
3. **人物知识 → 地理知识 → 命令延迟**：把 `CharacterKnowledgeRegistry` 从"人物"扩到"地方/事件"，信息传播就有了载体，且能复用现有的信使通道。

## 4. 明确不做（控制范围）

- **不做**独立"科技树 UI / 时代解锁"——Era 只作 AI 偏好（已否决）。
- **不做**全局"文明等级"——用可观察状态替代（已否决）。
- **不做**独立的"外交 AI 大脑"——外交走 `Plan` + 关系层。
- **不做**海战独立系统——先并入 S8（海军目前无生产者）。

## 5. 结论

- 总纲的 18 组系统里，**缺的是三类"连接组织"**：信息（谁知道什么）、后勤（东西怎么到前线）、价格（稀缺如何表达）。这三类不做，已有系统会互相看不见。
- 司法/识字/租佃是"已有系统的另一半"，不是新领域——它们让法律、教育、阶级真正闭环。
- 建议排序：**M0.5 之后先补信息与后勤（P0），再补司法与识字（P1）**；价格可以并进 M3 的经济闭环。
