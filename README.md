# Myriad Creation: A Phantasm of Passing Aeons
## 纷繁的世界：一场流逝的幻景

一款基于学术研究的大战略文明模拟游戏。以唯物史观、布罗代尔三时段理论、人类学、技术史、反辉格史观、地理历史学、历史政治学等研究为理论基础，模拟文明从游群到帝国的完整演进过程。

## 学术基础

### 史学理论
- **唯物史观** — 生产力与生产关系的矛盾运动推动社会变革
- **布罗代尔三时段** — 长时段（地理/生态）、中时段（经济/社会周期）、短时段（事件/人物）
- **反辉格史观** — 避免以今度古，尊重历史语境的复杂性
- **历史政治学** — 国家形成、制度变迁、权力结构的历史分析

### 社会科学
- **人类学** — 亲属制度、仪式、象征、文化相对主义
- **地理历史学** — 地理环境对历史进程的塑造与限制
- **技术史** — 技术演进的路径依赖、偶然性与社会嵌入
- **年鉴学派** — 总体史、问题史学、跨学科方法

## 核心设计理念

### 文明演进的多路径
不预设"进步"的线性叙事。文明可以通过定居农业、游牧征服、贸易控制、宗教统一、军事联盟等多条路径形成国家。同一文化阶段可以有不同的移动模式（定居/半定居/游牧）和经济基础。

### 地理决定论与能动性的平衡
地理条件决定物产与初始可能性，但不决定最终命运。物产→革新→路径依赖，历史充满偶然性与天才人物的突破。

### 社会分层的渐进性
从平等的游群，到氏族部落，到酋邦的初步分层，到国家的完整阶级结构。每个阶层的出现都需要特定的革新与社会条件。

### 行国与城国
定居政权（城国）与游牧政权（行国）是两种根本不同的国家形态。行国没有固定边界，以活动范围和移动王庭为特征；城国以固定城市和官僚体系为基础。两者可以互相转化。

## 游戏系统

### 塑造你的世界

每一局游戏都从一个独一无二的世界开始。调整海平面、大陆形态和气候剧烈程度，生成由山脉、河流、草原和沙漠编织而成的地图。世界不是空白的画布——大河沿岸孕育冲积平原，山脉阻挡水汽形成雨影，河口三角洲天然适合建城。地理决定了文明的起点，但不决定它的终点。

### 统治你的人民

人口不是抽象的数字，而是由农民、市民、工匠、商人、贵族和奴隶构成的社会。每个阶层都有自己的需求和诉求——农民需要土地与粮食安全，市民需要贸易与手工业机会，贵族需要权力与地位。需求得不到满足，不满就会滋生，叛乱就会酝酿。你要做的不是管理一个"人口池"，而是驾驭一个有内部矛盾的活的社会。

### 建设你的经济

地理决定物产，物产决定可能。没有铁矿的地区无法发展金属冶炼，没有适合耕作的土地无法支撑农业文明——这不是限制，而是历史的真实。通过生产实践积累经验，通过贸易弥补短板，通过技术突破提升效率。一座缺铜的城市可以通过商路获得铜，但代价更高；一片沃土如果没有足够的人口和技术，也无法将资源优势转化为文明优势。

### 推动你的革新

技术不是一棵可以随意攀爬的树，而是一张受地理、物产和社会条件约束的网。革新来自两条路径的交汇：社会总体的生产实践积累，和天才工匠、商人的个人突破。生产足够多的铜器才能理解青铜的脾气，而一个天才匠人可以在关键时刻带来跨越式的灵感。但没有铜的地方，再天才的工匠也无法发明青铜冶炼。

### 引领你的文化

从平等的游群，到氏族部落，到世袭酋邦，到完整的族群与文明——文化阶段的提升不是线性的"进步"，而是社会复杂度的增长。同一个阶段可以是逐水草而居的游牧民，可以是有冬夏营地的渔猎族群，也可以是定居的农耕村落。海洋城邦是定居的，只是经济依赖海洋贸易——它的城市是固定的，它的贸易网络是流动的。

### 选择你的道路

文明可以通过五条不同的路径形成国家：定居农业的剩余积累，游牧征服的军事扩张，贸易控制的财富集中，宗教统一的认同超越，军事联盟的共同行动。每条路径都有独特的优势和挑战。酋邦阶段的扈从制——首领通过私人扈从队积累武力——是军事首领向王权转化的关键机制。你的文明走哪条路，取决于地理、物产、领袖和机遇的交汇。

### 行国与城国

这是两种根本不同的国家形态，不是同一种国家的不同风格。

**城国**有固定的边界和都城，以农业、贸易和税收为经济基础，以常备军和守城战为军事特色。你管理的是领土、基建和官僚效率。

**行国**没有固定边界，只有随季节和实力变化的活动范围。王庭是移动的，随季节在冬营地和夏营地之间迁徙。经济基础是畜牧、劫掠和对被征服定居区征收的保护费。军事是全民皆兵的骑兵，擅长机动与诱敌深入。你不需要防守每一寸土地——因为土地本身不是行国的核心资产，人和牲畜才是。

行国可以通过定居化改革转化为城国，城国也可能在被游牧民族征服后发生游牧化。

### 组装你的政体

政体不是"君主制"或"共和制"的简单标签，而是七个维度的组合：最高权力归谁、权力如何交接、中央机构是什么、地方如何治理、头衔如何分配、继承法如何规定、城市有多少自治权。一个君主制国家可以有元老院作为中央机构，可以用选举方式交接权力，可以同时存在封建和官僚两种地方治理方式。你不是在"选政体"，而是在"组装"一个适合你的文明的制度结构。

### 驾驭你的外交

敌对是常态，宣战是例外。在敌对状态下，你可以直接发动局部入侵、劫掠城镇、攻击聚落——不需要正式宣战。但每一次敌对行动都会给对方制造战争借口，也会损害你的国际名声。正式宣战开启全面战争，不宣而战承担名声损耗。战争借口、战争目标和和平条约是三层分离的——开战的理由不一定等于你想要的结果。

外交关系从互不侵犯到全面同盟，从朝贡到傀儡，共十种类型。通行管制分四级——在严格管制地区，军队通过必须请求军事通行权。任何能通过战争赢得的东西，也可以在谈判桌上获得。

### 指挥你的军队

军队的核心不是兵力数字，而是组织度、士气和训练度。组织度决定部队能持续战斗多久，士气决定是否会崩溃，训练度决定组织度掉得有多慢。一支训练有素的小部队可以在有利地形击败人数众多但组织度低下的大军。追击溃败的敌军比正面交战更有效率——但前提是你的部队还有足够的组织度进行追击。

通行没有硬性的不可通行——山脉地区通行难度高，但并非完全无法通过。关隘仅可在狭窄地形修建，可以直接阻挡通行；堡垒不直接阻挡通行，但敌对部队经过时受行军损耗和速度影响。军队、盗匪、蛮族都可以建立营寨，营寨可以随时间升级为坞堡甚至聚落。

### 面对地图上的他者

地图上不只有国家和军队。商队在贸易路线上穿梭，流民在战乱后迁徙，蛮族在边境游荡，盗匪在低秩序地区滋生，雇佣兵等待出价最高的雇主。这些自主单位有自己的意志和行动逻辑——你可以招安盗匪，可以雇佣雇佣兵，可以接纳流民增加人口，也可以劫掠商队获取财富（但会影响名声）。

前国家形态的人类群体——游群、部落、酋邦——以自主单位的形式存在于地图上。当它们满足人口、领袖、领土和文化条件时，可以转化为正式政权。蛮族占据弃地、建立营地、形成活动范围，然后被招安或被征服——这是历史的常态。

### 见证文明的兴衰

城市可以被摧毁，土地可以被遗弃，文明可以倒退。轻度劫掠掠夺物资，中度破城拆除城墙，重度夷平系统性摧毁甚至屠城。摧毁不是简单的"减分"——一座城市被夷平会导致人口流失为流民，贸易路线中断，周边地区经济崩溃，地块变无主后盗匪和蛮族滋生。废墟保留着原有的文化和宗教，重新定居时可能恢复。

弃地也不是失败的代名词。游牧政权的季节性弃地是正常运作方式，战略收缩时的主动弃地是以空间换时间的明智选择。文明可以倒退，也可以在废墟上重生——这才是历史。

## 技术架构

### 引擎与语言
- **Unity 6000.6.0f1** — URP 渲染管线
- **C# 9.0** — netstandard2.1
- **模块化程序集** — 6 个 asmdef 单向依赖链

### 模块结构
```
Core              — 数据定义、枚举、本地化
World             — 地形、气候、水文、群系、省份、聚落
Simulation        — 人口、经济、革新、文化、宗教、社会、政治、战争、角色
Rendering         — 地图渲染、覆盖层
Infrastructure    — 存档、模组、序列化、事件系统
UI                — 界面系统、控件、面板
Editor            — 地图编辑器、地形绘制、省份编辑
```

### UI 材质体系
暖灰褐磨砂石材 + 做旧青铜 + 灰米色旧纸的统一设计语言：
- **主面板** — 暖灰褐磨砂石材（载体）
- **Tab** — 嵌入式标签，Active 底部青铜强调线
- **Button** — 稍亮磨砂石材，四状态过渡
- **InputField** — 内凹暗槽，Focus 青铜焦点线
- **Scrollbar** — 凹槽 + 凸起滑块
- **ProgressBar** — 凹槽 + 九语义色填充
- **Tooltip** — 灰米色旧纸信息层

### 字体系统
- **思源黑体** — 功能文字（按钮、Tab、数字、正文）
- **思源宋体** — 身份文字（人物、文化、国家名称、历史文本）
