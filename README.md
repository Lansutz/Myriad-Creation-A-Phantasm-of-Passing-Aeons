# Myriad Creation: A Phantasm of Passing Aeons
## 纷繁的世界：一场流逝的幻景

一款基于学术研究的大战略文明模拟游戏。以唯物史观、布罗代尔三时段理论、人类学、技术史、反辉格史观、地理历史学、历史政治学等研究为理论基础，模拟文明从游群到帝国的完整演进过程。

## 学术基础

### 史学理论
- **唯物史观** — 生产力与生产关系的矛盾运动推动社会变革
- **布罗代尔三时段** — 长时段（地理/生态）、中时段（经济/社会周期）、短时段（事件/人物）
- **反辉格史观** — 避免以今度古，尊重历史语境的复杂性
- **历史政治学** — 国家形成、制度变迁、权力结构的历史分析

### 社会科学
- **人类学** — 亲属制度、仪式、象征、文化相对主义
- **地理历史学** — 地理环境对历史进程的塑造与限制
- **技术史** — 技术演进的路径依赖、偶然性与社会嵌入
- **年鉴学派** — 总体史、问题史学、跨学科方法

## 核心设计理念

### 文明演进的多路径
不预设"进步"的线性叙事。文明可以通过定居农业、游牧征服、贸易控制、宗教统一、军事联盟等多条路径形成国家。同一文化阶段可以有不同的移动模式（定居/半定居/游牧）和经济基础。

### 地理决定论与能动性的平衡
地理条件决定物产与初始可能性，但不决定最终命运。物产→革新→路径依赖，历史充满偶然性与天才人物的突破。

### 社会分层的渐进性
从平等的游群，到氏族部落，到酋邦的初步分层，到国家的完整阶级结构。每个阶层的出现都需要特定的革新与社会条件。

### 行国与城国
定居政权（城国）与游牧政权（行国）是两种根本不同的国家形态。行国没有固定边界，以活动范围和移动王庭为特征；城国以固定城市和官僚体系为基础。两者可以互相转化。

## 游戏系统

### 世界生成：地理是历史的第一推动力

世界不是一张空白地图，而是一个由地形、气候、水文共同编织的生态舞台。玩家在游戏开始时选择世界模板（完整世界/局部区域），调整海平面、大陆数量、地形剧烈程度等参数，系统基于多层高度图叠加生成地形，再通过水力侵蚀算法雕刻河谷与山脉，最后用大气环流模型（GCM）计算全球温度与降水分布。

**核心机制：**
- **多层高度图** — 大陆板块、地形细节、微起伏三层叠加，支持导入自定义灰度图
- **水力侵蚀** — 模拟水流对地形的长期塑造，生成自然的河谷与冲积平原
- **气候模拟** — 基于纬度、海拔、洋流的温度降水模型，决定群系分布
- **群系配置化** — 所有群系参数（温度范围、降水范围、植被类型、物产）通过 JSON 定义，可模组化

**玩家体验：** 世界生成后，玩家看到的不是随机噪声，而是有逻辑的地理结构——山脉阻挡水汽形成雨影效应，大河沿岸孕育冲积平原，河口三角洲天然适合建城。这些地理特征直接决定了后续文明的发展可能性。

### 人口与社会：人是文明的载体，阶层是历史的动力

人口不是抽象的数字，而是由具体阶层构成的社会实体。每个地块的人口承载由地理承载力（耕地、水源、气候）、仓储承载力（粮仓容量）、贸易修正（商路补给）共同决定。人口按阶层划分——农民、自由民、奴隶、王室、贵族教士——每个阶层有独特的需求、产出和政治倾向。

**核心机制：**
- **阶层需求系统** — 农民需要土地与粮食安全，市民需要贸易与手工业机会，贵族需要权力与地位，奴隶只是会说话的工具。需求未满足会引发不满、迁徙甚至叛乱
- **聚落独立化** — 聚落（村镇/城/堡垒）建立在地块之上而非依附地块，有独立的等级、形态、辐射范围和控制范围。点击地块显示主要聚落，点击聚落显示内部详情
- **聚落形态演化** — 村镇可发展为城，堡可转型为城，城可因战乱强化为堡垒。形态不是永久标签，而是随军政/经贸倾向缓慢演化的属性
- **聚落摧毁** — 轻度劫掠（掠夺物资）、中度破城（拆除城墙）、重度夷平（系统性摧毁+屠城）。摧毁后产生流民，地块变无主，文化可能残留

**玩家体验：** 玩家管理的不是"人口池"，而是一个有内部矛盾的社会。农民起义不是随机事件，而是土地兼并+粮食短缺+税负过重的必然结果。一座城市被夷平不是减几个数字，而是人口流失为流民、贸易路线中断、周边地区经济崩溃的连锁反应。

---

### 经济：物产是地理的馈赠，生产是技术的结晶

经济系统的核心逻辑是：地理决定物产→物产决定可学习的革新→革新提升生产效率→生产剩余支撑社会分层与国家形成。没有铁矿的地区无法发展青铜冶炼，没有适合耕作的土地无法支撑农业文明，这不是限制，而是历史的真实。

**核心机制：**
- **物产系统** — 每个地块根据群系和地形产出特定物产（粮食、木材、铁矿、铜、马匹、盐等）。物产是革新学习的前置条件——要学习青铜冶炼，至少得有铜
- **加工品品质** — 加工品有品质等级（差/普通/优良/精良），品质受原材料库存、工匠技能、技术水平影响。原材料不足时品质下降
- **实践驱动革新** — 革新学习进度与生产实践数量挂钩，但边际收益递减——生产100件次品能积累基础经验，生产500件后同样品质的产出带来的经验越来越少，需要更高品质的产物才能突破
- **贸易与虹吸** — 高等级聚落对周边形成经济虹吸，税收和贸易向中心聚集。商路流量决定贸易价值，商路被切断会导致沿线聚落衰退

**玩家体验：** 玩家不是在玩一个"资源越多越好"的游戏，而是在管理一个有地理约束的生产体系。一个缺铜的文明可以通过贸易获得铜，但成本更高；一个有丰富铁矿的地区如果没有足够的人口和技术，也无法将资源优势转化为文明优势。

---

### 革新：技术不是树，是网；进步不是必然，是偶然

革新系统拒绝线性的"科技树"叙事。革新分为技术、思想、制度、军事、经济、社会六大类，每类革新有明确的前置关系，但前置链不是唯一的——同一项革新可能有两条甚至三条不同的前置路径。UI 仅展示最近一层前置，不把整个链条推到玩家面前。

**核心机制：**
- **实践与个人双驱动** — 革新进度由社会总体实践积累（生产数量×品质）和个人化突破（工匠、商人等角色在旧方法实践达到阈值后迸发新灵感）共同推动。天才人物可以加速突破，但不能凭空创造——没有铜的地区，再天才的工匠也无法发明青铜冶炼
- **数量门槛** — 学习一项革新至少需要相关物产的一定数量（如至少10个铜器才能开始积累研究进度），避免"只有一个就开始研究"的不合理情况
- **革新与文化阶段绑定** — 社会分层的完整度决定了可学习的革新范围。游群无法学习官僚制度，酋邦无法发展常备军——不是被禁止，而是社会条件不具备
- **思想与制度革新** — 民族主义是思潮类革新，前置是报纸等大众传播媒介；民族国家是制度类革新，前置是民族主义。思想改变认知，制度改变结构

**玩家体验：** 玩家不会看到一个"研究什么都可以"的自由科技树，而是看到一个受地理、物产、社会条件约束的革新网络。有时候，等待一个天才工匠的出现比盲目生产更有效；有时候，通过贸易获得关键物产比自己探索更划算。

---

### 文化：文明不是标签，是生活方式

文化系统的核心是"文化阶段"——游群→部落→酋邦→族群→高度文明——这不是线性进步，而是社会复杂度的提升。每个文化阶段都可以有三种移动模式（高度流动/季节性营地/定居）和四种生计类型（狩猎采集/渔猎/早期畜牧/管理型采集），移动模式与经济基础是两个独立维度。

**核心机制：**
- **五阶段渐进** — 游群（平等主义，临时首领）→部落（氏族制度，民众大会）→酋邦（世袭首领，初步分层，扈从制）→族群（完整分层，专业化生产，族群认同）→高度文明（成熟国家，官僚/封建制度）
- **移动模式三路径** — 高度流动（游牧，行国）、季节性营地（半定居，渔猎族群）、定居（城国，含海洋城邦）。海洋城邦是定居模式+海洋贸易经济，不是半定居
- **国家形成五路径** — 定居农业路径（农业剩余→人口增长→社会分层）、游牧征服路径（军事征服→吸收被征服者制度）、贸易控制路径（控制商路→财富积累→雇佣军）、宗教统一路径（宗教认同超越部落→政教合一）、军事联盟路径（部落联盟→共同军事行动→联盟固化）
- **扈从制** — 酋邦阶段的核心制度。首领通过扈从队积累私人武力，扈从的忠诚是人身依附关系。扈从制促进军事首领→王权的转化，进入国家阶段后转化为贵族侍从/骑士

**玩家体验：** 玩家不会被强制走"从野蛮到文明"的单一路径。一个游牧部落可以全程保持高度流动，最终形成游牧帝国（行国）；一个渔猎族群可以发展出复杂的半定居社会；海洋城邦可以通过贸易控制形成商业文明。每种路径都有独特的优势和挑战。

---

### 行国与城国：两种根本不同的国家形态

这是游戏最核心的设计之一。定居政权（城国）与游牧政权（行国）不是同一种国家的不同风格，而是两种根本不同的组织逻辑。

**城国（定居政权）：**
- 有固定边界和都城，领土通过行省/郡县/封建体系管理
- 经济基础是农业+贸易+税收，有农业税、商税、人头税
- 军事以常备军+民兵为主，擅长守城战
- 地图显示为固定边界+城市图标

**行国（游牧政权）：**
- 没有固定边界，只有"活动范围"——半透明色块+虚线边界，随季节和实力变化
- 王庭是移动的，随季节在冬营地/夏营地之间迁移
- 经济基础是畜牧+劫掠+保护费（对被征服定居区），无农业税
- 军事是全民皆兵的骑兵，擅长机动与诱敌深入
- 可以征服和控制定居城市（作为附庸/纳税地），但王庭本身不固定
- 随时可以弃地拔营，无外交成本

**转化：** 行国可以通过"定居化"改革转化为城国（需要农业技术+城市建设+官僚制建立）；城国罕见游牧化（通常是被游牧民族征服后统治阶层游牧化）。

**玩家体验：** 玩行国和玩城国是两种完全不同的游戏体验。城国玩家关心的是边界、税收、基建、官僚效率；行国玩家关心的是牧场、迁徙路线、部落联盟、军事机动。行国不需要防守每一寸土地，因为"土地"本身不是行国的核心资产——人和牲畜才是。

---

### 政治：政体是组合，不是标签

政体系统不使用"君主制/共和制"的简单二分，而是七维组合模型——最高权力、权力交接、中央机构、地方治理、头衔分配、继承法、城市特许——每个维度有多个选项，选项之间有组合约束但不是简单互斥。

**核心机制：**
- **最高权力** — 君主制或共和制。君主制下最高权力属于君主，共和制下属于中央机构
- **权力交接** — 世袭（细分继承法）、选举、推举、僭夺。即使是君主制也可以是选举君主或推举君主。世袭君主才有详细的继承法细分：范围（本族/血亲不论姓氏）、支系（长支优先/兄终弟及）、性别（仅男/男优先/平等/仅女/女优先）、长幼
- **主次交接** — 最高权力交接可以有主要和次要方式。以罗马到东罗马为例：僭主制为主导，推举制为第一次要，血缘世袭为第二次要。能选几个次要看政府的行政容量
- **中央机构** — 先选"有无"，再选类型（长老会/元老院/议会/官僚机构），选了议会才会有议会构成等子选项。君主制下也可以有中央机构
- **地方治理** — 封建类型和官僚类型是两个选项组，各自下面有不同的方式和范围选项。封建和官僚不必然互斥，但它们的子选项组有一定互斥性
- **头衔分配** — 类似法兰克人的情况：最高头衔家族共享，但管理的领地要分配
- **城市特许** — 可选项，授予城市自治权

**玩家体验：** 玩家不是在"选政体"，而是在"组装政体"。一个君主制国家可以有元老院作为中央机构，可以用选举方式交接权力，可以同时存在封建和官僚两种地方治理方式。这种组合性让每个政权都有独特的制度结构，也让制度改革成为有深度的策略选择。

---

### 外交与战争：敌对是常态，宣战是例外

外交系统拒绝"必须有宣战理由才能开战"的传统设计。游戏引入"敌对状态"——双方处于敌对状态时，可以直接发动局部入侵、劫掠城镇、攻击聚落，不需要正式宣战。正式战争状态是宣战后的更高层级冲突。

**核心机制：**
- **敌对状态 vs 战争状态** — 敌对状态下可发动局部入侵劫掠，但不触发全面战争机制；正式宣战进入战争状态，开启全面战争机制。不宣而战会承担名声损耗
- **战争借口/目标/条约三层分离** — 战争借口（casus belli）是开战的理由，战争目标是想要达成的结果，条约是最终的和平协议。三者分离，借口不一定等于目标
- **敌对活动制造借口** — 在敌对状态下劫掠、入侵会给对方制造战争借口
- **边境摩擦 vs 边境战争** — 边境摩擦是低烈度的边境冲突，边境战争是更高层级的冲突，两者有联系但不同
- **外交关系十类** — 平等盟约5种（互不侵犯/防御同盟/进攻同盟/全面同盟/阵营），不平等从属5种（朝贡/附庸/附属/保护国/傀儡）。封建附庸是内政关系，不是外交关系
- **通行管制四级** — 无管制/松散管制/有限管制/严格管制。严格管制地区军队通过必须请求军事通行权

**条约谈判：** 双方各有"让步"和"索取"两个清单，可选项受战争分数总分限制。占领领地一般只能选择与己方接壤或有海路相连的领地。

**玩家体验：** 玩家不会被"没有宣战理由不能开战"束缚。可以在敌对状态下持续进行低烈度劫掠和骚扰，逐步消耗对手，也可以突然发动全面战争。但每一次敌对行动都会给对方制造借口，也会影响自己的国际名声——名声差的政权更容易被联合针对。

---

### 军事：组织度是灵魂，训练度是骨骼

军事系统的核心不是兵力数字，而是组织度、士气、训练度三者的互动。组织度决定部队能持续战斗多久，士气决定部队是否会崩溃，训练度决定组织度掉得有多慢——训练度越高，组织度衰减越慢。

**核心机制：**
- **人口块编制** — 军队以100人为一个人口块，补员和征兵按100的整数计算。补员每隔一段时间按当前人数的10%批量增加，避免逐人计算的CPU负担
- **组织度与伤亡** — 组织度过低会增加敌方追击效率；瞬时伤亡率过高会瞬间降低组织度。总伤亡率和瞬时伤亡率分开计算
- **战斗结束与逃跑** — 部队总人数不足原有的一定比例时战斗结束，是否逃跑取决于指挥官
- **踩踏事件** — 组织度过低+瞬时伤亡率过高时可能触发踩踏事件，造成额外伤亡
- **通行难度** — 综合海拔与坡度计算通行难度，不设硬性不可通行。山脉地区通行难度高但并非完全无法通过，山脉地段和山脉中间一般都能通行
- **关隘与堡垒** — 关隘仅可在狭窄地形修建，可直接阻挡通行；堡垒不直接阻挡通行，但敌对部队经过时受行军损耗和速度影响，己方堡垒提供补给和支援加成
- **营寨系统** — 军队、盗匪、蛮族均可建立营寨（行军营地/冬营/山寨/毡帐群），营寨可升级为坞堡甚至聚落

**玩家体验：** 玩家不是在比拼"谁的兵多"，而是在管理一支有组织度、有训练度、有士气的军队。一支训练有素的小部队可以在有利地形击败一支人数众多但组织度低下的大军。追击溃败的敌军比正面交战更有效率——但前提是你的部队还有足够的组织度进行追击。

---

### MapActor 自主单位：地图上不只有国家

MapActor 是可以在地图上自主行动的单位，不一定隶属于任何政权。它们有独立的 AI，可以在无主地区活动，也可以进入政权领土。这个系统为游戏提供了极大的可扩展性。

**核心类型：**
- **流民** — 从战乱、摧毁、弃地中产生，逃向安全地区，可被接纳为人口
- **游牧民/蛮族** — 前国家形态的人类群体，以部落/酋邦形式活动，可建立营地，满足条件后可转化为正式政权
- **商队** — 在贸易路线上移动，受贸易需求驱动，可被劫掠
- **雇佣兵** — 可被政权雇佣参战，有自己的组织和诉求
- **盗匪** — 在低秩序地区滋生，劫掠商队和聚落，可被招安或剿灭
- **野兽/动物灾害** — 无智慧物种，可模拟动物灾害（蝗灾、狼群等）

**核心机制：**
- **前国家载体** — 游群/部落/酋邦阶段的人类群体以 MapActor 形式存在，满足文化阶段、人口、领袖、领土等条件后可转化为正式政权
- **营寨建立** — MapActor 可建立临时或半永久据点，据点可随时间升级
- **AI决策分级** — 不同类型的 MapActor 有不同的决策间隔（流民每天思考，游牧民每3天，野兽每7天），控制性能开销

**玩家体验：** 地图不是只有国家和军队在活动。商队在贸易路线上穿梭，流民在战乱后迁徙，蛮族在边境游荡，盗匪在低秩序地区滋生。这些自主单位为游戏世界增添了生命力，也为玩家提供了更多互动可能——可以招安盗匪，可以雇佣雇佣兵，可以接纳流民增加人口，也可以劫掠商队获取财富（但会影响名声）。

### 聚落摧毁与弃地：文明可以倒退，土地可以荒芜

历史上城市被摧毁、土地被遗弃是常见现象。汉谟拉比毁玛睿、杨坚毁建康、赵炅毁晋阳——摧毁的手段和程度各不相同。游戏完整模拟这一过程。

**摧毁程度：**
- **轻度·劫掠** — 掠夺物资、零星纵火，人口损失10-20%，防御损失30-50%，1-3年恢复
- **中度·破城** — 拆除城墙、烧毁主要建筑，人口损失30-50%，防御完全损毁，聚落降一级，5-10年恢复
- **重度·夷平** — 系统性摧毁、水淹、屠城，人口损失70-95%，聚落可能降为村镇/废墟或直接消失，20年以上或永不恢复

**摧毁手段：** 劫掠、纵火（可能蔓延）、拆城（获得建材）、水淹（仅临河城市，地块变沼泽）、屠城（产生大量流民，名声暴跌）、夷平（彻底摧毁）

**弃地机制：**
- **主动弃地** — 政权战略决策放弃，军队撤离，聚落降级
- **被动弃地** — 战争失败/被驱逐
- **自然弃地** — 环境恶化/经济崩溃导致人口流失
- **游牧弃地** — 游牧政权季节性迁移，拔营即走，无外交成本

**连锁反应：** 聚落被摧毁→人口流失为流民 MapActor→地块变无主→秩序下降→盗匪/蛮族滋生→蛮族占据弃地建立营地→形成活动范围→可被招安或征服。废墟地块保留原文化宗教，重新定居时可能恢复。

**玩家体验：** 摧毁一座城市不是简单的"减分"，而是会引发一系列连锁反应。夷平敌方核心城市可能导致对方文明倒退（黑暗时代），但也会产生大量流民涌向周边地区，可能给你自己的领土带来人口压力。弃地不是失败的代名词——游牧政权的季节性弃地是正常运作方式，战略收缩时的主动弃地是以空间换时间的明智选择。

## 技术架构

### 引擎与语言
- **Unity 6000.6.0f1** — URP 渲染管线
- **C# 9.0** — netstandard2.1
- **模块化程序集** — 6 个 asmdef 单向依赖链

### 模块结构
```
Core              — 数据定义、枚举、本地化
World             — 地形、气候、水文、群系、省份、聚落
Simulation        — 人口、经济、革新、文化、宗教、社会、政治、战争、角色
Rendering         — 地图渲染、覆盖层
Infrastructure    — 存档、模组、序列化、事件系统
UI                — 界面系统、控件、面板
Editor            — 地图编辑器、地形绘制、省份编辑
```

### UI 材质体系
暖灰褐磨砂石材 + 做旧青铜 + 灰米色旧纸的统一设计语言：
- **主面板** — 暖灰褐磨砂石材（载体）
- **Tab** — 嵌入式标签，Active 底部青铜强调线
- **Button** — 稍亮磨砂石材，四状态过渡
- **InputField** — 内凹暗槽，Focus 青铜焦点线
- **Scrollbar** — 凹槽 + 凸起滑块
- **ProgressBar** — 凹槽 + 九语义色填充
- **Tooltip** — 灰米色旧纸信息层

### 字体系统
- **思源黑体** — 功能文字（按钮、Tab、数字、正文）
- **思源宋体** — 身份文字（人物、文化、国家名称、历史文本）
