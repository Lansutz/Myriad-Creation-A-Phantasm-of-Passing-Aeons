# Myriad Creation: A Phantasm of Passing Aeons
## 纷繁的世界：一场流逝的幻景

一款**大战略 + 上帝模拟**游戏。以唯物史观、布罗代尔三时段理论、人类学、技术史、反辉格史观、地理历史学、历史政治学等研究为理论基础，模拟文明从游群到帝国的完整演进过程。

> **关于本项目的开发方式**：本项目大量使用了 AI 辅助编程和文档撰写，但游戏的核心设计理念、系统架构、创新机制和学术判断均出自我个人的思考和研究。AI 是工具，不是设计者。文中提到的"我"指的是项目的独立设计者。
>
> **开发状态**：持续开发中，很多系统还只是框架，细节会随着开发不断调整。

## 一、学术基础与设计理念

### 史学理论
- **唯物史观** — 生产力与生产关系的矛盾运动推动社会变革
- **布罗代尔三时段** — 长时段（地理/生态）、中时段（经济/社会周期）、短时段（事件/人物）
- **反辉格史观** — 避免以今度古，尊重历史语境的复杂性
- **历史政治学** — 国家形成、制度变迁、权力结构的历史分析

### 社会科学
- **人类学** — 亲属制度、仪式、象征、文化相对主义
- **地理历史学** — 地理环境对历史进程的塑造与限制
- **技术史** — 技术演进的路径依赖、偶然性与社会嵌入
- **年鉴学派** — 总体史、问题史学、跨学科方法

### 核心设计原则

**文明演进的多路径** — 不预设"进步"的线性叙事。文明可以通过定居农业、游牧征服、贸易控制、宗教统一、军事联盟等多条路径形成国家。同一文化阶段可以有不同的移动模式和经济基础。

**地理决定论与能动性的平衡** — 地理条件决定物产与初始可能性，但不决定最终命运。物产→革新→路径依赖，历史充满偶然性与天才人物的突破。

**社会分层的渐进性** — 从平等的游群，到氏族部落，到酋邦的初步分层，到国家的完整阶级结构。每个阶层的出现都需要特定的革新与社会条件。

**革新是核心驱动力** — 很多东西都是由革新系统推动的，不只是技术，还包括思想、制度、社会结构的变化。革新在整个游戏中占据很大比重，是理解整个游戏运作方式的关键。

## 二、核心游戏系统

### 1. 世界与地理

世界生成的核心思路是：地理不是背景板，而是历史的第一推动力。我不希望玩家看到的是一张随机噪声地图，而是一个有逻辑的生态结构——山脉阻挡水汽形成雨影效应，大河沿岸孕育冲积平原，河口三角洲天然适合建城。

这部分的设计依据主要来自地理历史学和环境史的研究——地理环境不决定历史，但它深刻地塑造了历史的可能性空间。

#### 1.1 世界生成

实现上基于多层高度图叠加生成地形，再用水力侵蚀算法雕刻河谷，最后用简化的大气环流模型计算温度和降水分布。群系（biome）的所有参数都通过 JSON 定义，方便后续调整和模组化。水文系统包括河流生成、流域划分和河口三角洲。省份被设计为包含多个子地块的结构，支持地块级别的精细模拟。

#### 1.2 地理与历史的联动

地理不是静态的背景——它通过物产系统影响革新的可能性，通过地形影响军事行动，通过气候影响人口承载，通过河流影响贸易路线。没有铁矿的地区无法发展金属冶炼，没有适合耕作的土地无法支撑农业文明——这不是刻意的限制，而是历史的真实。

### 2. 革新与经济

革新与经济是紧密交织的两个系统——革新是经济发展的核心驱动力，经济基础又决定了革新的可能性（物产是革新的前置条件）。我把它们放在一起讲，因为脱离了经济的革新是无源之水，脱离了革新的经济是一潭死水。

**革新系统是整个游戏中占比重最大的系统**，也是理解其他所有系统的钥匙。很多东西都是由革新推动的——不只是技术，还包括思想、制度、社会结构的变化。我拒绝线性的"科技树"叙事，因为技术史的研究表明，技术演进是路径依赖的、充满偶然性的、受社会条件约束的。

这个系统的设计有几个核心创新点，都是我自己思考的结果：

**第一，物产是革新的前置条件。** 要学习和某样东西相关的革新，至少得要有这个东西。没有铜的地区，再天才的工匠也无法发明青铜冶炼。这不是数值增益减益的问题，而是一个简单的逻辑：你连这个东西都没有，怎么开始研究它？

**第二，实践驱动而非点数驱动。** 每样革新有学习进度，这个进度和生产实践的数量与品质有关。生产一样相对完美的东西需要很多次品来堆积——这是技术史的基本常识。但实践经验有边际收益递减：生产总量100以内的品质较差的产物时增长率较高，生产500同品质之后增长就很有限了，后面需要更高品质的产物才能继续推进。

**第三，个人化的革新。** 革新不是抽象的"国家在研究"，而是具体的工匠、学者、商人在推动。角色研究系统（CharacterResearchSystem）追踪每个角色对革新的贡献——角色有研究专长领域、研究能力、灵感值。用旧方法实践一定次数后，角色会获得"灵感"，灵感爆发时研究效率翻倍。但研究不是免费的——需要消耗物资、时间、设施。

这三点结合起来，形成了一个"社会总体实践积累 + 个人天才突破"的双轨机制——大多数技术进步是缓慢的实践积累，但关键时刻的天才人物可以带来跨越式发展。这参考了技术史中关于"学习曲线"和"天才突破"的讨论，但具体的双轨设计是我自己的创新。

#### 2.1 革新分类与数据驱动

革新采用**两级分类**：大类（技术/思维/制度/传统）× 子类。大类是借鉴了技术史和知识社会学的分类方法，子类的具体划分是我自己设计的。革新定义全部数据驱动，由 JSON 文件加载，支持模组覆盖和新增。

每类革新有明确的前置关系，但前置链不是唯一的——同一项革新可能有不同的前置路径。比如炼铜技术，从"自然铜加工"和"陶器烧制温度提升"两条路径都可能到达。

#### 2.2 革新的专业化细化

以炼铜为例，具体的革新技术需要细化——从哪个技术变成哪个技术，都要有明确的前置。不是笼统的"冶金术"，而是"自然铜加工→冷锻→退火→熔炼→铸造→合金"这样的链条。每个环节都有自己的实践要求和品质门槛。

加工品有品质等级（差、普通、优良、精良），品质受原材料库存、工匠技能和技术水平影响——原材料不足时品质会下降。不同品质的产物对革新进度的贡献不同，高品质产物能推进更高阶段的革新。

#### 2.3 个人化的革新

革新不是抽象的"国家在研究"，而是具体的工匠、学者、商人在推动。角色研究系统（CharacterResearchSystem）追踪每个角色对革新的贡献：
- 角色有**研究专长领域**（InnovationField），在该领域研究效率+50%
- 角色有**研究能力**（0-10），影响研究效率
- 角色有**灵感值**（0-100），用旧方法实践积累，满了触发灵感爆发
- 灵感爆发时研究效率翻倍，持续一段时间
- 研究需要消耗物资、时间、设施，不是免费的

工匠、学者、商人等不同角色有不同的研究方向——工匠擅长技术革新，学者擅长思维和制度革新，商人擅长经济和贸易革新。这让"天才人物推动技术突破"不再是随机事件，而是有具体角色支撑的系统。

个人化革新和社会总体实践积累是双轨关系——大多数技术进步是全社会缓慢实践积累的结果，但关键时刻的天才人物可以带来跨越式发展。这参考了技术史中关于"学习曲线"和"天才突破"的讨论，但具体的双轨设计是我自己的创新。

#### 2.4 革新与其他系统的联动

革新不是一个独立的"科技树"，而是渗透到各个系统中：
- **经济**：新生产技术提升效率，新经济制度（货币、税收、贸易）改变经济结构
- **社会**：新思想观念（私有财产、市场观念）改变阶层结构，新技术解锁新阶层
- **政治**：官僚制度需要文字和行政技术，封建制度需要土地私有和军事依附观念
- **军事**：新武器技术解锁新兵种，新军事制度改变军队组织
- **文化**：新思想推动文化演进，新文化传统影响革新方向

#### 2.5 经济系统

经济是整个社会的基础——生产剩余支撑社会分层，贸易网络连接各个聚居点，税收制度养活官僚和军队。经济系统的核心逻辑是一条因果链：地理决定物产，物产决定可学习的革新，革新提升生产效率，生产剩余支撑社会分层和国家形成。

商品系统定义了各种物产和加工品。这里需要特别澄清：**矿物是矿物，金属是金属**——它们是不同的物资类别。矿物是原材料（铁矿石、铜矿石），金属是加工品（铁、铜、青铜），从矿物到金属需要冶炼革新和冶炼设施。商品有不同的类型和品质等级，加工品的品质受原材料库存、工匠技能和技术水平影响。

货币系统处理货币的发行、流通和价值。税收系统支持多种税收类型——农业税、商税、人头税、畜牧税、保护费。贸易系统包括贸易中心、贸易路线和商队。高等级聚落对周边形成经济虹吸效应——税收和贸易向中心聚集。这参考了历史地理学中关于中心地理论和经济地理学的研究。

社会阶层可用性系统定义了每个阶层出现需要哪些革新和文化传统——这是社会分层渐进性的具体实现。社会分层计算器自动计算社会的分层完整度——这是文化阶段提升的核心指标之一。

#### 2.6 革新与经济的联动

革新与经济的联动是整个游戏最核心的循环之一：
- **物产→革新**：没有相关物产就无法开始研究对应的革新（没有铜就无法研究青铜冶炼）
- **革新→生产效率**：新生产技术提升产量和品质，产生更多剩余
- **剩余→社会分层**：生产剩余支撑专业化分工，催生新的社会阶层
- **新阶层→新革新**：专业化的工匠、商人、学者推动新的革新
- 这是一个正反馈循环，但也受地理条件、人口规模、社会稳定等因素的制约

### 3. 人口与社会

人口与社会是紧密交织的两个系统——人口是社会的载体，社会结构决定人口的组织方式。有些内容无法分开来讲（比如人口承载与阶层需求的互动），所以先做综合描述，再分系统详细论述。

这部分的设计依据主要来自历史社会学和人类学对前现代社会分层的研究，包括韦伯的阶层理论、马克思的阶级分析，以及人类学对酋邦和早期国家的研究。但具体的阶层划分（农民四层、自由民四类、奴隶四源）和阶层需求系统是我自己的创新，不是直接套用任何现有理论。

#### 3.1 人口与聚落

人口不是抽象的数字，而是由具体阶层构成的社会实体。人口承载由地理承载力（耕地、水源、气候）、仓储承载力（粮仓容量）和贸易修正（商路补给）共同决定。

**聚居点统一术语**：我把所有"人类在地图上建立的点"统一称为**聚居点（Settlement）**，分为两大类：

1. **定居点（Burg）**：永久性建筑，长期定居，不可移动。分为村镇（Village）、城（City）、堡垒（Fort）三大类，每类有等级（Ⅰ-Ⅴ级）、功能类型（行政/军事/商业/宗教等）、形态（圆城/方城/山城/水城等）。
2. **营地（Camp）**：临时性/半永久性，可拔营转移。分为临时营地、军营、山寨、游牧营地、难民营等类型。

两者之间有演化路径：营地长期存在+人口积累+定居化改革 → 定居点；定居点被摧毁后可能降级为废墟或被游牧政权控制后降级为营地。这个统一分类是我自己设计的，目的是避免"聚落""据点""定居点""营地"这些术语混用造成的混乱。

定居点（村镇、城、堡垒）被设计为独立于地块的实体，有自己的等级、形态和辐射范围。这是因为前现代的聚落不是地块的附属品，而是一个有自身生命力的节点。聚落的形态也不是永久标签——村镇可以发展为城，堡可以转型为城，城也可能因战乱强化为堡垒。

聚落摧毁系统设计了三级程度（轻度劫掠、中度破城、重度夷平）和六种手段（劫掠、纵火、拆城、水淹、屠城、夷平）。这参考了历史上的真实案例——汉谟拉比毁玛睿、杨坚毁建康、赵炅毁晋阳——摧毁的手段和程度各不相同，后果也不一样。摧毁后会引发连锁反应：人口流失为流民，地块变无主，秩序下降导致盗匪和蛮族滋生。

#### 3.2 社会阶层与派系

##### 3.2.1 社会阶层

阶层系统将人口划分为农民（自耕农、佃农、农奴、雇农）、自由民（市民、商人、工匠、士人）、奴隶（家奴、官奴、债务奴、战俘奴）、王室和贵族教士几个阶层。每个阶层有独特的需求维度——农民需要土地和粮食安全，市民需要贸易和手工业机会，贵族需要权力和地位。需求得不到满足会引发不满、迁徙甚至叛乱。

##### 3.2.2 阶层与革新的关系

阶层与革新的关系是这个系统最重要的设计之一。我不认为所有社会都有相同的阶层结构——不同的社会，因为技术水平、思想观念和经济基础不同，拥有的阶层并不完全一致。一个没有农业技术的游群社会不可能有农民阶层，一个没有私有财产观念的社会不可能有佃农阶层，一个没有官僚制度的社会不可能有士人阶层。

因此，**固定阶层在某个社会或政权下的产生，需要有相应的革新作为前提**——不管是技术方面的还是思想方面的。比如：
- 农业革新（技术）解锁自耕农阶层
- 土地私有观念（思想）解锁佃农阶层
- 庄园制度（制度）解锁农奴阶层
- 金属冶炼和手工业分工（技术）解锁工匠阶层
- 货币和市场经济（经济）解锁商人阶层
- 文字和官僚制度（技术+制度）解锁士人阶层
- 世袭首领制度（思想）解锁贵族阶层
- 战俘奴役观念（思想）解锁奴隶阶层

这不是一个简单的"解锁"机制，而是一个社会结构随技术和思想进步而逐渐分化的过程。

##### 3.2.3 派系与社会分化

派系系统的设计基于一个观察：前现代政治的核心冲突往往不是个人之间的，而是基于阶层利益的派系斗争。派系有阶层基础（各阶层对派系的支持权重，可以跨阶层结盟）、领袖角色、成员名单和政治纲领。派系可以推动法律改革、支持或反对继承、甚至发动叛乱。

社会分化系统追踪社会分层的完整度——这是文化阶段提升的核心指标之一。从平等的游群，到初步分层的酋邦，到完整分层的国家，社会分化是一个渐进的过程，不是突变。

#### 3.3 人口与社会的联动

人口增长推动社会分化——当人口超过一定规模，简单的平等主义无法维持，社会分层开始出现。社会分层反过来影响人口——不同阶层有不同的生育率和死亡率，贵族人口增长快于平民，奴隶人口可能因高死亡率而需要持续补充。阶层需求得不到满足会导致人口流失（迁徙）或社会动荡（叛乱），进一步影响人口规模。

### 4. 文化与宗教

文化与宗教都是身份认同系统——文化定义"我们是谁"，宗教定义"我们信仰什么"。两者紧密交织但又各自独立：同一个文化可以有不同宗教，同一个宗教可以传播到不同文化中。

这部分的设计参考了比较宗教学（伊利亚德的神圣与世俗框架、缪勒和弗雷泽的宗教起源研究）和考古学文化理论，但具体的系统设计有很多我自己的创新。

#### 4.1 文化系统

文化系统的核心是"文化阶段"——游群、部落、酋邦、族群、高度文明——这参考了人类学的经典框架（塞维斯的四阶段论），并在此基础上扩展。这不是线性的"进步"叙事，而是社会复杂度的提升——每个阶段都可以有不同的移动模式和经济基础。

##### 4.1.1 文化七大板块

文化数据的七大板块是文化系统的核心设计——这是我参考考古学文化研究方法后自己设计的框架。需要说明的是，这七大板块准确来说描述的是**考古阶段的文化**，也就是酋邦阶段以前的文化形态。在这个阶段，文化主要通过物质遗存（器物组合、葬俗、居住方式）来识别，还没有形成文字记录和复杂制度。而这些板块本身——比如某种葬俗的出现、某种物质风格的形成、某种象征实践的聚焦——本质上也是某种革新的产物，是早期人类社会在技术和思想上的突破。

每个文化都由七个维度定义：
1. **生计主轴**（狩猎采集/渔猎/早期畜牧/管理型采集）
2. **移动模式**（高度流动/季节性营地/半定居）
3. **葬俗类型**（竖穴墓/二次葬/瓮棺/屈肢葬/仰身葬/赭石施用，可多选）
4. **原始崇拜权重向量**（七维：生殖/自然/祖先/死亡/图腾/形象/巫术，0-100相对配比）
5. **物质风格倾向**（石器组合/陶器/骨器偏好）
6. **象征实践焦点**（动物力量/生殖/山石/死亡处理，主+次双焦点）
7. **环境适应标签**（草原/河谷/森林边缘/海岸/山地，可多选）

这种设计参考了考古学中"考古学文化"的定义方法——一个考古学文化通常由一组共同的器物组合、葬俗、居住方式来定义。但将其系统化、可量化为七大板块，是我自己的设计。

移动模式和生计类型是两个独立的维度。这里需要特别澄清：海洋城邦是定居模式加海洋贸易经济，不是半定居——它的城市是永久固定的，只是经济依赖海洋贸易。半定居（季节性营地）指的是渔猎族群那种有冬夏营地的模式。

##### 4.1.2 文化阶段与国家形成

国家形成被设计为五条可能的路径：定居农业路径、游牧征服路径、贸易控制路径、宗教统一路径、军事联盟路径。这参考了比较人类学和国家形成理论的研究——国家不是只有一种形成方式。

扈从制被设计为酋邦阶段的核心制度——首领通过私人扈从队积累武力，扈从的忠诚是人身依附关系。这参考了塔西佗《日耳曼尼亚志》中对日耳曼扈从制（Comitatus）的描述，以及恩格斯关于扈从制促进王权产生的论断。

##### 4.1.3 文明的定义

什么是文明？这是一个学术界长期争论的问题。旧的"文明三要素"标准（城市、文字、青铜器）和新的"五要素"标准（专业化生产、完整社会分层、城市化、强制性权力、领土控制）都有各自的道理，学术界也有他们的考虑。

但以我自己的理解，这两套标准之间其实有一个逻辑关系：

**旧标准中的某些要素，其实是发展到某个阶段的衍生物，而不是文明的本质定义。**

以**文字**为例：文字不是凭空出现的，它是出于复杂的记账和记录需求。当一个社会的税收、贸易、仓储变得足够复杂，结绳记事和口头传述已经无法满足管理需求时，文字就会自然而然地出现。拿印加来举例——印加长期使用奇普（结绳记事），不是因为他们"发明不出文字"，而是因为他们的税收和管理体系还没有复杂到必须使用文字的程度。但随着时间的推移，社会越来越复杂，管理需求越来越大，印加也会像玛雅一样发展出自己的文字系统。文字是社会复杂度达到一定程度后的必然产物，不是文明的前提条件。

**青铜器**也是类似的逻辑——它是冶金技术发展到一定阶段的产物，而冶金技术的发展又依赖于矿产资源、生产剩余和专业化工匠的出现。没有铜矿的地区，社会再复杂也不会"自然"出现青铜器；但有铜矿且社会复杂度足够的地区，青铜器迟早会被发明出来。

而**城市化**不同——它不能算是衍生物，而是文明的**外在表现**。城市不是社会复杂度的原因，而是社会复杂度的结果和可见标志。当专业化生产、社会分层、强制性权力这些本质要素发展到一定程度，城市就会作为它们的空间载体出现。

因此，我在设计中采用的立场是：**新标准（专业化生产、完整社会分层、强制性权力、领土控制）是文明的本质定义，是必要条件；城市化是文明的外在表现；文字和青铜器是社会复杂度达到一定阶段后的衍生物，是成就条件而非前提条件。**

在游戏中，新标准是文化阶段从"族群"提升到"高度文明"的必要条件。旧三要素（城市、文字、青铜器）则作为"成就条件"——不是必要的，但有重大加成（文字提升管理效率和知识传播速度，青铜器提升军事和生产效率）。这种设计允许玩家在没有文字或青铜器的情况下仍然可以形成文明，就像历史上的印加和玛雅一样——但他们最终也会随着社会复杂度的提升而发展出这些衍生物。

#### 4.2 宗教系统

宗教系统是设计得最深入的模块之一，因为我相信宗教在前现代社会中扮演了远超"信仰"的角色——它是法律、教育、艺术、政治合法性、社会凝聚的核心。

##### 4.2.1 双维度宗教谱系与教统

双维度宗教谱系是这个系统最核心的设计，也是我自己的创新。宗教不是简单的树状结构，而是两个独立维度的交叉：
- **组织谱系**（组织父）：宗教→宗派（组织性分裂，互斥）→传统（思想性传承，可共存）→分支传统（任意深度）
- **思想谱系**（学派父）：思想源链——礼仪祖先学派，与组织谱系独立

这种设计是为了捕捉历史上宗教的复杂性——比如聂斯托里派在组织上是独立的宗派，但在思想上可以追溯到安提阿学派；亚述教会在组织上有使徒统绪，但在思想上源自赛琉基亚-泰西封学派。

教统（使徒统绪/法脉）是组织连续性的标志——宗派必须有教统，没有教统的学派只能思想并入，不能独立组织化。这参考了基督教的使徒统绪、佛教的法脉传承等概念。

教义系统允许自定义宗教的核心教义，每个教义有多个选项。教义影响宗教的法律、道德判定和社会效果。神祇系统支持多神教和一神教，每个神祇有自己的属性、崇拜方式和神职人员。

##### 4.2.2 神祇的起源与演化

神祇的起源与演化是宗教系统的另一个核心设计。比较宗教学的研究表明，神祇不是凭空出现的——最初一个部落就有一个神祇，部落征战融合后形成大部族守护神，城国最初也是城邦守护神。随着历史发展，某些神祇消亡在历史长河中，一些则被编进了神谱变成下位的存在。在游戏中，当两个不同宗教的政治实体发生接触、征服或融合时，神祇系统会发生相应的变化——被征服方的神祇可能消亡，也可能被纳入征服方的神谱成为下位神。

多神教与一神教共享同一套框架。整个宗教系统的设计遵循一个通用框架——神祇、教义、仪式、神职人员、圣地、法律、传教——但不同类型的宗教在这个框架下有不同的复杂度：一神教通常有更复杂的教统机制和教会组织，多神教通常没有教统这种复杂机制，更原始一点的宗教连完整的神祇谱系都没有。但它们都遵循同一套底层逻辑。

##### 4.2.3 封圣与主保圣人

虔诚且有美德的角色可以被封圣，圣人有自己的纪念日、崇拜和主保范围（某个城市、行业、群体的保护者）。

需要特别说明的是，**主保圣人制度很大程度上是多神教万神殿传统的衍生和残留**，而不是简单的"人神化"。多神教的起源大致是这样的：各个小部落有自己的守护神，各个城邦有自己的城邦守护神——这些神祇最初是独立的。随着部落征战、融合，这些独立的守护神被编进一个大的谱系，形成了**万神殿系统（Pantheon）**。

当一神教向多神教地区传播时，它不可能完全剥离这些成分——如果完全剥离了，它就没有传播的土壤。因此，一神教采取了一种文化适应的策略：将原来各地守护神的传统，转化为**主保圣人制度**——原来罗马时期各个神庙供奉的神祇，变成了各个城市的主保圣人。

因此，封圣系统不仅适用于一神教，也适用于多神教和原始宗教——在多神教中，对应的就是万神殿中的神祇选择和主保神祇崇拜；在一神教中，对应的就是封圣和主保圣人制度。两者共享同一套底层逻辑。

##### 4.2.4 其他宗教机制

法律与犯罪系统：宗教法律定义了什么是罪行，审判系统处理宗教犯罪。这参考了中世纪的宗教裁判所、伊斯兰的沙里亚法庭等。

传教系统：传教士可以在异教地区传播信仰，信仰传播有不同的阶段和方式。

思想流派与意识形态运动：宗教内部可以产生不同的思想流派，流派可以演化为意识形态运动，推动宗教改革或分裂。这参考了宗教改革、伊斯兰的教法学派等历史现象。

#### 4.3 个人化的信仰

这是宗教系统中一个很重要但容易被忽略的设计——**不是所有人都信仰同一个宗教**。每个角色有三层信仰：

1. **社会信仰（faithId）**：角色公开宣称的信仰，也是社会期望他拥有的信仰
2. **私人信仰（privateFaithId）**：角色内心真正信仰的宗教，可能与社会信仰不同
3. **秘密信仰（isSecretBeliever）**：当私人信仰与社会信仰不同且被社会禁止时，角色成为秘密信徒，有暴露风险

角色还可以有**个人信条（personalTenets）**——自己选择或组合的教义选项，来源可以是借鉴其他信仰、组合原有教义、甚至自创。个人信条与官方教义的差异构成**信仰偏离度**。

这种设计是为了捕捉历史上宗教信仰的复杂性——很多人表面上信仰官方宗教，但内心有自己的想法；很多人在私下融合了不同宗教的元素；在宗教迫害时期，很多人成为秘密信徒。这不是简单的"宗教转换"，而是一个更细腻的信仰光谱。

#### 4.4 文化与宗教的联动

文化和宗教互相塑造——文化的原始崇拜权重向量影响宗教的形成方向，宗教的教义和仪式反过来影响文化的象征实践和葬俗。同一个文化可以分裂为不同宗教（如基督教的东西教会分裂），同一个宗教可以传播到不同文化中（如佛教从印度传到中国、日本）。宗教皈依往往伴随着文化融合，而不是简单的替换。

### 5. 政治与外交

政治系统处理权力的组织方式，外交系统处理政权之间的关系。两者紧密相关——政体形态决定外交行为，外交压力反过来影响政体演变。

#### 5.1 行国与城国

行国与城国是整个游戏最核心的设计之一，也是最容易被误解的地方。

首先需要澄清：前现代国家没有现代意义上的"固定边界"。无论是城国还是行国，领土都是模糊的、势力范围式的。我们说的"行国与城国"不是"有边界 vs 没边界"的区别，而是两种根本不同的组织逻辑。

**城国**（定居政权）以固定的定居点为基础，经济主要依赖农业、贸易和税收，军事以常备军和守城战为主。它的核心资产是土地和城市。

**行国**（游牧政权）以移动的人群和牲畜为基础，王庭随季节在冬营地和夏营地之间迁徙，经济主要依赖畜牧、劫掠和对被征服定居区征收的保护费，军事是全民皆兵的骑兵，擅长机动和诱敌深入。它的核心资产是人和牲畜，而不是土地——所以行国不需要防守每一寸土地，拔营即走。

行国可以征服和控制定居城市（作为附庸或纳税地），但王庭本身不固定。行国也可以通过定居化改革转化为城国——这需要农业技术、城市建设和官僚制度的建立。城国罕见游牧化，通常是被游牧民族征服后统治阶层发生游牧化。

这个设计的依据主要来自中国史学界对"行国"与"城国"的经典区分（如司马迁《史记》中对匈奴的描述），以及人类学对游牧社会的研究。

#### 5.2 内政与政体

内政系统处理政权内部的治理——法律、税收、官僚、地方治理、继承等。政体不是简单的"君主制/共和制"二分，而是由多个维度共同决定的：最高权力归谁、权力如何交接、中央机构是什么、地方如何治理、继承法如何规定。

这样设计是因为历史上的政体远比"君主/共和"复杂——罗马帝国是君主制但有元老院，神圣罗马帝国是选举君主制，威尼斯是共和制但有世袭贵族。一个君主制国家可以有中央机构，可以用选举方式交接权力，可以同时存在封建和官僚两种地方治理方式。

最高权力的交接方式决定了政体的基本形态——个人传承系（世袭、僭夺、神命）推导为君主，选举系（选举、轮座）根据权力分配推导为选举君主或共和。"王国""帝国"等只是外交头衔（纯称号，不产生机制影响）。

继承法被细分为范围（本族/血亲不论姓氏）、支系（长支优先/兄终弟及）、性别（仅男/男优先/平等/仅女/女优先）和长幼。最高权力的交接可以有主要方式和次要方式——比如罗马到东罗马，僭主制是主导，推举制是第一次要，血缘世袭是第二次要。

中央机构先选"有无"，再选类型（长老会、元老院、议会、官僚机构）。选了议会才会有议会构成等子选项。君主制下也可以有中央机构。

地方治理的封建类型和官僚类型是两个选项组，各自下面有不同的方式和范围选项。封建和官僚不必然互斥，但它们的子选项组有一定互斥性。

官职系统定义了各种官职的名称、职责和任命方式。政权更迭系统追踪政权的结构性张力和关键节点——当社会矛盾积累到一定程度时，会触发关键节点（Juncture），可能导致政权更迭、改革或内战。这参考了历史社会学中关于国家崩溃和革命的研究。

政体的变化也往往是由革新推动的——官僚制度的建立需要文字和行政技术，封建制度的形成需要土地私有和军事依附观念，共和制度的出现需要公民观念和议事传统。政体不是凭空选择的，而是社会的技术水平、思想观念和经济基础发展到一定阶段后的产物。

这部分的设计依据主要来自历史政治学和比较政治学对前现代政体的研究。需要说明的是，政体的多维度分析框架借鉴了比较政治学的结构分析方法，但具体的维度划分、选项设计和约束规则是我自己设计的。

#### 5.3 外交系统

外交系统的一个核心设计是：敌对是常态，宣战是例外。我不希望玩家被"没有宣战理由不能开战"束缚——在敌对状态下，可以直接发动局部入侵、劫掠城镇、攻击聚落。但每一次敌对行动都会给对方制造战争借口，也会损害国际名声。正式宣战开启全面战争，不宣而战承担名声损耗。

战争借口、战争目标和和平条约被设计为三层分离的——开战的理由不一定等于想要的结果。条约谈判时，双方各有"让步"和"索取"清单，可选项受战争分数限制。

外交关系设计了十种类型：平等盟约五种（互不侵犯、防御同盟、进攻同盟、全面同盟、阵营），不平等从属五种（朝贡、附庸、附属、保护国、傀儡）。封建附庸是内政关系，不是外交关系。

通行管制分四级——在严格管制地区，军队通过必须请求军事通行权。和平谈判系统处理战争结束时的条约签订，有谈判状态和条款系统。

这部分的设计参考了历史国际关系学和战争史的研究，特别是关于前现代国际关系中"灰色地带"冲突的研究。很多大战略游戏把外交关系简化为"友好/中立/敌对"三态，我试图还原前现代外交中更复杂的灰色地带——不宣而战的劫掠、名义上的朝贡实际上的独立、同盟中的离心离德。

### 6. 军事与战争

军事系统的核心不是兵力数字，而是组织度、士气和训练度三者的互动。组织度决定部队能持续战斗多久，士气决定是否会崩溃，训练度决定组织度掉得有多慢。

这样设计是因为军事史的研究表明，前现代战争的胜负往往不取决于人数，而取决于部队的凝聚力和纪律性。一支训练有素的小部队可以在有利地形击败人数众多但组织度低下的大军。

#### 6.1 三军编制与兵种

##### 6.1.1 三军编制

三军编制系统是军事系统的基础框架——前军/中军/后军（或左军/中军/右军）的军队编制。这是我参考中国古代军事编制（如春秋时期的三军制）和世界军事史中的阵型部署后自己设计的系统。每个军有不同的战术角色：前军负责先锋和试探，中军是主力和指挥核心，后军负责预备队和撤退掩护。不同的阵型部署会影响战斗结果——比如前军强势可以快速突破，但后军薄弱则容易被包抄。

##### 6.1.2 兵种系统

兵种系统不是简单的"步兵/骑兵/海军"三分法，而是**多个维度的组合**。这里需要把几个维度区分清楚：

第一个维度是**装备**：轻型、中型、重型、超重型。这不是"等级"，不是说重型就一定比轻型好——轻型、中型、重型各有优缺点，是不同的装备形态，和战斗属性相关联：轻型速度快、追击效率高、补给消耗低，但正面战斗力弱；重型正面战斗力强、防御高，但速度慢、补给消耗大、追击效率低。超重型则是极端情况，有特殊的战术用途但也有明显的短板。

第二个维度是**战场定位**：步兵、骑兵——这里主要指的是战兵。需要特别说明的是，**作战领域和战场定位是两码事**。步兵和骑兵不是简单的"走路的"和"骑马的"，而是不同的战术定位：步兵的本质是"占领和控制地面的力量"，骑兵的本质是"高机动性的突击力量"。即使技术发展了，骑兵的定位也不会消失——比如现代没有骑兵了，但高机动性突击的定位给了装甲部队、机动步兵。在游戏的前现代背景下，这个定位主要由骑马的战兵来承担，所以称之为骑兵。

第三个维度是**远程/近战**：弓步兵、弓骑兵属于远程兵种，近战步兵、近战骑兵属于近战兵种。

这三个维度组合起来，就形成了具体的兵种：轻步兵、重步兵、中骑兵、弓步兵、弓骑兵等等。每个具体兵种都有自己的战斗属性：近战攻击、远程攻击、防御、士气、速度、补给消耗、追击效率。追击效率决定了兵种在敌方组织度崩溃后的追杀能力——骑兵的追击效率远高于步兵，这也是为什么古代战争中骑兵对溃败步兵的杀伤往往远大于正面交战。

至于**海陆空**，这是另一个维度——作战领域，和步兵/骑兵不是一个意思。陆军里有步兵和骑兵，海军里也有步兵（接舷战、登陆作战）和骑兵（某些特殊情况），但海军的核心其实是**船只系统**和**水军的专业化演化**：从早期不那么专业化的民船征召、运输船队，到后来专业化的战舰、水兵制度。所以海军更准确地说是一个特殊的作战领域，而不是一个与步兵、骑兵并列的兵种类别。

兵种不是凭空出现的，而是技术革新和社会条件发展到一定阶段后的产物——没有马镫就没有重骑兵，没有造船技术就没有专业化的水军。

#### 6.2 战斗与行军

##### 6.2.1 战斗系统

战斗系统处理两军交战的结算，采用分阶段战斗推进（最多5个阶段），总伤亡率和瞬时伤亡率分开计算，组织度过低会增加敌方追击效率，瞬时伤亡率过高会瞬间降低组织度，极端情况下可能触发踩踏事件——踩踏是军事战斗系统中的一个机制，不是独立的灾害系统。

##### 6.2.2 行军与补给

行军与寻路系统处理军队在地图上的移动。通行系统不设硬性的不可通行——山脉地区通行难度高，但并非完全无法通过。

补给系统是军事系统中非常重要的一环，也是我花了不少心思设计的部分。前现代的军队补给完全不同于现代——没有高效、专业化的稳定补给线，没有高效的通讯，交通条件差导致行军效率低。军队主要依赖**行营和随军补给**，以及在途经地区的征发。当随军补给不够时，**劫掠就成了非常常见的选择**。

这里我想多说几句，因为网络上总有人"津津乐道"地说"十字军天天抢劫"，然后简单归咎于"日耳曼或者拉丁蛮子野蛮"。我个人认为这不是根本原因。根本原因是：他们的补给系统在同时代更为落后，而且当时的常备军制度不够完善，也不要想有什么专业化的训练来达成严格的军纪要求。而旁边的罗马本尊——东罗马——才有这种相对完善的补给和军纪体系。前现代的制度注定了军队就不是什么善茬，士气低落的时候你不让他们去抢，他们反过来就干你，除非你的威望相当高。有的时候还会发生屠城——这当然有道德问题，但这种道德问题的根源是经济基础和制度条件导致的，而不是简单的蛮子野蛮。

因此在游戏中，劫掠不是一个"邪恶选项"，而是前现代军队的常态机制。军队在敌境行军时会自动征发和劫掠当地物资，劫掠效率受军队规模、当地人口密度、将领威望和军纪影响。将领威望高、军纪好的军队劫掠程度较轻；威望低、士气差的军队劫掠更狠，甚至可能失控。长期补给不足会导致士气下降、逃兵增加，极端情况下军队可能哗变。

##### 6.2.3 其他军事机制

关隘与堡垒系统：关隘仅可在狭窄地形修建，可以直接阻挡通行；堡垒不直接阻挡通行，但敌对部队经过时受行军损耗和速度影响。

大圣战系统处理宗教性的大规模战争——如十字军、吉哈德等。大圣战有自己的状态机和规则。

营寨系统：军队、盗匪、蛮族都可以建立营寨（行军营地、冬营、山寨、毡帐群），营寨可以随时间升级为坞堡甚至聚落。

军队以100人为一个编制块，补员按一定比例批量增加——这主要是出于性能考虑，避免逐人计算的CPU负担。

### 7. 灾害与瘟疫

灾害与瘟疫是前现代社会不可忽视的力量——一场瘟疫可以摧毁一个帝国的人口基础，一次旱灾可以引发大规模饥荒和叛乱，一次地震可以摧毁一座城市。我不希望这些只是随机事件的数字惩罚，而是有其传播规律、社会影响和历史后果的系统。

需要说明的是，这里讲的是**群体层面的灾害和瘟疫**，个体层面的疾病属于角色系统的范畴。

这部分的设计参考了医疗社会史和环境史的研究——如黑死病对欧洲社会的深远影响、明末小冰期对明朝灭亡的推动、火山爆发导致的全球性饥荒。

#### 7.1 灾害系统

灾害有不同的类型（气象灾害、地质灾害、生物灾害等），每种灾害有自己的发生条件、频率、持续时间和严重程度。灾害不是凭空发生的——旱灾与气候变化相关，洪水与水文系统相关，地震与地质构造相关。

灾害的影响是多方面的：直接的人口损失、基础设施破坏、农业减产、贸易中断、社会秩序崩溃。灾害还可能引发连锁反应——旱灾导致饥荒，饥荒导致流民，流民导致盗匪滋生，盗匪导致社会动荡，社会动荡可能引发政权更迭。

#### 7.2 瘟疫系统

需要区分两个层面：**疾病**是个体层面的（角色会生病、受伤、死亡），**瘟疫**是群体和社会层面的——当传染病在人口中大规模传播时，才构成瘟疫，才算是一种灾害。

目前内置七种传染病，每种有独特的传播逻辑和参数：

- **鼠疫**（黑死病）：高感染率（0.15）、高死亡率（0.5）、低恢复率（0.02），潜伏期7天，持续21天，R0=3.0。历史上的黑死病就是这种，沿着商路和军队路线从亚洲传到欧洲，短时间内摧毁大量人口。
- **天花**：高感染率（0.12）、中高死亡率（0.3）、中恢复率（0.05），潜伏期12天，持续30天，R0=3.5。传染性极强，幸存者会留下疤痕（麻子），历史上长期是儿童的主要杀手之一。
- **霍乱**：中感染率（0.1）、中死亡率（0.2）、高恢复率（0.08），潜伏期3天，持续10天，R0=2.5。经水源传播，与卫生条件密切相关，暴发快但持续时间短。
- **斑疹伤寒**：中低感染率（0.08）、中低死亡率（0.15）、中恢复率（0.06），潜伏期10天，持续21天，R0=2.0。经虱子传播，与战争、饥荒、拥挤的环境密切相关，历史上多次在军队和围城战中暴发。
- **疟疾**：低感染率（0.06）、低死亡率（0.05）、低恢复率（0.03），潜伏期14天，持续60天，R0=1.5，地方性疾病。经蚊子传播，与气候和地理环境密切相关，在热带和亚热带地区长期存在，是地方性的健康负担。
- **结核病**（肺痨）：极低感染率（0.03）、低死亡率（0.1）、极低恢复率（0.01），潜伏期90天，持续365天，R0=1.2，地方性疾病。慢性消耗性疾病，病程长，与营养不良和拥挤环境相关，历史上是"白色瘟疫"。
- **痢疾**：低感染率（0.05）、低死亡率（0.08）、高恢复率（0.1），潜伏期2天，持续7天，R0=1.8。经水源和食物传播，暴发快、恢复快，常见于卫生条件差的地区和军队行军中。

瘟疫的传播受多种因素影响：人口密度、贸易路线、战争移动、卫生条件、气候。传染病可以沿着商路和军队路线传播，从一个地区蔓延到另一个地区。每种疾病的传播方式不同——鼠疫和天花主要通过呼吸道和接触传播，霍乱和痢疾通过水源传播，疟疾通过蚊子传播，斑疹伤寒通过虱子传播，结核病通过长期密切接触传播。

瘟疫不仅影响人口数量，还影响社会结构——大量人口死亡可能导致劳动力短缺，劳动力短缺可能导致农奴制的瓦解（如黑死病后的欧洲），也可能导致工资上涨和经济结构变化。瘟疫还会引发社会恐慌、宗教狂热、迫害少数群体等连锁反应。

个体层面的疾病则属于角色系统——角色有肉体健康和精神健康两个维度，疾病可以降低肉体健康，长期的压力和恐惧可以导致精神疾病。

### 8. 角色与家族

角色与家族系统很大程度上借鉴了 Crusader Kings（十字军之王）系列的设计——角色有性格、关系、家族、继承，这些是 CK 系列的核心机制。但我做了很多改良和扩展，加入了很多 CK 没有的东西。

我做这个系统的原因是：我相信历史是由具体的人推动的——不是抽象的"国家"在做决策，而是有性格、有关系、有欲望的具体人物。CK 系列证明了角色驱动的大战略游戏是可行的，但我觉得 CK 的角色系统还可以更深入、更学术化。

#### 8.1 角色系统

角色与家族系统很大程度上借鉴了 Crusader Kings（十字军之王）系列的设计——角色有属性、性格、关系、家族、继承，这些是 CK 系列的核心机制。但我做了很多改良和扩展，加入了很多 CK 没有的东西，比如肉体与精神双重健康、基本能力与专精两层属性、技能树系统等。

##### 8.1.1 基本属性与健康

角色有年龄、性别、生日等基本信息。健康分为**肉体健康**和**精神健康**两个维度——肉体健康（health 0-100）受疾病、伤害、年龄、肥胖等影响；精神健康通过压力（stress）和精神疾病来体现，压力>60时人格漂移翻倍，>80时有精神疾病风险。压力系统借鉴自 CK 系列，但我做了扩展——CK 的压力主要影响角色的健康和事件触发，我在这里加入了人格漂移和精神疾病的机制。角色还可以有精神障碍（抑郁、焦虑、失智等）——这不是为了猎奇，而是因为历史上很多重要人物确实有精神健康问题，这些问题影响了他们的决策和历史进程。

##### 8.1.2 基本能力、专精与技能树

角色的属性系统采用**三层结构**：基本能力 → 专精 → 技能树。基本能力是更底层、更通用的身体素质和心智能力，专精是在基本能力基础上发展出来的面向特定领域的专业技能，技能树挂在专精之下，是专精领域内具体可学习的能力节点。

需要说明的是，基本能力高不代表专精就强——专精 = 基本能力 + 学到的技能。一个体魄很强的人，如果没有受过战斗训练，他的勇武也不会很高；一个心智很强的人，如果没有学过行政管理，他的管理能力也不会很强。

**基本能力**分为四大类，每类有三个子属性：

1. **体魄**：力量（肌肉力量和爆发力）、协调（身体协调性和灵巧度）、坚韧（耐力和抗疲劳能力）
2. **心智**：记忆（记忆力和知识留存）、逻辑（逻辑推理和分析能力）、灵感（创造力和直觉思维）
3. **交涉**：口才（表达能力和说服力）、洞察（读懂他人意图和情绪的能力）、气度（个人魅力和气场）
4. **感知**：观察（观察力和细节捕捉）、直觉（直觉判断和预感）、反应（反应速度和应变能力）

**专精**分为六个维度（0-100），每个专精下挂若干棵技能树，每棵树有分叉，节点有前置。技能树的具体节点内容还在设计中，这里只说明结构和每棵树的定位：

1. **社交** — 用**正当、公开的手段**处理关系的能力，是能放得上台面的东西。范围从国家间的正式外交到个人间的非正式交往，核心是通过谈判、结盟、宴会、结交等光明正大的方式建立和维护关系。下挂技能树：外务（国家或势力之间的正式关系）、人际（具体个人之间的非正式关系）、家庭（家族或宗族内部事务）。
2. **阴谋** — 用**隐秘、不正当的手段**达到目的的能力，是放不上台面的东西。核心是通过暗杀、投毒、勒索、操纵、煽动等见不得人的方式在幕后操控局势。社交和阴谋的本质区别不在于处理什么关系，而在于**手段是否正当**——同样是影响一个人，社交用的是说服和结交，阴谋用的是操纵和胁迫。下挂技能树：密谋（秘密策划并执行针对具体目标的敌对行动）、威吓（通过制造恐惧迫使具体的人服从）、操纵（利用已有关系或心理弱点隐蔽影响具体的人）、煽动（鼓动群体产生行动意愿或情绪）。
3. **军事** — 军事指挥和战略能力。下挂技能树：统御（对军队的直接带领和管理）、军略（对战争和战役的规划与决策）、后勤（为军队提供物资和人员保障）。
4. **管理** — 行政管理和经济治理能力。下挂技能树：财政（管理金钱和资源）、建设（基础设施和领地的开发与建造）、行政（法律和官僚体系的运作）。
5. **学识** — 知识水平和学习能力。下挂技能树：医学（人体健康和疾病的知识与实践）、技艺（物质世界的建造和制造知识）、义理（权力合法性的叙事和论证）、文学（书面表达和记录）。
6. **勇武** — 个人战斗能力和勇猛程度。下挂技能树：战斗（正面对抗中的个人战斗能力）、生存（野外环境中的生存和行动能力）。

这六维专精中，勇武和军事的区分参考了 CK3 的设计——CK3 本身就有"勇武"（Prowess）和"军事"（Martial）的区分，因为个人勇猛和统帅能力是两回事。而在六维专精之上增加基本能力这一层，是我自己的设计——CK 系列没有这一层，我认为增加这一层可以让角色的成长更有层次感，也可以让不同专精之间有更合理的关联（比如勇武和军事都依赖体魄，但侧重不同的子属性）。

这里有几个容易混淆的术语，层级关系从低到高是：**交涉**（基本能力里的大类，指一个人底层的社交能力）→ **社交**（专精，范围更广，包括外务、人际、家庭三个子技能树）→ **外务**（社交专精下面的子技能树，专门负责国家间的正式关系）。这几个词各有各的含义，不能混用。

**节点解锁条件**：

- **专精数值 ≥ 节点门槛**：代表你学过的东西够不够
- **剩余点数 ≥ 1**：代表你还有没有没花掉的点
- **前置节点**：树内部有层级，高级节点需要先点出前置
- **基本能力门槛**：某些节点要求某个基本能力子属性达到一定值

**节点效果类型**：

- **解锁行动**：获得原本没有的行动选项
- **解锁事件选项**：特定事件中出现新的选择分支
- **提供判定修正**：特定判定获得加成
- **解锁特殊互动**：角色间出现新的互动方式
- **作为前置节点**：解锁更高级节点
- **提供被动效果**：持续生效的修正

需要说明的是，CK3 那套生活方式系统还可以，但是有些层级混乱。比如宣战这种操作，它是政权层面的决策，不是角色个人层面的技能，不应该绑在角色的个人技能树上。

##### 8.1.4 性格

性格系统的核心框架（特质、对立特质、隐藏人格维度推导、压力机制、经济原型）照搬 CK3，不做无谓重复。以下只说明我在此基础上做的扩展和修改。

**扩展一：每个特质分四档**

CK3 原版的特质是二元的（有或没有），我从 More Personality Depth 模组得到灵感，扩展为每个特质分四个档位：轻微、普通、明显、极端。

基础特质约 25-30 个（照搬 CK3），每个分 4 档，相乘后总共推导出 100+ 个性格特质变体。每一档对隐藏人格维度的修正值和属性修正都不同，档位会随角色经历和压力升降。

**扩展二：经济原型从四种扩展到十一种**

CK3 原版只有四种经济原型（好战者、谨慎者、建设者、不可预测者），我扩展了七种：经济繁荣者、虔诚建设者、征服者、行政官僚、阴谋家、文化赞助人、不敬神的改革者。共十一种，由隐藏人格维度和特质组合推导，影响 AI 统治者的经济行为倾向。

**扩展三：本真、表现、期许三维度**

这是我自己加的设计，CK3 里没有。每个角色的性格存在三个层面，都是角色自身的，不是外部施加的：

- **本真（Authentic Self）**：角色真实的内心性格，即隐藏人格维度的真实值。这是角色独处时、卸下所有伪装后真正的样子——现在的我。
- **表现（Persona）**：角色自己选择展示给别人的性格，别人看到的样子。表现也不是随机的，而是**特定的本真特质组合**导致角色选择特定的表现方式——一个狡诈多变的人可能会有意识地伪装出与本真完全不同的性格，一个野心勃勃的人可能会表现得安于现状来隐藏野心，一个多疑的人可能会表现得格外信任他人来麻痹对手。与期许不同，表现不一定需要身份这一层，纯粹的特质组合就可能触发特定的表现策略。表现是角色主动选择的社交面具，与本真的差距越大，维持这种伪装消耗的精力越多，长期会导致压力积累。
- **期许（Ideal Self）**：角色自己想要达成的性格目标，理想中的我——我想成为什么样的人。期许不是随便产生的，而是**特定的本真特质组合加上角色身份**共同触发的：一个本真怯懦的继承人可能期许自己变得勇敢，一个本真贪婪的神职人员可能期许自己变得慷慨，一个本真残暴的君主可能期许自己成为仁君。这里的特质组合不一定只有一个特质，可能是两个甚至三个特质的组合（比如怯懦+多疑+身份=继承人，会产生特定的期许方向）。期许是角色内心的追求方向，不是外部施加的规范。

需要说明的是，**并不是所有角色都会有三者不一致的情况**——这取决于特定的特质。一个诚实坦荡的人可能本真、表现、期许三者完全一致，既不伪装也不想改变自己；只有特定的特质组合（比如狡诈、野心、怯懦、贪婪等）才会触发表现或期许的偏离。三维度的不一致是有条件的，不是普遍状态。

三个维度之间的张力是角色成长和戏剧的来源：

- **本真 vs 期许**：角色真实的样子与自己想成为的样子之间的差距。这种差距是角色成长的动力——努力改变自己、克服天性。但如果差距太大且长期无法弥合，会导致自我否定、压力积累，甚至精神疾病。
- **表现 vs 本真**：角色展示给别人的样子与真实内心的差距。短期的伪装是社交技能和生存策略，长期的伪装会导致自我认同混乱和精神压力。当压力过大时，表现可能崩裂，真实性格暴露出来。
- **表现 vs 期许**：角色努力表现出自己想成为的样子，但如果本真差距太大，表现会显得虚假、不自然，他人可能察觉到这种不一致，导致信任下降。

这个设计的灵感来自社会学的拟剧理论（戈夫曼：社会是舞台，人是演员，有前台和后台）和荣格的人格面具（Persona）与自我（Self）概念。我希望通过这三个维度，让角色的性格不只是一组静态数值，而是充满内在张力、成长可能性和戏剧冲突的动态系统。

**压力与人格漂移**

压力机制照搬 CK3（行为与特质冲突→压力积累→阈值触发后果），但在三维度框架下，压力的来源更丰富了：不只是行为与特质冲突，还包括本真与期许的长期冲突、维持表现的精力消耗。压力>60时人格漂移速度翻倍，>80持续90天有精神疾病风险。

##### 8.1.5 其他数值

**威望与恶名——对 CK3 相关系统的重构**

威望和恶名这两个系统，是我把 CK3 的威望（Prestige）和恐惧/暴政（Dread/Tyranny）系统重构了一下。CK3 里威望是有等级的声望值，恐惧和暴政是通过恐怖行为和不正当行为积累的威慑值；我把它们重构为两个独立的维度：威望是容量型数值，恶名是档位累积型数值。

**威望（Prestige）——容量型数值**

威望是容量型数值，有当前值、容量等级和容量上限：
- 等级1-5，上限分别为100/300/600/1000/1500
- 达到上限自动升级，低于30%自动降级
- 缓慢向零回归（每天-0.05）

威望通过战功、外交成就、文化贡献、宗教功绩等获得，用于重大决策（如宣战、联姻、封圣）的消耗。

**恶名（Notoriety）——档位累积型数值**

恶名不是容量型数值——它没有"当前值/容量上限/升级降级"这种可消耗的机制。恶名的档位是自然而然累积增加的，没有主动升级操作。

恶名分为五个档位，通过暴行、暴政、背叛、屠杀等行为累积：
- 无恶名：行为正当，无显著暴行记录
- 小恶：偶有严苛行为，但未造成广泛恐惧
- 大恶：经常性暴政或暴行，在邻国有一定恶名
- 极恶：大规模屠杀或背叛，令人闻风丧胆
- 遗臭：反人类级别的暴行，史书留名，遗臭万年

恶名会缓慢消退（比威望慢，每天-0.02），但极端档位的恶名几乎不可逆。恶名影响：
- 他人恐惧（Dread）——高恶名角色天然令人畏惧
- 外交关系——恶名越高，邻国越可能结盟对抗
- 封臣忠诚——暴政型恶名会降低封臣好感
- 历史评价——死后的评价等级和绰号

**威望与恶名的关系**

威望和恶名是两个独立的维度，不是非此即彼的。一个角色可以同时有高威望和高恶名（比如战功赫赫但残暴成性的征服者），也可以高威望低恶名（明君），低威望高恶名（暴君），或双低（平庸之主）。

5档威望 × 5档恶名 = 25种组合，不是简单的四种二分能概括的。因此我不再使用"明君/暴君/昏暴之君/平庸之主"这种简单分类，而是让威望和恶名各自独立影响游戏机制。

**上限型数值（0-100固定上限）**：

- **健康**（health）：肉体健康，受疾病、伤害、年龄、肥胖等影响。50岁起开始自然衰减，肥胖>70加速衰老。健康过低会死亡。
- **生育力**（fertility）：影响生育概率。
- **压力**（stress）：>60人格漂移翻倍，>80精神疾病风险。压力会自然恢复，但抑郁/焦虑等精神疾病会降低恢复速度。
- **恐惧**（dread）：通过恐怖行为积累，用于威慑封臣和敌人。>80会触发偏执风险。
- **肥胖**（obesity）：饮食/活动驱动，影响健康和魅力。会自然回落（活动代谢）。
- **魅力**（charm）：这是我单独独立出来的属性，CK3 里没有独立的魅力值——吸引力（Attraction）在 CK3 里是隐藏的计算值。我把它独立成了和六维专精并列的第七个属性，初始值通过 DNA 外观微调计算（AA +5 / Aa +2 / aa -3，±10随机），影响人际互动和婚姻选择。特质和精神疾病也会对魅力产生修正。

需要说明的是，我个人认为魅力值或者说吸引度这个东西应该跟一些身体特征有关，所以设计了**角色偏好**——不同的角色对不同的身体特征（身高、体型、外貌、身体标记等）有不同的偏好。因此魅力不是一个绝对数值，而是相对的：同一个角色在不同人眼里的魅力可能不同，因为评判者的偏好不一样。比如一个偏好高大体型的角色，会觉得高个子更有魅力；而一个偏好娇小体型的角色，则会觉得矮个子更有吸引力。身体标记（俊美、秃顶、矮小等外貌型特征）和伤病（跛足、失明、驼背等健康状态）都会根据评判者的偏好产生不同的魅力修正。

**DNA与寿命相关**：

- **预期寿命**（expectedLifespanYears）：种族基准 + DNA寿命偏移，出生时确定。
- **个体抵抗力**（individualResistance）：0-100，种族抗性基准 + DNA抗性偏移，疾病感染修正用。
- **DNA表达结果**（dnaExpression）：出生时一次性计算，终身不变，包括外观标签等。

**信仰与灵性**：

- **灵性满足**（spiritualFulfillment）：0-100，角色与信仰的真实关系。美德特质增长、罪行特质下降、秘密信仰煎熬。参考 CK3 的唯主是依（Spiritual Fulfillment），区别于隐藏人格维度的虔信——这是虔诚资源。
- **社会信仰**（faithId）：展示给社会的公开合法信仰。
- **私人信仰**（privateFaithId）：本人真实信仰，默认同社会信仰，可不同，冲突时转入秘密信仰状态。
- **个人信条**（personalTenets）：本人信条，可借其他信仰/组合原有/自创，与官方教义冲突→偏离度。
- **秘密信仰标记**（isSecretBeliever）：私人≠社会且被禁止时为true，有身份暴露风险。

**身体标记**（bodyMarks）：身体标记是一个更大的范围，来源不一，目前统一放在 bodyMarks 里，后续可能会按来源细分。主要有三个来源：

1. **先天外观**：由 DNA 和先天因素决定的外貌特征，比如发色、瞳色、美丑这些。需要说明的是，这里不应该用"中立"来划分——哪怕是瞳色这种看似正常的先天特征，不同的也确实可能有特定缺陷，只是够不上疾病的程度。先天外观和疾病之间没有绝对的界限，而是一个连续谱：有些特征（比如侏儒症、巨人症、白化、虹膜异色、脱发等）可能介于两者之间，既可以看作先天外观的变异，也可以看作某种程度的疾病或缺陷。身高、体型、秃顶这些还可能受后天因素（营养、锻炼、衰老、压力）影响，不完全是先天的。
2. **疾病**：分为先天的和后天的。先天疾病如天生驼背、天生失明等，由遗传或先天因素导致；后天疾病如战斗受伤导致的跛足、感染导致的癞病、衰老导致的失明等，由事件、伤病或衰老写入。疾病会影响健康和能力，部分后天疾病可通过治疗恢复。
3. **服饰和装备**：角色穿戴的服饰和装备，比如黑甲、白袍、王冠等。这些是外在的、可变的标记，会随角色的身份和状态变化。

身体标记是外貌型绰号（秃头、美男子、瘸子、瞎子、黑王等）的判定源，也会影响魅力评判——不同来源的标记对魅力的影响方式不同：先天外观主要影响基础吸引力，疾病会根据评判者的偏好产生不同修正，服饰和装备则会根据场合和身份产生不同的魅力加成或减成。

**精神疾病系统**：角色级状态机，与传染病系统（人口级）分层。精神疾病不是笼统的"疯了"，而是有不同的类型和表现，目前内置五种，设计上可以扩展到更详细的分类：

- **抑郁**（情绪障碍）：可逆，学识/社交/魅力-5，压力恢复速度×0.4。表现为意志消沉、对政务与人事提不起兴致、日渐寡言。触发条件：长期高压（压力>80持续90天）。
- **焦虑**（焦虑障碍）：可逆，管理/军事/魅力修正，压力恢复速度×0.3。表现为终日忧惧不安、寝食难安、决断迟疑、杯弓蛇影。触发条件：深度恐惧（>80）或长期高压。
- **偏执**（精神病性障碍/妄想性障碍）：可逆，社交-8、阴谋+5，好感衰减速度×2。表现为怀疑身边的一切人，把善意当作阴谋，睚眦必报。触发条件：深度恐惧（>80）持续或长期高压。
- **谵妄**（急性神经认知障碍/急性脑综合征）：可逆，六维全部-3。表现为神志昏乱、言语无状、时而清醒时而糊涂、不识昼夜。触发条件：重病后、高烧、极度疲劳或老年急性发作。
- **失智**（慢性神经认知障碍/痴呆）：不可逆，学识-15、军事/社交/魅力-5。表现为年迈带来的心智衰退，往事如烟，认不清亲人，性情大变。触发条件：高龄心智衰退（70岁以上，学识低于45时风险上升）。

这五种分别对应不同的精神疾病分类：抑郁属于情绪障碍，焦虑属于焦虑障碍，偏执属于妄想性障碍，谵妄属于急性神经认知障碍，失智属于慢性神经认知障碍。设计上还可以扩展双相情感障碍、精神分裂症、强迫症、人格障碍等更多类型。

压力长期低于30持续120天可恢复（失智除外，不可逆）。精神疾病数据驱动，可由模组覆盖/新增。

**健康系统与疾病**：本质上，所有这些——传染病、慢性病、伤病、遗传病、精神疾病——都归属于**健康系统**这个大框架下。这和 CK3 的"健康特质（Health traits）"是一致的：CK3 里疾病、伤病、老年特质、失能都归在健康特质这个大类下，以特质（trait）的形式存在，每年有概率获得疾病，也可从领地瘟疫中感染，性传播疾病可通过睡觉传播。我在 CK3 的基础上做了大量扩展和细化。

之前角色只有精神疾病，没有完整的身体疾病系统，这显然不够——历史上很多重要人物死于疾病、受伤、瘟疫，这些都应该在游戏中体现。

为了便于理解和组织，我把健康系统中的疾病分为五大类，目前内置约30种疾病，数据驱动可由模组扩展。需要说明的是，**这个分类是参考性的，不是严格互斥的，本质上所有疾病都归属于健康系统**——有些疾病同时属于多个分类，比如先天性白内障、先天性青光眼、先天性心脏病，它们既是遗传病（出生即有、遗传或发育异常导致）又是慢性病（长期存在、渐进发展）；再比如糖尿病，既有后天的2型糖尿病（与肥胖、饮食相关），也有先天的1型糖尿病（自身免疫、遗传倾向）。因此分类只是为了便于理解和组织，不代表疾病只能属于某一类，更不代表它们不属于健康系统。

**1. 传染病**——可从人口级瘟疫感染，也可在角色间传播。与人口级瘟疫系统共用7种疾病（鼠疫、天花、霍乱、斑疹伤寒、疟疾、结核病、痢疾），另外增加了流感、麻风病（癞病）、梅毒。每种传染病有独特的传播方式：鼠疫和斑疹伤寒经虫媒（跳蚤、虱子）传播，天花和流感经呼吸道传播，霍乱和痢疾经水源传播，疟疾经蚊子传播，结核病经密切接触传播，麻风和梅毒经接触/性传播。传染病是前现代社会的主要杀手之一，一场鼠疫可以在短时间内夺走大量人口，也包括统治者和贵族。

**2. 慢性病/老年病**——与年龄、生活方式、遗传相关，长期存在。目前内置9种：心脏病、中风、糖尿病、痛风、关节炎、哮喘、癫痫、白内障、青光眼。慢性病的特点是病程长、致死率低但持续影响健康和能力，随年龄增长发病概率上升，肥胖会增加心脏病、糖尿病、痛风的风险。

关于**同名疾病的区分**：我认为名称上没必要做区分，但描述上是要的。比如**心脏病**——它是心血管疾病的统称，名称上不区分先天和后天，但描述上需要区分：后天性心脏病（冠心病、心衰等）与肥胖、饮食、年龄、压力相关，中年以后发病；先天性心脏病出生即有，由遗传和发育异常导致，体力受限、寿命较短。再比如**失明**——名称上就是失明，但描述上需要区分是外伤性的（急性、战斗导致）还是疾病性的（渐进、白内障/青光眼导致）。

更进一步，**从代码设计上，不应该严格区分什么先天后天，但要区分形态上的差异**。这里需要强调的是：不同形态的区别**不只是发病机制不同，更重要的是临床表现、进展方式、预后等整体表现都不一样**——如果单纯是发病机制不同，我觉得没有必要去区分。我本人就是先天性白内障患者，有亲身的体会：有些白内障是会进展的，有些就静止不动；有些出生时就有但一辈子不发展，有些中年以后才出现但快速恶化。它们的症状表现、对视力的影响方式、治疗反应、预后都不一样，所以才需要在代码上用形态编号区分。

我的设计思路是：同一种疾病用**形态编号**来区分不同亚型，比如"白内障一"、"白内障二"，而不是"先天性白内障"、"后天性白内障"。不同形态有不同的发病机制、DNA 关联方式，以及更重要的——不同的临床表现和进展方式：

- **形态一（如白内障一）**：本身有一个基础发病概率，在 DNA 的某个字段里，有一个能控制这个概率的位点——DNA 会影响发病概率的高低，但没有这个 DNA 也可能发病。这种形态可能是进展性的，随年龄逐渐恶化，更多对应后天性疾病，基础概率随年龄、环境等因素变化，DNA 只是修正因素。
- **形态二（如白内障二）**：可能只有某个特定 DNA 能控制这个概率——没有这个特定 DNA 几乎不会发病。这种形态可能是静止性的，出生时就有但一辈子不发展，更多对应先天性疾病，几乎完全由遗传决定。

这样设计的好处是：名称上统一都是"白内障"，不会因为"先天/后天"的标签而把疾病割裂；但通过形态编号，实际上区分了不同的疾病表现——进展性还是静止性、症状轻重、对属性的影响方式、治疗反应等。描述上可以说明"白内障一是进展性的，与衰老、紫外线、糖尿病相关；白内障二是静止性的，由遗传或宫内发育异常导致"，但代码层面不需要用"先天/后天"这样的命名来区分，因为形态编号本身就承载了这些差异。

比如痛风在历史上被称为"帝王病"，因为它与 rich diet 相关，贵族和富人更容易得；关节炎是老年常见病，会影响勇武和军事能力；癫痫在古代常被视为神圣或邪恶的征兆，影响社交和统治合法性；白内障和青光眼是老年常见的眼科疾病，渐进性视力下降，最终可致失明，前现代无法有效治疗。

**3. 伤病**——战斗或意外导致的急性损伤。目前内置7种：伤口感染、骨折、失明、跛足、脑震荡、烧伤、冻伤。伤病是战斗系统的重要组成部分——将领在战斗中有概率受伤，受伤程度取决于战斗激烈程度和个人勇武。前现代医学条件下，伤口感染是致死的主要原因之一（比直接战死更多）。

需要特别说明的是**失明**——它是一个比较中性的描述，准确来说它是一个可达成的最终状态，而不是一个独立的疾病。失明更容易由伤病直接导致（战斗中眼睛受伤），但也很有可能和其他原因有关，比如白内障、青光眼、糖尿病并发症、衰老等渐进性疾病。因此在疾病系统中，除了伤病导致的失明，还单独设置了**白内障**和**青光眼**两种眼科慢性病——它们都是渐进性的视力下降，最终可致失明，前现代无法有效治疗。

和心脏病一样，白内障和青光眼名称上也不区分先天和后天，但描述上需要区分：**后天性白内障**与衰老、紫外线暴露、糖尿病、外伤相关，老年高发；**先天性白内障**出生即有，由遗传或宫内发育异常导致，可能伴随其他先天异常。**后天性青光眼**与遗传、年龄、近视相关，中年以后发病，急性发作时眼痛头痛；**先天性青光眼**出生即有或婴幼儿期发病，由前房角发育异常导致，常表现为畏光流泪、眼球增大。

跛足是永久或半永久的残疾，会严重影响角色的战斗能力和统治能力——一个跛足的将领行军能力会大打折扣。冻伤与严寒环境和冬季行军相关，历史上拿破仑征俄和德军征苏都因冻伤损失惨重。

**4. 遗传病/先天疾病**——由DNA决定，出生即有。目前内置6种：血友病、白化病、侏儒症、巨人症、先天性心脏病、驼背。遗传病是遗传系统的重要延伸——DNA不仅决定外貌，也决定健康缺陷。血友病在欧洲王室中非常著名（维多利亚女王的后代），因为近亲结婚导致隐性遗传病高发；巨人症和侏儒症是历史上经常被记载的异常体型，有些巨人成为战士或宫廷奇观，有些侏儒成为弄臣或侍从；驼背在历史上也有著名案例（如理查三世，虽然莎士比亚的描写有夸张）。

**5. 精神疾病**——已有系统（见上文），这里统一纳入疾病框架。

疾病有五个阶段：**潜伏期**（已感染但无症状，仍可传播）、**急性期**（症状明显，健康快速下降，有死亡风险）、**慢性期**（长期存在，症状较轻但持续影响，可能急性发作）、**恢复期**（症状减轻，逐渐恢复）、**永久期**（不可逆，如失智、失明、断肢）。

疾病与人口级瘟疫系统的联动：当某个地区暴发瘟疫时，该地区的角色有概率感染相应的传染病，感染概率受角色的个体抵抗力、年龄、卫生条件影响。角色感染后也可以成为传染源，传播给家庭成员和廷臣。这就是为什么历史上宫廷中经常暴发瘟疫——一个感染的仆人可以把疾病传给整个宫廷。

治疗机制：疾病是否可治疗取决于所需的医学革新——在"医学"革新出现之前，大部分疾病只能靠自然恢复，治疗效果很差；有了医学革新后，可治疗疾病的恢复率显著提升。但即使有医学，前现代的治疗效果仍然有限，很多疾病（如麻风病、失智、遗传病）是不可治疗的。

疾病对属性的影响：每种疾病都有特定的属性修正，急性期影响最大，慢性期减半，恢复期减为三成。比如鼠疫急性期勇武-10、军事-5、魅力-5，每日健康-3；心脏病慢性期勇武-5、军事-3；失明永久期勇武-20、军事-10、学识-5。疾病还会影响生育力（如先天性心脏病、糖尿病）和魅力（如麻风病、天花疤痕、烧伤）。

**借鉴与扩展的对比**：

- **借鉴 CK3 的部分**：疾病作为独立系统影响角色健康和属性；伤病（失明、跛足等）和疾病分开；传染病与人口级瘟疫联动；疾病影响属性和死亡概率；性病（梅毒）可通过性传播；痛风、麻风病、结核病、斑疹伤寒、黑死病等具体疾病。
- **我扩展的部分**：把疾病分为五大类（传染病、慢性病、伤病、遗传病、精神疾病），CK3 主要是伤病、疾病、老年特质、失能；疾病五阶段（潜伏期、急性期、慢性期、恢复期、永久期），CK3 的疾病特质相对简单没有明确阶段；更详细的参数（感染率、死亡率、恢复率、潜伏期、持续时间、R0）；个体抵抗力影响感染概率；治疗机制与医学革新挂钩；更多的慢性病（心脏病、中风、糖尿病、哮喘、癫痫、白内障、青光眼等）；遗传病分类（血友病、白化病、侏儒症、巨人症、先天性心脏病、驼背）；精神疾病系统更详细；同名疾病名称不区分但描述区分（先天/后天）。

我设计这个系统的原因是：我相信疾病和健康是历史的重要驱动力——黑死病改变了欧洲的社会结构，疟疾影响了罗马帝国的衰落，天花帮助西班牙人征服了阿兹特克，很多国王和皇帝死于疾病（如查士丁尼大瘟疫中的查士丁尼本人，爱德华三世的继承人黑太子死于痢疾）。一个没有疾病系统的历史游戏是不完整的。

##### 8.1.6 关系系统

关系系统是角色系统的核心之一。角色之间有各种关系纽带（友谊、敌对、忠诚、怨恨、爱慕等），关系不是静态的，会随着事件和互动变化。关系影响角色的决策——一个对你有深仇大恨的封臣更可能叛乱，一个忠诚的盟友更可能在战争中支援你。关系系统还包括家族关系（父母、配偶、子女、兄弟姐妹）和政治关系（封君、封臣、盟友、对手）。

##### 8.1.7 绰号与评价

绰号系统为角色生成基于其事迹和性格的绰号（如"大帝""无畏者""昏庸者"），有不同的层级和褒贬含义。这参考了历史上统治者绰号的传统。评价系统记录角色在不同维度上的历史评价。这两个系统相对简单，主要是为了增加历史感和角色辨识度。

这部分的设计依据主要来自历史人物研究和心理史学的尝试——我不试图精确模拟历史人物的心理，而是试图捕捉性格、关系和健康如何影响历史决策。

#### 8.2 家族系统

家族系统追踪家族谱系和继承关系。家族不是简单的血缘树，而是有政治意义的实体——家族之间可以结盟、联姻、对抗。继承系统处理角色死亡后的权力和财产转移，有多种继承法（长子继承、选举继承、兄终弟及等）。

#### 8.3 角色与其他系统的联动

角色是连接各个系统的节点——角色的性格影响政治决策，角色的家族影响继承和外交，角色的信仰影响宗教传播，角色的研究推动革新，角色的阶层归属影响派系斗争。没有角色系统，各个系统就是孤立的数值模拟；有了角色系统，历史才有了"人"的维度。

### 9. 世界生态与自主单位

MapActor 自主单位是可以在地图上自主行动的单位，不一定隶属于任何政权。

设计这个系统有几个深层原因，都是我针对市面上大战略游戏的常见问题思考的结果：

**第一，解决政权边界化的问题。** 很多大战略游戏有一个共同的问题——地图被各种政权的色块填满，每一寸土地都属于某个政权，边界清晰得像现代民族国家。这在模拟上是不真实的——前现代世界的大部分土地其实是"无主"的，政权的实际控制范围远小于地图上画的边界。边境地区往往是模糊的、 contested 的、充满了各种非国家行为体的。我不希望地图被色块填满，而是希望有大量的"灰色地带"——无主的土地、蛮族的活动范围、商队的贸易路线、流民的迁徙路径——这些都由 MapActor 来填充。

**第二，让世界更有生命力。** 我不希望地图上只有国家和军队在活动——商队在贸易路线上穿梭，流民在战乱后迁徙，蛮族在边境游荡，盗匪在低秩序地区滋生，雇佣兵等待出价最高的雇主。这些自主单位让世界感觉像是一个活着的生态系统，而不是一个只有玩家和AI政权在博弈的棋盘。

这些自主单位有自己的 AI 和行动逻辑，不同类型有不同的决策间隔（流民每天思考，游牧民每三天，野兽每七天）以控制性能开销。

前国家形态的人类群体——游群、部落、酋邦——以 MapActor 的形式存在于地图上。当它们满足人口、领袖、领土和文化条件时，可以转化为正式政权。这为游戏提供了"蛮族建国"的可能性，也让世界更有生命力。

弃地与聚落摧毁的联动：聚落被摧毁后产生流民 MapActor，地块变无主后蛮族/盗匪滋生，蛮族占据弃地建立营地形成活动范围，可被招安或征服——这是一个完整的生态循环。

## 三、技术架构

### 引擎与语言
- **Unity 6000.6.0f1** — URP 渲染管线
- **C# 9.0** — netstandard2.1
- **模块化程序集** — 6 个 asmdef 单向依赖链

### 模块结构
```
Core              — 数据定义、枚举、本地化
World             — 地形、气候、水文、群系、省份、聚落
Simulation        — 人口、经济、革新、文化、宗教、社会、政治、战争、角色
Rendering         — 地图渲染、覆盖层
Infrastructure    — 存档、模组、序列化、事件系统、音频
UI                — 界面系统、控件、面板
Editor            — 地图编辑器、地形绘制、省份编辑
```

### UI 材质体系
暖灰褐磨砂石材 + 做旧青铜 + 灰米色旧纸的统一设计语言：
- **主面板** — 暖灰褐磨砂石材（载体）
- **Tab** — 嵌入式标签，Active 底部青铜强调线
- **Button** — 稍亮磨砂石材，四状态过渡
- **InputField** — 内凹暗槽，Focus 青铜焦点线
- **Scrollbar** — 凹槽 + 凸起滑块
- **ProgressBar** — 凹槽 + 九语义色填充
- **Tooltip** — 灰米色旧纸信息层

### 字体系统
- **思源黑体** — 功能文字（按钮、Tab、数字、正文）
- **思源宋体** — 身份文字（人物、文化、国家名称、历史文本）

### AI 系统
AI 系统控制非玩家角色和政权的行为。AI 有不同的决策类型（建造、外交、军事等）、目标系统、性格和立场。AI 的决策不是脚本化的，而是基于目标和性格的动态选择——不同性格的 AI 会做出不同的决策。聚落 AI 专门处理聚落的自主发展——即使没有玩家干预，聚落也会根据经济、人口和安全状况自主发展。

### 模组与存档
模组系统支持游戏内容的模组化——群系、商品、革新、宗教、事件等都可以通过 JSON 或脚本添加和修改。这是因为我相信一个历史模拟游戏的生命力在于玩家社区的创造。

存档系统支持游戏状态的保存和加载，包括世界状态、所有角色、所有政权、所有事件等。存档格式设计为可扩展的，方便后续添加新系统。

### 音频
音频系统处理游戏中的音乐和音效。虽然目前还比较基础，但设计目标是根据游戏的时代、地区和情境动态调整音乐——和平时期的舒缓旋律、战争时期的紧张节奏、不同文化地区的不同音乐风格。
