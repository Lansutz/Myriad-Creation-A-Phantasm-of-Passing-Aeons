# Myriad Creation: A Phantasm of Passing Aeons
## 纷繁的世界：一场流逝的幻景

一款基于学术研究的大战略文明模拟游戏。以唯物史观、布罗代尔三时段理论、人类学、技术史、反辉格史观、地理历史学、历史政治学等研究为理论基础，模拟文明从游群到帝国的完整演进过程。

## 学术基础

### 史学理论
- **唯物史观** — 生产力与生产关系的矛盾运动推动社会变革
- **布罗代尔三时段** — 长时段（地理/生态）、中时段（经济/社会周期）、短时段（事件/人物）
- **反辉格史观** — 避免以今度古，尊重历史语境的复杂性
- **历史政治学** — 国家形成、制度变迁、权力结构的历史分析

### 社会科学
- **人类学** — 亲属制度、仪式、象征、文化相对主义
- **地理历史学** — 地理环境对历史进程的塑造与限制
- **技术史** — 技术演进的路径依赖、偶然性与社会嵌入
- **年鉴学派** — 总体史、问题史学、跨学科方法

## 核心设计理念

### 文明演进的多路径
不预设"进步"的线性叙事。文明可以通过定居农业、游牧征服、贸易控制、宗教统一、军事联盟等多条路径形成国家。同一文化阶段可以有不同的移动模式（定居/半定居/游牧）和经济基础。

### 地理决定论与能动性的平衡
地理条件决定物产与初始可能性，但不决定最终命运。物产→革新→路径依赖，历史充满偶然性与天才人物的突破。

### 社会分层的渐进性
从平等的游群，到氏族部落，到酋邦的初步分层，到国家的完整阶级结构。每个阶层的出现都需要特定的革新与社会条件。

### 行国与城国
定居政权（城国）与游牧政权（行国）是两种根本不同的国家形态。行国没有固定边界，以活动范围和移动王庭为特征；城国以固定城市和官僚体系为基础。两者可以互相转化。

## 游戏系统

> 以下是目前在设计和开发中的系统。很多还只是框架，细节会随着开发不断调整。写在这里是为了把设计思路和学术依据记录下来，也方便后续回顾和修正。

### 世界生成

世界生成的核心思路是：地理不是背景板，而是历史的第一推动力。我们不希望玩家看到的是一张随机噪声地图，而是一个有逻辑的生态结构——山脉阻挡水汽形成雨影效应，大河沿岸孕育冲积平原，河口三角洲天然适合建城。

实现上基于多层高度图叠加生成地形，再用水力侵蚀算法雕刻河谷，最后用简化的大气环流模型计算温度和降水分布。群系（biome）的所有参数都通过 JSON 定义，方便后续调整和模组化。

这部分的依据主要来自地理历史学和环境史的研究——地理环境不决定历史，但它深刻地塑造了历史的可能性空间。

### 人口与社会

人口系统的设计出发点是：人不是数字，而是由具体阶层构成的社会实体。我们参考了人类学对前现代社会的研究，将人口划分为农民、自由民（市民、商人、工匠、士人）、奴隶、王室和贵族教士几个阶层。每个阶层有独特的需求——农民需要土地和粮食安全，市民需要贸易和手工业机会，贵族需要权力和地位。需求得不到满足会引发不满、迁徙甚至叛乱。

聚落（村镇、城、堡垒）被设计为独立于地块的实体，有自己的等级、形态和辐射范围。这是因为前现代的聚落不是地块的附属品，而是一个有自身生命力的节点。聚落的形态也不是永久标签——村镇可以发展为城，堡可以转型为城，城也可能因战乱强化为堡垒。

聚落摧毁系统设计了三级程度（轻度劫掠、中度破城、重度夷平）和六种手段（劫掠、纵火、拆城、水淹、屠城、夷平）。这参考了历史上的真实案例——汉谟拉比毁玛睿、杨坚毁建康、赵炅毁晋阳——摧毁的手段和程度各不相同，后果也不一样。

### 经济

经济系统的核心逻辑是一条因果链：地理决定物产，物产决定可学习的革新，革新提升生产效率，生产剩余支撑社会分层和国家形成。没有铁矿的地区无法发展金属冶炼，没有适合耕作的土地无法支撑农业文明——这不是刻意的限制，而是历史的真实。

加工品被设计为有品质等级（差、普通、优良、精良），品质受原材料库存、工匠技能和技术水平影响。原材料不足时品质会下降。这参考了技术史中关于"生产实践积累"的研究——完美的产品需要大量次品来堆积经验。

贸易系统设计了商路流量、贸易节点和经济虹吸效应——高等级聚落对周边形成经济吸引，税收和贸易向中心聚集。这参考了历史地理学中关于中心地理论和经济地理学的研究。

### 革新

革新系统的设计是为了回应一个问题：技术进步是怎么发生的？我们拒绝线性的"科技树"叙事，因为技术史的研究表明，技术演进是路径依赖的、充满偶然性的、受社会条件约束的。

革新分为技术、思想、制度、军事、经济、社会六大类，每类有明确的前置关系，但前置链不是唯一的——同一项革新可能有不同的前置路径。

革新进度由两条路径共同推动：一是社会总体的生产实践积累（生产数量乘以品质，但边际收益递减），二是个人化的突破（工匠、商人等角色在旧方法实践达到阈值后迸发新灵感）。这参考了技术史中关于"学习曲线"和"天才突破"的讨论——大多数技术进步是缓慢的实践积累，但关键时刻的天才人物可以带来跨越式发展。

需要强调的是，天才不能凭空创造——没有铜的地区，再天才的工匠也无法发明青铜冶炼。物产是革新学习的前置条件，至少需要一定数量的相关物产才能开始积累研究进度。

### 文化与社会演进

文化阶段的设计参考了人类学的经典框架（塞维斯的游群-部落-酋邦-国家四阶段论），并在此基础上扩展为五阶段：游群、部落、酋邦、族群、高度文明。这不是线性的"进步"叙事，而是社会复杂度的提升——每个阶段都可以有不同的移动模式和经济基础。

移动模式（高度流动、季节性营地、定居）和生计类型（狩猎采集、渔猎、早期畜牧、管理型采集）是两个独立的维度。这里需要特别澄清：海洋城邦是定居模式加海洋贸易经济，不是半定居——它的城市是永久固定的，只是经济依赖海洋贸易。半定居（季节性营地）指的是渔猎族群那种有冬夏营地的模式。

国家形成被设计为五条可能的路径：定居农业路径（农业剩余推动人口增长和社会分层）、游牧征服路径（军事征服后吸收被征服者的制度）、贸易控制路径（控制商路积累财富）、宗教统一路径（宗教认同超越部落界限）、军事联盟路径（部落联盟固化为国家）。这参考了比较人类学和国家形成理论的研究——国家不是只有一种形成方式。

扈从制被设计为酋邦阶段的核心制度——首领通过私人扈从队积累武力，扈从的忠诚是人身依附关系。这参考了塔西佗《日耳曼尼亚志》中对日耳曼扈从制（Comitatus）的描述，以及恩格斯关于扈从制促进王权产生的论断。

### 行国与城国

这是整个游戏最核心的设计之一，也是最容易被误解的地方。

首先需要澄清：前现代国家没有现代意义上的"固定边界"。无论是城国还是行国，领土都是模糊的、势力范围式的。我们说的"行国与城国"不是"有边界 vs 没边界"的区别，而是两种根本不同的组织逻辑。

**城国**（定居政权）以固定的定居点为基础，经济主要依赖农业、贸易和税收，军事以常备军和守城战为主。它的核心资产是土地和城市。

**行国**（游牧政权）以移动的人群和牲畜为基础，王庭随季节在冬营地和夏营地之间迁徙，经济主要依赖畜牧、劫掠和对被征服定居区征收的保护费，军事是全民皆兵的骑兵，擅长机动和诱敌深入。它的核心资产是人和牲畜，而不是土地——所以行国不需要防守每一寸土地，拔营即走。

行国可以征服和控制定居城市（作为附庸或纳税地），但王庭本身不固定。行国也可以通过定居化改革转化为城国——这需要农业技术、城市建设和官僚制度的建立。城国罕见游牧化，通常是被游牧民族征服后统治阶层发生游牧化。

这个设计的依据主要来自中国史学界对"行国"与"城国"的经典区分（如司马迁《史记》中对匈奴的描述），以及人类学对游牧社会的研究。

### 政治与政体

政体系统不使用"君主制/共和制"的简单二分，而是设计为七个维度的组合：最高权力归谁、权力如何交接、中央机构是什么、地方如何治理、头衔如何分配、继承法如何规定、城市有多少自治权。

这样设计是因为历史上的政体远比"君主/共和"复杂——罗马帝国是君主制但有元老院，神圣罗马帝国是选举君主制，威尼斯是共和制但有世袭贵族。一个君主制国家可以有中央机构，可以用选举方式交接权力，可以同时存在封建和官僚两种地方治理方式。

继承法被细分为范围（本族/血亲不论姓氏）、支系（长支优先/兄终弟及）、性别（仅男/男优先/平等/仅女/女优先）和长幼。最高权力的交接可以有主要方式和次要方式——比如罗马到东罗马，僭主制是主导，推举制是第一次要，血缘世袭是第二次要。

这部分的设计依据主要来自历史政治学和比较政治学对前现代政体的研究。

### 外交与战争

外交系统的一个核心设计是：敌对是常态，宣战是例外。我们不希望玩家被"没有宣战理由不能开战"束缚——在敌对状态下，可以直接发动局部入侵、劫掠城镇、攻击聚落。但每一次敌对行动都会给对方制造战争借口，也会损害国际名声。正式宣战开启全面战争，不宣而战承担名声损耗。

战争借口、战争目标和和平条约被设计为三层分离的——开战的理由不一定等于想要的结果。条约谈判时，双方各有"让步"和"索取"清单，可选项受战争分数限制。

外交关系设计了十种类型：平等盟约五种（互不侵犯、防御同盟、进攻同盟、全面同盟、阵营），不平等从属五种（朝贡、附庸、附属、保护国、傀儡）。通行管制分四级——在严格管制地区，军队通过必须请求军事通行权。

这部分的设计参考了历史国际关系学和战争史的研究，特别是关于前现代国际关系中"灰色地带"冲突的研究。

### 军事

军事系统的核心不是兵力数字，而是组织度、士气和训练度三者的互动。组织度决定部队能持续战斗多久，士气决定是否会崩溃，训练度决定组织度掉得有多慢。

这样设计是因为军事史的研究表明，前现代战争的胜负往往不取决于人数，而取决于部队的凝聚力和纪律性。一支训练有素的小部队可以在有利地形击败人数众多但组织度低下的大军。

军队以100人为一个编制块，补员按一定比例批量增加——这主要是出于性能考虑，避免逐人计算的CPU负担。战斗结算中，总伤亡率和瞬时伤亡率分开计算，组织度过低会增加敌方追击效率，瞬时伤亡率过高会瞬间降低组织度，极端情况下可能触发踩踏事件。

通行系统不设硬性的不可通行——山脉地区通行难度高，但并非完全无法通过。关隘仅可在狭窄地形修建，可以直接阻挡通行；堡垒不直接阻挡通行，但敌对部队经过时受行军损耗和速度影响。

### MapActor 自主单位

MapActor 是可以在地图上自主行动的单位，不一定隶属于任何政权。设计这个系统是因为我们不希望地图上只有国家和军队在活动——商队在贸易路线上穿梭，流民在战乱后迁徙，蛮族在边境游荡，盗匪在低秩序地区滋生，雇佣兵等待出价最高的雇主。

这些自主单位有自己的 AI 和行动逻辑，不同类型有不同的决策间隔（流民每天思考，游牧民每三天，野兽每七天）以控制性能开销。

前国家形态的人类群体——游群、部落、酋邦——以 MapActor 的形式存在于地图上。当它们满足人口、领袖、领土和文化条件时，可以转化为正式政权。这为游戏提供了"蛮族建国"的可能性，也让世界更有生命力。

### 聚落摧毁与弃地

历史上城市被摧毁、土地被遗弃是常见现象，我们希望完整地模拟这一过程，而不是简单地"减分"。

摧毁分为三级程度：轻度劫掠（掠夺物资、零星纵火）、中度破城（拆除城墙、烧毁主要建筑）、重度夷平（系统性摧毁、水淹、屠城）。六种手段各有特点——纵火可能蔓延，拆城可以获得建材，水淹仅临河城市可用但地块会变沼泽，屠城产生大量流民但名声暴跌。

摧毁后会引发连锁反应：人口流失为流民 MapActor，地块变无主，秩序下降导致盗匪和蛮族滋生，蛮族占据弃地后建立营地、形成活动范围。废墟地块保留原有的文化和宗教，重新定居时可能恢复。

弃地也有四种类型：主动弃地（战略收缩）、被动弃地（战败被驱逐）、自然弃地（环境恶化或经济崩溃）、游牧弃地（季节性迁移）。弃地不是失败的代名词——游牧政权的季节性弃地是正常运作方式，战略收缩时的主动弃地是以空间换时间的选择。

这部分的设计参考了历史地理学中关于"废弃聚落"和"黑暗时代"的研究，以及环境史中关于文明崩溃的讨论。

## 技术架构

### 引擎与语言
- **Unity 6000.6.0f1** — URP 渲染管线
- **C# 9.0** — netstandard2.1
- **模块化程序集** — 6 个 asmdef 单向依赖链

### 模块结构
```
Core              — 数据定义、枚举、本地化
World             — 地形、气候、水文、群系、省份、聚落
Simulation        — 人口、经济、革新、文化、宗教、社会、政治、战争、角色
Rendering         — 地图渲染、覆盖层
Infrastructure    — 存档、模组、序列化、事件系统
UI                — 界面系统、控件、面板
Editor            — 地图编辑器、地形绘制、省份编辑
```

### UI 材质体系
暖灰褐磨砂石材 + 做旧青铜 + 灰米色旧纸的统一设计语言：
- **主面板** — 暖灰褐磨砂石材（载体）
- **Tab** — 嵌入式标签，Active 底部青铜强调线
- **Button** — 稍亮磨砂石材，四状态过渡
- **InputField** — 内凹暗槽，Focus 青铜焦点线
- **Scrollbar** — 凹槽 + 凸起滑块
- **ProgressBar** — 凹槽 + 九语义色填充
- **Tooltip** — 灰米色旧纸信息层

### 字体系统
- **思源黑体** — 功能文字（按钮、Tab、数字、正文）
- **思源宋体** — 身份文字（人物、文化、国家名称、历史文本）
