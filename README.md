# Myriad Creation: A Phantasm of Passing Aeons
## 纷繁的世界：一场流逝的幻景

一款基于学术研究的大战略文明模拟游戏。以唯物史观、布罗代尔三时段理论、人类学、技术史、反辉格史观、地理历史学、历史政治学等研究为理论基础，模拟文明从游群到帝国的完整演进过程。

## 学术基础

### 史学理论
- **唯物史观** — 生产力与生产关系的矛盾运动推动社会变革
- **布罗代尔三时段** — 长时段（地理/生态）、中时段（经济/社会周期）、短时段（事件/人物）
- **反辉格史观** — 避免以今度古，尊重历史语境的复杂性
- **历史政治学** — 国家形成、制度变迁、权力结构的历史分析

### 社会科学
- **人类学** — 亲属制度、仪式、象征、文化相对主义
- **地理历史学** — 地理环境对历史进程的塑造与限制
- **技术史** — 技术演进的路径依赖、偶然性与社会嵌入
- **年鉴学派** — 总体史、问题史学、跨学科方法

## 核心设计理念

### 文明演进的多路径
不预设"进步"的线性叙事。文明可以通过定居农业、游牧征服、贸易控制、宗教统一、军事联盟等多条路径形成国家。同一文化阶段可以有不同的移动模式（定居/半定居/游牧）和经济基础。

### 地理决定论与能动性的平衡
地理条件决定物产与初始可能性，但不决定最终命运。物产→革新→路径依赖，历史充满偶然性与天才人物的突破。

### 社会分层的渐进性
从平等的游群，到氏族部落，到酋邦的初步分层，到国家的完整阶级结构。每个阶层的出现都需要特定的革新与社会条件。

### 行国与城国
定居政权（城国）与游牧政权（行国）是两种根本不同的国家形态。行国没有固定边界，以活动范围和移动王庭为特征；城国以固定城市和官僚体系为基础。两者可以互相转化。

## 游戏系统

### 世界生成
- **地形生成** — 基于高度图的程序化地形，支持灰度图导入、水力侵蚀、大气环流 GCM、洋流模拟
- **气候与群系** — 温度、降水、海拔共同决定群系分布，群系 JSON 配置化
- **水文系统** — 河流生成、流域划分、河口三角洲
- **省份与子地块** — 省份包含多个子地块，支持地块级别的精细模拟
- **地图模式** — 政治、文化、宗教、经济、军事等多种地图模式互斥切换，基础图层可叠加

### 人口与社会
- **阶层系统** — 农民（自耕农/佃农/农奴/雇农）、自由民（市民/商人/工匠/士人）、奴隶（家奴/官奴/债务奴/战俘奴）、王室、贵族教士
- **阶层需求** — 每个阶层有独特需求，需求未满足会引发不满、叛乱、迁徙
- **人口承载** — 地理承载、仓储承载、贸易修正共同决定地块人口上限
- **聚落系统** — 村镇/城/堡垒三大形态，建立在地块之上而非依附地块，有辐射范围和控制范围
- **聚落形态演化** — 村镇→城、堡→城、城→堡垒，形态可缓慢演化而非永久固化

### 经济
- **物产系统** — 地理条件决定物产分布，物产是革新学习的前置条件
- **生产与加工** — 加工品有品质等级（差/普通/优良/精良），品质受原材料库存、工匠技能影响
- **贸易系统** — 商路流量、贸易节点、虹吸效应
- **税收** — 农业税、商税、人头税、畜牧税、保护费

### 革新
- **革新分类** — 技术、思想、制度、军事、经济、社会
- **实践驱动** — 革新学习进度与生产实践数量挂钩，边际收益递减，需要更高品质产物突破
- **个人化革新** — 工匠、商人等角色在旧方法实践达到阈值后迸发新灵感
- **前置链** — 革新有明确前置关系，UI 仅展示最近一层前置
- **文化阶段绑定** — 革新解锁与文化阶段、社会分层、专业化程度联动

### 文化
- **文化阶段** — 游群→部落→酋邦→族群→高度文明，五阶段渐进
- **移动模式** — 高度流动（游牧）/季节性营地（半定居）/定居，三路径独立于经济基础
- **生计类型** — 狩猎采集/渔猎/早期畜牧/管理型采集
- **国家形成多路径** — 定居农业、游牧征服、贸易控制、宗教统一、军事联盟
- **扈从制** — 酋邦阶段核心制度，促进军事首领→王权转化

### 宗教
- **宗教教义与传统** — 可自定义教义、仪式、圣地
- **个人化信仰** — 角色有个人信仰倾向，与社会总体宗教互动

### 政治
- **政体七维组合** — 最高权力（君主/共和）、权力交接（世袭/选举/推举/僭夺）、中央机构（有无→类型→交接分配构成）、地方治理（封建/官僚，各有子选项组）、头衔分配、城市特许
- **继承法细分** — 范围（本族/血亲不论姓氏）、支系（长支优先/兄终弟及）、性别（仅男/男优先/平等/仅女/女优先）、长幼
- **外交关系** — 平等盟约5种（互不侵犯/防御同盟/进攻同盟/全面同盟/阵营）、不平等从属5种（朝贡/附庸/附属/保护国/傀儡）
- **通行管制** — 无管制/松散管制/有限管制/严格管制，严格管制需请求军事通行权
- **敌对与战争** — 敌对状态可发动局部入侵劫掠，正式战争需宣战；不宣而战承担名声损耗
- **战争借口/目标/条约分层** — 三者分离，条约谈判有让步/索取和战争分数总分限制

### 军事
- **军队属性** — 组织度、士气、训练度，训练度越高组织度掉得越慢
- **人口块** — 100人/块，补员按10%批量增加以优化性能
- **战斗结算** — 总伤亡率与瞬时伤亡率分离，组织度过低增加敌方追击效率
- **通行系统** — 综合海拔与坡度计算通行难度，不设硬性不可通行
- **关隘与堡垒** — 关隘仅可在狭窄地形修建，可直接阻挡通行；堡垒影响行军损耗与补给
- **营寨系统** — 军队、盗匪、蛮族均可建立，行军营地/冬营/山寨/毡帐群等

### 角色
- **人物系统** — 角色有属性、技能、性格、关系
- **家族与谱系** — 家族传承、继承法、家族政治
- **派系** — 基于阶层和利益的政治派系
- **个人化革新与信仰** — 天才角色可推动技术突破，个人信仰与社会宗教互动

### MapActor 自主单位
- **无归属单位** — 可在无主地区自主行动，有独立 AI
- **类型** — 流民、游牧民、蛮族酋邦、商队、雇佣兵、盗匪、野兽、动物灾害
- **前国家载体** — 游群/部落/酋邦阶段的人类群体以 MapActor 形式存在，满足条件后转化为正式政权
- **营寨建立** — MapActor 可建立临时或半永久据点

### 聚落摧毁与弃地
- **摧毁程度** — 轻度劫掠/中度破城/重度夷平，六种手段（劫掠/纵火/拆城/水淹/屠城/夷平）
- **废墟状态** — 摧毁后聚落变为废墟，可被重新定居
- **流民产生** — 摧毁导致人口流失，产生流民 MapActor
- **弃地机制** — 主动弃地/被动弃地/自然弃地/游牧弃地，地块变无主
- **文化残留** — 废墟地块保留原文化宗教，重新定居时可能恢复

## 技术架构

### 引擎与语言
- **Unity 6000.6.0f1** — URP 渲染管线
- **C# 9.0** — netstandard2.1
- **模块化程序集** — 6 个 asmdef 单向依赖链

### 模块结构
```
Core              — 数据定义、枚举、本地化
World             — 地形、气候、水文、群系、省份、聚落
Simulation        — 人口、经济、革新、文化、宗教、社会、政治、战争、角色
Rendering         — 地图渲染、覆盖层
Infrastructure    — 存档、模组、序列化、事件系统
UI                — 界面系统、控件、面板
Editor            — 地图编辑器、地形绘制、省份编辑
```

### UI 材质体系
暖灰褐磨砂石材 + 做旧青铜 + 灰米色旧纸的统一设计语言：
- **主面板** — 暖灰褐磨砂石材（载体）
- **Tab** — 嵌入式标签，Active 底部青铜强调线
- **Button** — 稍亮磨砂石材，四状态过渡
- **InputField** — 内凹暗槽，Focus 青铜焦点线
- **Scrollbar** — 凹槽 + 凸起滑块
- **ProgressBar** — 凹槽 + 九语义色填充
- **Tooltip** — 灰米色旧纸信息层

### 字体系统
- **思源黑体** — 功能文字（按钮、Tab、数字、正文）
- **思源宋体** — 身份文字（人物、文化、国家名称、历史文本）
